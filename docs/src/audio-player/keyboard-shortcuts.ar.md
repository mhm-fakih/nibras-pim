# اختصارات لوحة المفاتيح

الاختصارات التي تتضمن **Ctrl** تعمل في كل مكان — حتى أثناء كتابة تسمية علامة أو تحرير نص مفرّغ.
أما اختصارات المفتاح المنفرد فلا تعمل إلا حين **لا** تكتب في حقل نصي.

## التشغيل { #playback }

| المفاتيح | الإجراء |
|---|---|
| **Space** · **Ctrl+Space** | تشغيل / إيقاف مؤقت |
| **←** · **Ctrl+←** | تخطٍّ للخلف (بمقدار وقت **Skip forward / back** (التخطي للأمام / للخلف)) |
| **→** · **Ctrl+→** | تخطٍّ للأمام |

## العلامات المرجعية { #bookmarks }

| المفاتيح | الإجراء |
|---|---|
| **B** · **Ctrl+B** | إضافة علامة (قبل بضع ثوانٍ، وإعادة التشغيل من هناك) |
| **N** | الانتقال إلى حقل تسمية العلامة |
| **Enter** (في حقل التسمية) | إضافة علامة بتلك التسمية |
| **Enter** (عند تحرير تسمية في القائمة) | حفظ التسمية |

## الملفات والنافذة { #files-and-window }

| المفاتيح | الإجراء |
|---|---|
| **Ctrl+O** | فتح ملف وسائط |
| **Ctrl+L** | الانتقال إلى حقل **Go to path…** (انتقل إلى مسار) |
| **Ctrl+S** | حفظ تعديلات النص المفرّغ الآن (وهي تُحفظ تلقائيًا أيضًا) |
| **Ctrl+Delete** | نقل الملف قيد التشغيل إلى سلة المهملات (يطلب التأكيد أولًا) |
| **Ctrl+T** | التبديل بين السمة الفاتحة / الداكنة |
| **Ctrl+,** | الإعدادات |
| **Ctrl+Q** | الخروج |
| **Esc** | مغادرة حقل نصي (والعودة إلى قائمة التشغيل) |
| **Enter** (في قائمة التشغيل) | تشغيل المقطع المحدد |

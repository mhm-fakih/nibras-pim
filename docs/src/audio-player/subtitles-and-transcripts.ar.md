# الترجمات والنصوص المفرّغة

يلتقط المشغّل نوعين من الملفات النصية الموجودة بجانب التسجيل والتي تحمل اسمه:

| النوع | اسم الملف | مُوقَّت؟ | طريقة العرض |
|---|---|---|---|
| الترجمات | `talk.en.srt`، `talk.srt` | نعم | سطر واحد في كل مرة، متزامنًا مع التشغيل |
| النصوص المفرّغة | `talk.ar.ai.txt`، `talk.en.ai.txt`، `talk.ai.txt` | لا | النص كاملًا في اللوحة الجانبية **TRANSCRIPT** (النص المفرّغ) |

حين يكون للملف أيٌّ منهما، يظهر صفّ من الشارات تحت عنوانه.

## الترجمات { #subtitles }

الترجمات ملفات `.srt` قياسية. الجزء بين اسم التسجيل و`.srt` هو اللغة: `talk.en.srt` يعطي شارة
**en**. أما `talk.srt` العادي فيعطي شارة **sub**.

1. افتح التسجيل. تظهر شارات **Subtitles:** (الترجمات) مع تحديد **Off** (إيقاف).
2. انقر شارة لغة.

يظهر السطر الحالي فوق الفيديو، أو — في الصوت — فوق شريط التقديم مباشرة. انقر **Off** لإخفاء
الترجمات.

!!! tip "تلميح"
    حين تكون الترجمات مفعّلة، تُسمّى العلامة التي تضيفها دون كتابة تسمية بالسطر المنطوق حينها. انظر
    [العلامات المرجعية](bookmarks.md#with-a-label).

## النصوص المفرّغة { #transcripts }

النص المفرّغ ملف نصي عادي بترميز UTF-8 ينتهي بـ`.ai.txt` — مثل مخرجات أداة تحويل الكلام إلى نص.
ليس فيه توقيتات، لذا يعرض المشغّل النص كاملًا في لوحة **TRANSCRIPT** على يمين المشغّل، ككلمات
الأغاني.

- تعرض شارات **Transcript:** (النص المفرّغ) كل لغة موجودة (`talk.ar.ai.txt` ← **ar**؛ و`talk.ai.txt`
  العادي ← **txt**).
- **تُفتح اللوحة تلقائيًا** حين يكون للملف نص مفرّغ. وإن كنت اخترت لغة لملف سابق، تُختار تلك اللغة
  مجددًا حين تكون متاحة.
- تُعرض النصوص العربية من اليمين إلى اليسار. وتتبع اللغات الأخرى اتجاه نصها. انظر
  [اللغات](../concepts/languages.md).

### تصحيح نص مفرّغ { #correct-a-transcript }

اللوحة قابلة للتحرير — صحّح ما أخطأ فيه برنامج التفريغ. تُحفظ تغييراتك في ملف `.ai.txt` بعد لحظة من
توقفك عن الكتابة، ودائمًا قبل تبديل اللغة أو فتح ملف آخر أو الخروج. اضغط **Ctrl+S** للحفظ فورًا. يؤكّد
سطر الرسائل كل عملية حفظ.

### بدء نص مفرّغ جديد { #start-a-new-transcript }

لكلٍّ من **ar** و**en** غير الموجودة بعدُ للملف، يظهر زر **+ ar** / **+ en**. انقر أحدهما لإنشاء ملف
`talk.ar.ai.txt` فارغ (أو `.en.ai.txt`) وابدأ الكتابة في اللوحة. الزر الذي تضغطه يحدد اللغة؛ ويحتفظ
الملف بذلك الاسم.

### حذف نص مفرّغ { #delete-a-transcript }

لكل شارة نص مفرّغ زر سلة مهملات صغير خاص بها. النقر عليه ينقل ذلك الملف إلى سلة مهملات سطح المكتب
**فورًا، دون سؤال** — استعده من سلة المهملات إن غيّرت رأيك.

!!! note "من أين تأتي النصوص المفرّغة"
    المشغّل يقرأ هذه الملفات ويحرّرها وينشئها فقط — ولا يفرّغ الصوت بنفسه. أي أداة تكتب
    `<recording>.<lang>.ai.txt` بجانب التسجيل تفي بالغرض.

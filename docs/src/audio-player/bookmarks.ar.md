# العلامات المرجعية

العلامة المرجعية تعلّم لحظةً في تسجيل، مع تسمية اختيارية. بُني مشغّل الصوت حول إنشائها بسرعة — أثناء
الاستماع، دون توقف.

## إضافة علامة { #add-a-bookmark }

اضغط **B** (أو **Ctrl+B**، الذي يعمل حتى أثناء الكتابة)، أو انقر **＋ Bookmark** (إضافة علامة).

توضع العلامة قبل بضع ثوانٍ **إلى الوراء** — عند اللحظة التي سمعتها للتوّ، لا اللحظة التي تفاعلت فيها —
ويقفز التشغيل إلى هناك لتسمعها مجددًا. يؤكّد سطر الرسائل ذلك، مثلًا
`✓ Bookmarked 12:04 (−5s)`. غيّر مقدار الرجوع عبر **Bookmark rewind (seconds)** (رجوع العلامة
بالثواني) في [الإعدادات](settings.md).

### مع تسمية { #with-a-label }

1. اضغط **N** للانتقال إلى حقل **Optional note for the next bookmark…** (ملاحظة اختيارية للعلامة
   التالية).
2. اكتب تسمية.
3. اضغط **Enter** (أو **Ctrl+B**) لإضافة العلامة بتلك التسمية.

إن لم تكتب تسمية وكان مسار ترجمة مفعّلًا، تُسمّى العلامة بسطر الترجمة في تلك اللحظة.

## استخدام علاماتك { #use-your-bookmarks }

تعرض قائمة **BOOKMARKS** (العلامات المرجعية) تحت أزرار التحكم كل علامات الملف الحالي، مرتّبةً زمنيًا.
وتظهر العلامات أيضًا كعلامات صغيرة على [شريط التقديم الموجي](playback.md#the-waveform-seek-bar).

| لكي… | افعل هذا |
|---|---|
| تنتقل إلى علامة | انقر وقتها (أو أي مكان في الصف خارج التسمية) |
| تعدّل تسمية | انقر التسمية (أو **no label** (بلا تسمية))، واكتب، ثم اضغط **Enter** أو انقر خارجها للحفظ |
| تحذف علامة | انقر زر سلة المهملات الخاص بها |

يعرض عمود **Bkm** في قائمة التشغيل عدد العلامات في كل ملف، وتظهر الملفات التي تضع عليها علامات تحت
**RECENTLY BOOKMARKED** (عُلِّمت مؤخرًا).

## ملف ‎.tmk { #the-tmk-file }

تُحفظ العلامات فورًا في ملف نصي عادي بجانب التسجيل، بالاسم نفسه وبامتداد `.tmk`:

```
lecture.mp3
lecture.tmk
```

علامة واحدة في كل سطر — الوقت بين قوسين معقوفين، ثم التسمية:

```
[1:09]
[12:04] key point on refraction
[1:03:20] auto
```

- الأوقات بصيغة `M:SS`، أو `H:MM:SS` بعد تجاوز الساعة.
- التسميات التي تكتبها تطبيقات أخرى (مثل أولوية `p2` أو كلمة `auto` من الهاتف) تُحفظ كما هي تمامًا.
- حذف آخر علامة يزيل ملف `.tmk`.

ولأنه نص عادي، يمكنك قراءة ملف `.tmk` أو تحريره في أي محرر، وهو يُزامَن كأي ملف آخر. يكتب الهاتف
الصيغة نفسها، فتظهر العلامات المنشأة على أي جانب في الجانبين. انظر
[العلامات المرجعية (‎.tmk)](../concepts/bookmarks-tmk.md).

!!! tip "العلامات في ملاحظاتك"
    إن كان التسجيل في [المجلد المرافق](../concepts/companion-folders.md) لملاحظة، يعرض knotes لسطح
    المكتب عدد العلامات بوصفها **time marks** (علامات زمنية) على بطاقة الملاحظة.

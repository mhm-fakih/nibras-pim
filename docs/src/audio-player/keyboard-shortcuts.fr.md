# Raccourcis clavier

Les raccourcis avec **Ctrl** fonctionnent partout — même pendant que vous saisissez une étiquette de marque-page ou modifiez une
transcription. Les raccourcis à touche simple ne fonctionnent que lorsque vous n'êtes **pas** en train de saisir dans un champ de texte.

## Lecture { #playback }

| Touches | Action |
|---|---|
| **Space** · **Ctrl+Space** | Lecture / pause |
| **←** · **Ctrl+←** | Saut arrière (de la durée **Skip forward / back** (saut avant / arrière)) |
| **→** · **Ctrl+→** | Saut avant |

## Marque-pages { #bookmarks }

| Touches | Action |
|---|---|
| **B** · **Ctrl+B** | Ajouter un marque-page (quelques secondes en arrière, et reprendre la lecture à partir de là) |
| **N** | Aller au champ d'étiquette du marque-page |
| **Enter** (dans le champ d'étiquette) | Ajouter un marque-page avec cette étiquette |
| **Enter** (en modifiant une étiquette dans la liste) | Enregistrer l'étiquette |

## Fichiers et fenêtre { #files-and-window }

| Touches | Action |
|---|---|
| **Ctrl+O** | Ouvrir un fichier multimédia |
| **Ctrl+L** | Aller au champ **Go to path…** (aller au chemin) |
| **Ctrl+S** | Enregistrer immédiatement les modifications de la transcription (elles s'enregistrent aussi d'elles-mêmes) |
| **Ctrl+Delete** | Placer le fichier en cours de lecture dans la corbeille (avec confirmation) |
| **Ctrl+T** | Basculer entre thème clair et sombre |
| **Ctrl+,** | Paramètres |
| **Ctrl+Q** | Quitter |
| **Esc** | Quitter un champ de texte (retour à la liste de lecture) |
| **Enter** (dans la liste de lecture) | Lire la piste sélectionnée |

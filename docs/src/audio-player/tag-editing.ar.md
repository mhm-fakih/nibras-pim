# تحرير الوسوم

يستطيع المشغّل كتابة الوسوم الأكثر شيوعًا — العنوان والفنان والألبوم والنوع — مباشرة في ملفات الوسائط،
فتظهر في أي مشغّل آخر أيضًا.

!!! note "يتطلب mutagen"
    تتطلب كتابة الوسوم حزمة Python ‏`mutagen` (`python3-mutagen` على Debian/Ubuntu، و`python-mutagen`
    على Arch). بدونها يعمل كل شيء آخر، لكن زر **Apply** (تطبيق) يكون معطّلًا، وتُبلغ تعديلات العنوان
    بأنها لم تُحفظ.

## إعادة تسمية عنوان الملف قيد التشغيل { #rename-the-playing-files-title }

1. انقر داخل حقل **Title** (العنوان) أعلى المشغّل.
2. اكتب العنوان الجديد.
3. اضغط **Enter**.

يعرض سطر الرسائل `✓ Title saved` وتُحدَّث قائمة التشغيل. اسم الملف نفسه لا يتغير — مرّر المؤشر فوق
الحقل لرؤيته.

## وسم مجلد كامل { #tag-a-whole-folder }

يكتب شريط **Tag →** (وسم) تحت قائمة التشغيل القيم نفسها لـ**Genre** (النوع) و**Artist** (الفنان)
و**Album** (الألبوم) في كل ملف مدرج حاليًا في قائمة التشغيل.

1. حمّل مجلدًا (انظر [المكتبة](library.md)) وضيّق قائمة التشغيل إلى الملفات التي تريدها —
   وغالبًا ما يكون **Untagged only** (غير الموسومة فقط) نقطة البداية المناسبة.
2. املأ أيًّا من **Genre** و**Artist** و**Album**. تُترك الحقول الفارغة دون تغيير.
3. انقر **Apply** (تطبيق) وأكّد (`Write these tags to N file(s)?`).

يُعاد قراءة المجلد بعد ذلك، فيعكس متصفّح الأنواع / الفنانين / الألبومات الوسوم الجديدة.

## الصيغ التي يمكن وسمها { #which-formats-can-be-tagged }

| الصيغة | تُكتب الوسوم بصيغة |
|---|---|
| MP3 | ID3v2 (العنوان، الفنان، الألبوم، النوع) |
| FLAC، Ogg، Opus | تعليقات Vorbis |
| M4A / MP4 | وسوم MP4 القياسية |

الملفات التي لا يمكن وسمها — بعض صيغ الفيديو والصيغ الأقل شيوعًا — تُتخطّى وتُحتسب في رسالة النتيجة
(مثلًا `Tagged 12 file(s), 2 unsupported`). لا يتغير أي شيء آخر.

# الإعدادات

افتح **Settings** (الإعدادات) بـ**Ctrl+,** أو بزر الترس في شريط العنوان. انقر **Save** (حفظ) للتطبيق.

| الإعداد | ما يفعله | الافتراضي |
|---|---|---|
| **Folder-tree root** (جذر شجرة المجلدات) | المجلد الذي تبدأ منه شجرة **FOLDERS** (المجلدات). اكتب مسارًا أو الصقه (يُسمح بـ`~`)، أو استخدم **Browse…** (استعراض). اجعله محدودًا — مجلد تسجيلاتك، لا مجلد المنزل كله | قيمة افتراضية مدمجة، وإلا فمجلد المنزل |
| **Skip forward / back (seconds)** (التخطي للأمام / للخلف بالثواني) | مقدار قفز زرّي الرجوع/التقديم العريضين، و**←**/**→** و**Ctrl+←**/**Ctrl+→** | 10 |
| **Bookmark rewind (seconds)** (رجوع العلامة بالثواني) | كم إلى الوراء توضع العلامة الجديدة (ويرجع التشغيل) | 5 |
| **Waveform limit (MB)** (حدّ الموجة بالميغابايت) | الملفات الأكبر من هذا لا يُرسم لها شكل موجي. 0 = بلا حد | 10 |
| **Sleep timer** (مؤقّت النوم) ← **Show the sleep timer** (إظهار مؤقّت النوم) | إظهار قائمة **Sleep** (النوم) بجانب مستوى الصوت | معطّل |
| **Sleep presets (minutes)** (مُدد النوم الجاهزة بالدقائق) | الأوقات التي يعرضها مؤقّت النوم، مفصولة بفواصل | `15, 30, 45, 60` |

يمكنك أيضًا تغيير المجلد الجذر للشجرة بزر ⚙ فوقها.

## ما يُحفظ تلقائيًا { #remembered-automatically }

لا تحتاج إلى حفظ هذه — المشغّل يحتفظ بها لك:

- السمة الفاتحة أو الداكنة (**Ctrl+T**)
- سرعة التشغيل ومستوى الصوت
- حجم النافذة وأحجام كل اللوحات
- ترتيب أعمدة قائمة التشغيل
- آخر مجلد حمّلته وآخر ملف شغّلته
- موضعك في كل ملف (للاستئناف)
- الملفات المشغّلة مؤخرًا والمعلَّمة مؤخرًا

## ملف الإعدادات { #the-config-file }

يُخزَّن كل شيء في `config.json` **بجانب البرنامج**. أغلق المشغّل قبل تحريره يدويًا. حذفه يعيد
المشغّل إلى إعداداته الافتراضية — ولا تتأثر علاماتك المرجعية، لأنها موجودة في ملفات `.tmk` بجانب
تسجيلاتك.

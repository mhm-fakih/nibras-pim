# المكتبة

الجزءان الأيسر والعلوي من النافذة مخصّصان لإيجاد ما تشغّله: شجرة مجلدات، وشريط موقع، ومتصفّح من ثلاثة
أعمدة، وقائمة التشغيل.

## تصفّح المجلدات { #browse-folders }

تبدأ شجرة **FOLDERS** (المجلدات) من **المجلد الجذر** — اضبطه في [الإعدادات](settings.md) أو بزر ⚙
فوق الشجرة. إن لم يكن المجلد موجودًا، تعود الشجرة إلى مجلد المنزل.

- لا تُدرج إلا المجلدات التي تحتوي وسائط في مكان ما بداخلها، فتبقى مجلدات الملاحظات أو المستندات
  بعيدة عن الطريق.
- توسيع مجلد لا يحمّل شيئًا أبدًا؛ **انقر نقرًا مزدوجًا** عليه لتحميله إلى المكتبة.
- التحميل يقرأ المجلد **وكل مجلداته الفرعية**. يعرض شريط الحالة في الأسفل مؤشر انتظار أثناء العمل،
  ثم عدد الملفات التي وُجدت.

زر المجلد في شريط العنوان ينقل تركيز لوحة المفاتيح إلى شجرة المجلدات.

## الانتقال إلى مسار { #go-to-a-path }

يقبل حقل **Go to path…** (انتقل إلى مسار) فوق الشجرة (**Ctrl+L**) مسارًا مكتوبًا أو ملصوقًا. اضغط
**Enter** أو انقر السهم:

| ما تُدخله | ما يحدث |
|---|---|
| مجلد | يُحدَّد في الشجرة ويُحمَّل |
| ملف وسائط | يُحمَّل مجلده ويبدأ تشغيل الملف |
| أي ملف آخر (مثل `.srt`) | يُحمَّل مجلده |
| شيء غير موجود | يتحوّل الحقل إلى الأحمر ويخبرك المشغّل بذلك |

يمكن أن تكون المسارات بين علامتي اقتباس، أو تبدأ بـ`~`، أو تحتوي `$VARIABLES`، أو تكون روابط
`file://`. وأثناء الكتابة، تُقترح المجلدات الفرعية المطابقة للإكمال.

## التضييق: الأنواع والفنانون والألبومات { #narrow-down-genres-artists-albums }

تعمل الأعمدة الثلاثة فوق قائمة التشغيل كمكتبة موسيقى تقليدية: اختر نوعًا لتضييق الفنانين، وفنانًا
لتضييق الألبومات، وتتبعها قائمة التشغيل. تُقرأ الوسوم من الملفات نفسها عند تحميل المجلد.

**Untagged only** (غير الموسومة فقط) (أعلى اليمين) يعرض فقط الملفات التي ليس لها نوع أو فنان أو
ألبوم — وهو مفيد [لوسم مجلد كامل دفعة واحدة](tag-editing.md#tag-a-whole-folder).

## قائمة التشغيل { #the-playlist }

| العمود | يعرض |
|---|---|
| **#** | رقم المقطع |
| **Title** (العنوان) | وسم العنوان، أو اسم الملف |
| **Artist** (الفنان)، **Album** (الألبوم) | من وسوم الملف |
| **Length** (المدة) | المدة |
| **Bkm** (العلامات) | عدد [العلامات المرجعية](bookmarks.md) في الملف |

- **انقر** مقطعًا لتشغيله. تصبح قائمة التشغيل كما تظهر حاليًا قائمة الانتظار لـ**Previous track**
  (المقطع السابق) / **Next track** (المقطع التالي).
- **Enter** يشغّل الصف المحدد.
- انقر رأس عمود للفرز؛ واسحب الرؤوس لإعادة ترتيبها. يُحفظ الترتيب.
- يظهر المقطع قيد التشغيل بخط عريض ويبقى ظاهرًا.

## عُلِّمت مؤخرًا { #recently-bookmarked }

تحت شجرة المجلدات، تسرد **RECENTLY BOOKMARKED** (عُلِّمت مؤخرًا) الملفات التي أضفت إليها علامات
مؤخرًا (الأحدث أولًا). انقر أحدها لتشغيله.

## الصيغ المدعومة { #supported-formats }

`.mp3` `.m4a` `.m4b` `.aac` `.ogg` `.oga` `.opus` `.flac` `.wav` `.wma` `.mka` `.webm` `.mp4`
`.m4v` `.mkv` `.mov` `.avi`

يعتمد تشغيل كل منها على إضافات GStreamer المثبّتة (انظر [التثبيت](index.md#install)).

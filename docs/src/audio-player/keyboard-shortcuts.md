# Keyboard shortcuts

Shortcuts with **Ctrl** work everywhere — even while you're typing a bookmark label or editing a
transcript. The plain-key shortcuts only work when you're **not** typing in a text field.

## Playback

| Keys | Action |
|---|---|
| **Space** · **Ctrl+Space** | Play / pause |
| **←** · **Ctrl+←** | Skip back (by the **Skip forward / back** time) |
| **→** · **Ctrl+→** | Skip forward |

## Bookmarks

| Keys | Action |
|---|---|
| **B** · **Ctrl+B** | Add a bookmark (a few seconds back, and replay from there) |
| **N** | Jump to the bookmark label field |
| **Enter** (in the label field) | Add a bookmark with that label |
| **Enter** (editing a label in the list) | Save the label |

## Files and window

| Keys | Action |
|---|---|
| **Ctrl+O** | Open a media file |
| **Ctrl+L** | Go to the **Go to path…** field |
| **Ctrl+S** | Save transcript edits now (they also save by themselves) |
| **Ctrl+Delete** | Move the playing file to the Trash (asks first) |
| **Ctrl+T** | Toggle light / dark theme |
| **Ctrl+,** | Settings |
| **Ctrl+Q** | Quit |
| **Esc** | Leave a text field (back to the playlist) |
| **Enter** (in the playlist) | Play the selected track |

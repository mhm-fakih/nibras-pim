# التشغيل

تضمّ لوحة **PLAYER** (المشغّل) كل ما يخص الملف قيد التشغيل.

## افتح شيئًا لتشغيله { #open-something-to-play }

- انقر مقطعًا في قائمة التشغيل (انظر [المكتبة](library.md)).
- اضغط **Ctrl+O** (أو زر الفتح في شريط العنوان) واختر ملفًا.
- الصق مسار ملف في **Go to path…** (انتقل إلى مسار) (**Ctrl+L**) واضغط **Enter**.
- شغّل المشغّل مع ملف: `./run.sh ~/Music/talk.mp3`.
- انقر ملفًا تحت **RECENTLY BOOKMARKED** (عُلِّمت مؤخرًا).

عندما تفتح ملفًا بمفرده (لا من قائمة التشغيل)، تصبح ملفات الوسائط الأخرى في مجلده هي قائمة الانتظار،
مرتّبةً حسب الاسم.

## أزرار التحكم { #controls }

من الأعلى إلى الأسفل:

| عنصر التحكم | ما يفعله |
|---|---|
| منطقة الفيديو | تظهر فقط للملفات التي تحتوي فيديو |
| حقل **Title** (العنوان) وزر سلة المهملات | عنوان الملف — عدّله واضغط **Enter** لحفظه وسمًا (انظر [تحرير الوسوم](tag-editing.md)). مرّر المؤشر فوقه لرؤية اسم الملف. زر سلة المهملات ينقل الملف إلى سلة المهملات |
| شارتا الترجمات / النص المفرّغ | تظهران حين يكون للملف ترجمات أو نص — انظر [الترجمات والنصوص المفرّغة](subtitles-and-transcripts.md) |
| شريط التقديم الموجي | انقر أو اسحب للانتقال؛ تظهر العلامات كعلامات صغيرة |
| الأوقات | المنقضي والمتبقي والإجمالي |
| أزرار النقل | **Previous track** (المقطع السابق)، رجوع، **Play / Pause** (تشغيل / إيقاف مؤقت)، تقديم، **Next track** (المقطع التالي) |
| حقل العلامة و**＋ Bookmark** (إضافة علامة) | انظر [العلامات المرجعية](bookmarks.md) |
| **Speed** (السرعة) | من 0.75× إلى 1.25×، دون تغيير طبقة الصوت |
| **Sleep** (النوم) | إيقاف مؤقت بعد مدة محددة (فقط عند تفعيله في الإعدادات) |
| **Vol** (مستوى الصوت) | من 0 إلى 3× — ما فوق العلامة الوسطى يرفع صوت التسجيلات الخافتة |

زرّا الرجوع والتقديم العريضان ينتقلان بمقدار وقت **Skip forward / back** (التخطي للأمام / للخلف)
(10 ثوانٍ افتراضيًا؛ غيّره في [الإعدادات](settings.md)).

## شريط التقديم الموجي { #the-waveform-seek-bar }

يُرسم شريط التقديم فوق منحنى ارتفاع صوت التسجيل: تظهر المقاطع العالية كأعمدة طويلة، وتبقى الهادئة
مسطّحة، ويُلوَّن الجزء الذي شُغِّل. إنها طريقة سريعة لمعرفة أين يبدأ أحدهم بالكلام، أو لتخطي صمت طويل.

يُحسب الشكل الموجي في الخلفية بعد فتح الملف، فلا ينتظره التشغيل أبدًا. وفي الملفات الكبيرة جدًا
يُتخطّى — ويخبرك المشغّل بذلك — لأنه يحتاج إلى قراءة الملف كله. ارفع الحد أو أزله عبر
**Waveform limit (MB)** (حدّ الموجة بالميغابايت) في [الإعدادات](settings.md).

## الاستئناف من حيث توقفت { #resume-where-you-left-off }

يتذكّر المشغّل موضعك في كل ملف استمعت إليه أكثر من بضع ثوانٍ. افتح الملف مجددًا فيتابع من هناك.
وعند البدء التالي، يُفتح آخر ملف شغّلته مرة أخرى، متوقفًا مؤقتًا.

## نهاية الملف { #end-of-file }

عندما ينتهي ملف، **يتوقف** المشغّل. لا ينتقل تلقائيًا إلى التسجيل التالي — اضغط **Next track** أو
انقر التالي في قائمة التشغيل حين تكون جاهزًا.

## مؤقّت النوم { #sleep-timer }

يبقى مؤقّت النوم مخفيًا حتى تفعّل **Sleep timer** (مؤقّت النوم) في [الإعدادات](settings.md). عندها
تظهر قائمة **Sleep** بجانب مستوى الصوت: اختر مدة (15 أو 30 أو 45 أو 60 دقيقة افتراضيًا) فيتوقف
التشغيل مؤقتًا حين تنتهي. اختر **Off** (إيقاف) للإلغاء.

## نقل ملف إلى سلة المهملات { #move-a-file-to-the-trash }

اضغط **Ctrl+Delete** أو زر سلة المهملات بجانب العنوان، وأكّد بـ**Move to Trash** (نقل إلى سلة
المهملات). ينتقل الملف وعلاماته `.tmk` إلى سلة مهملات سطح المكتب (فيمكنك استعادتها)، وينتقل المشغّل
إلى الملف التالي في قائمة الانتظار.

## الفاتح والداكن { #light-and-dark }

**Ctrl+T** أو زر القمر في شريط العنوان يبدّل بين السمة الفاتحة (الافتراضية) والداكنة.

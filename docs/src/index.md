# Nibras

**Nibras** is a personal knowledge ecosystem that lives in your own files, not in someone else's
cloud. Notes are plain-text Markdown files in one folder. Five apps read and write that same folder,
each fitted to a different moment of the day — and an optional server turns the captures you choose
into structured records (tasks, journal entries, goals, writings, resources…).

- **One folder of plain text.** Every note is a `.md` file whose *name* carries its tags. Any
  editor can open it; any file-sync tool can copy it.
- **Five clients, one format.** Phone, browser, desktop, terminal and audio player all agree on the
  same file names and sidecar files, byte for byte.
- **Works offline.** Capturing, tagging, searching and bookmarking never need a network.
  Anything bound for the server waits in a queue until it is reachable.
- **The server is optional.** Without it you have a fast, portable note system. With it you also
  get records, reports, a calendar and a shared vocabulary of types and categories.

## The apps

| App | Runs on | What it is for |
|-----|---------|----------------|
| [knotes for Android](mobile/index.md) | Phone | Quick capture, the media player with bookmarks, widgets, reminders, and an offline view of your server records. |
| [Nibras web app](web/index.md) | Browser + server | The full record system: tasks, journals, goals, writings, resources, reports — plus importing notes from the folder. |
| [knotes desktop](desktop/index.md) | Linux / Windows (GTK) | A keyboard-driven board for capturing, triaging, merging and attaching files to notes. |
| [knotes terminal](terminal/index.md) | Any terminal | One-line note entry and quick server reports, without leaving the shell. |
| [Audio player](audio-player/index.md) | Linux (GTK) | A desktop audio & video player whose bookmarks are shared with the phone. |

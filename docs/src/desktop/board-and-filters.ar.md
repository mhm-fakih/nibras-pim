# اللوحة والشريط الجانبي والمرشحات

وسط النافذة هو **اللوحة**: بطاقة واحدة لكل ملاحظة. وعلى الحافة اليسرى يقع **الشريط الجانبي
للمرشحات**، أما شريط الأدوات في الأعلى فيبدّل طرق العرض وترتيب الفرز.

## طرق العرض { #views }

تحدد أزرار العرض في شريط الأدوات طريقة ترتيب اللوحة. ويُحفظ اختيارك.

| العرض | ما تراه |
|---|---|
| **Kanban** (كانبان) | عمود لكل فئة، مع تجميع حسب النوع داخل كل عمود. انقر عنوان نوع لطيّه. لا تحصل على عمود إلا الفئات التي لها ملاحظات. تتوزع الأعمدة على 1–3 صفوف (**Kanban rows** — صفوف كانبان — في الإعدادات). |
| **Simple list** (قائمة بسيطة) | كل الملاحظات في عمود واحد، الأقدم في الأعلى والأحدث في الأسفل. |
| **Columns** (أعمدة) | القائمة نفسها ملفوفة في أكبر عدد من الأعمدة يتسع له عرض النافذة. يحدّ **Card max width** (أقصى عرض للبطاقة) في الإعدادات من عرض البطاقة. |
| **Week calendar** (التقويم الأسبوعي) | ملاحظات اليوميات (**J**) والتخطيط (**P**) مرتّبة على أسبوع، في خاناتها الزمنية. راجع [التقويم الأسبوعي](#week-calendar). |
| **Minimal** (مصغّر) | اللوحة مخفية — فقط آخر ملاحظة والحقل النصي (**Ctrl+L**). راجع [كتابة الملاحظات](writing-notes.md#minimal-side-note-mode). |

تنقّل بين البطاقات بـ**مفاتيح الأسهم**: ↑↓ داخل العمود، و←→ بين الأعمدة.

## ترتيب الفرز { #sort-order }

ترتّب قائمة الفرز في شريط الأدوات البطاقات:

| الخيار | الترتيب |
|---|---|
| **Last updated** (آخر تحديث) | حسب آخر تغيير للملف، والأحدث في الآخر (الافتراضي) |
| **Date created** (تاريخ الإنشاء) | حسب الطابع الزمني في اسم الملف، والأحدث في الآخر — ثابت أثناء إعادة الوسم |
| **Category** (الفئة) / **Type** (النوع) | بالترتيب الذي يعرّفه المجلد |
| **Priority** (الأولوية) | الأعلى أولًا |
| **Note length** (طول الملاحظة) | الأطول أولًا — مفيد لإيجاد الملاحظات التي كبرت أكثر من اللازم |

## قراءة البطاقة { #reading-a-card }

تعرض كل بطاقة:

- **النوع** و**الأولوية** و**الفئة** في هامش صغير على اليسار.
- نص الملاحظة، مع **السطر الأول بخط عريض**. تعرض الملاحظات الطويلة بدايتها ونهايتها (اضبط
  المقدارين بـ**Preview characters (head)** (أحرف المعاينة — البداية) و**(tail)** (النهاية) في
  الإعدادات). وتُلوَّن المقاطع المظلَّلة. ويأخذ كل سطر اتجاهه الخاص، فتُقرأ الأسطر العربية وتُحاذى
  من اليمين والإنجليزية من اليسار، حتى داخل الملاحظة الواحدة.
- وسوم `#hashtags` الخاصة بالملاحظة، مرة واحدة، ككلمات ملوّنة بعد السطر الأخير.
- **صف إجراءات**: **open folder** (فتح المجلد)، **open note** (فتح الملاحظة)، نسخ اسم الملف، نسخ
  المسار الكامل، الاستيراد إلى خادم Nibras، والحذف. مرّر المؤشر فوق زر لترى اختصاره.
- أعداد على الملاحظات الطويلة: الكلمات، والمقاطع المظلَّلة، و— إذا كانت للملاحظة تسجيلات — العلامات
  الزمنية من [ملفات العلامات `.tmk`](../concepts/bookmarks-tmk.md)، إضافة إلى عدد
  [ملفاتها المرفقة](attached-files.md)، مثلًا `1,204 words · 2 highlights · 4 time marks · 3 files`.
- تاريخان في طرف صف الإجراءات: متى **أُنشئت** الملاحظة (من اسم ملفها) ومتى **غُيّرت آخر مرة**.
  يتحول الثاني إلى البرتقالي بعد 3 أيام وإلى الأحمر بعد 7 — ملاحظة تواصل العودة إليها.

## شريط العنوان { #the-title-bar }

يعرض شريط العنوان إصدار التطبيق وعدد الملاحظات في المجلد:
`Nibras Notes v1.3.2.b57 · 412 notes · 3 to settle`.

- لا تُعدّ إلا **الملاحظات الحقيقية** — وهو العدد نفسه الذي يعرضه [تطبيق الطرفية](../terminal/index.md).
  أما الملفات المتفرقة التي تنتظر وسومًا فتُعدّ وحدها كـ **· N to settle** (بانتظار التسوية)، ويختفي
  هذا الجزء عند الصفر (راجع [طوابير التنظيف](#clean-up-queues)).
- حين يضيّق بحث أو مرشح اللوحة، يعرض الرقمين معًا: `12 / 412 notes`.
- حين تكون هناك بطاقات معلَّمة، يضيف تذكيرًا مثل `⛓ 3 marked — Ctrl+Shift+M to merge, Esc to clear`.

## البحث { #search }

اضغط **Ctrl+F** (أو زر العدسة)، واكتب، ثم اضغط **Enter**. تضيق اللوحة إلى الملاحظات التي:

- يحتوي **نصها** على ما كتبته،
- أو يحتوي **رمز نوعها أو فئتها** عليه،
- أو يحتوي **اسم ملفها** عليه — الصق اسمًا كاملًا لإيجاد ملاحظة واحدة، أو اكتب جزءًا من كتلة
  الوسوم مثل `N~p2` لعرض كل ملاحظة موسومة بذلك،
- أو تضم [**ملفاتها المرفقة**](attached-files.md) ملفًا أو مجلدًا في اسمه ما كتبته، على أي عمق.

المطابقة نصية بسيطة ولا تميّز حالة الأحرف. ويجري البحث على المجلد كله: الضغط على **Enter** يضع
مرشحات الشريط الجانبي جانبًا، ثم تعود حين ينتهي البحث. أفرغ المربع (أو اضغط **Esc**) لإنهاء
البحث ورؤية اللوحة كما كانت.

## ما الذي يصفّي اللوحة { #whats-filtering-the-board }

كلما ضيّق بحث أو مرشح اللوحة، يقول ذلك سطر فوق البطاقات — مثلًا
`4 of 8 │ Search "n~p2" │ Type N · Note │ Priority P2`. يفرغ زر **clear** (مسح) فيه مربع البحث
ويعيدك إلى عرض البدء (اليوم والأمس)؛ وانقره مرة أخرى لرؤية المجلد كله.

واللوحة الفارغة تقول دائمًا السبب: **No notes entered today or yesterday** (عرض البدء)،
أو **No notes entered today**، أو **No note's text, file name or attached file name contains “…”**،
أو **No notes match the filters**، أو **No notes in this folder yet**.

## الشريط الجانبي للمرشحات { #the-filter-sidebar }

اضغط **Ctrl+B** لإظهار الشريط الجانبي أو إخفائه. عند إخفائه يتقلص إلى شريط رفيع باسم **FILTERS**
(المرشحات) يظل يعرض عدد المرشحات النشطة. اسحب حافته اليمنى لتوسيعه أو تضييقه؛ ويُحفظ عرضه.

يعرض كل خيار **عدد الملاحظات التي تقف وراءه**. والأعداد *متعددة الأوجه*: كل رقم يخبرك
كم ملاحظة ستراها لو اخترت هذا الخيار أيضًا، مع مراعاة مرشحاتك الأخرى
ومربع البحث.

### الأقسام { #sections }

من الأعلى إلى الأسفل:

| القسم | ما يفعله |
|---|---|
| **Calendar** (التقويم) | عرض شهري — كل يوم فيه ملاحظات يظهر رقمه بخط عريض. انقر يومًا للتصفية عليه؛ و**Shift+نقرة** على يوم آخر لاختيار نطاق. تُملأ الأيام المختارة بلون التمييز. |
| **Type** / **Priority** / **Category** | جنبًا إلى جنب: النوع فوق الأولوية في عمود، والفئات في العمود الآخر (تُقرأ الأسماء العربية من اليمين). كل خيار يعرّفه المجلد، إضافة إلى أي رموز غير معروفة تستخدمها الملاحظات فعلًا (بـ*خط مائل كهرماني*). اختر واحدًا أو أكثر. |
| **Non-standard** (غير قياسي) | **Include** (تضمين) / **Hide** (إخفاء) / **Only** (فقط) — الملفات والمجلدات المتفرقة التي ليست ملاحظات صحيحة بعد. |
| **Bad taxonomy** (تصنيف خاطئ) | **Include** / **Hide** / **Only** — الملاحظات التي لا يعرّف المجلد رموزها. |
| **Tags** (الوسوم) | سحابة من `#hashtags` المستخدمة في نصوص الملاحظات، يتناسب حجمها مع عدد مرات ظهورها. انقر واحدًا لعرض الملاحظات التي تحمله فقط (وسم واحد في كل مرة). يُخفى إن لم تحتوِ أي ملاحظة على هاشتاغ. |

للتقويم مفتاح **Created** (الإنشاء) / **Updated** (التحديث). يستخدم **Created** التاريخ الموجود في
اسم ملف الملاحظة، فلا تنقل إعادة الوسم الملاحظة في الزمن أبدًا. ويستخدم **Updated** تاريخ آخر
تغيير للملف — أي عرض "متى عدت إلى هذا". مرّر المؤشر فوق يوم لترى الرقمين. وتحت الشهر يوجد
**Today** (اليوم — للعودة إلى هذا الشهر) و**Clear days** (مسح الأيام — للعودة إلى اليوم والأمس؛
وانقره مرة أخرى لكل الأيام).

يعيدك **Clear all filters** (مسح كل المرشحات) أسفل الشريط الجانبي إلى عرض البدء؛ وانقره مرة
أخرى لرؤية المجلد كله. تُطوى الأقسام كلٌّ على حدة، ويُحفظ التخطيط.

!!! note "عرض البدء"
    يُفتح التطبيق على **اليوم والأمس**، مع إخفاء العناصر غير القياسية — أوقف ذلك بـ
    **Open filtered to today's and yesterday's notes** و**Hide non-standard items by default**
    في [الإعدادات](settings.md). ولا تُحفظ الاختيارات الأخرى من تشغيل إلى آخر، فلا تبدأ يومك أبدًا
    بمرشح قديم. وخلال الجلسة الواحدة، **يحتفظ كل مجلد ملاحظات بمرشحاته**: الانتقال إلى مجلد آخر
    ثم العودة يعيدها، والمجلد الذي لم تزره بعد يُفتح على عرض البدء.

### طوابير التنظيف { #clean-up-queues }

يوجد قسمان لمساعدتك على الترتيب:

- **Non-standard ← Only** يعرض الملفات والمجلدات في مجلد الملاحظات التي لا يتبع اسمها
  صيغة `<timestamp>~<type>~p<n>~<category>.md` — أشياء أسقطتها ولا تزال تحتاج إلى وسوم.
  وتُدرج دائمًا تحت *اليوم* في التقويم إلى أن تسوّيها. راجع
  [تسوية الملفات المتفرقة](organizing-notes.md#settle-loose-files). (هي مخفية افتراضيًا، فاختر
  **Include** أو **Only** لرؤيتها.)
- **Bad taxonomy ← Only** يعرض الملاحظات ذات الاسم السليم لكن برمز لا يعرّفه المجلد.
  اختر واحدة وأعد وسمها بـ**Ctrl+Shift+<code>**.

يعرض شريط العنوان المتراكم، مثلًا `412 notes · 3 to settle`، أيًّا كانت المرشحات. والملفات أو
المجلدات التي تنتمي إلى مجلد الملاحظات لكنها ليست ملاحظات — سكربت، أو مجلد موقع — يمكن
إخراجها من هذا العدد نهائيًا عبر **Note folders: leave out (one path per line)** في
[الإعدادات](settings.md).

## التقويم الأسبوعي { #week-calendar }

يعرض زر التقويم في مجموعة العرض أسبوعًا كما تفعل المفكرة المكتبية: سبعة أعمدة للأيام، تبدأ
بالاثنين، في خانات من نصف ساعة. كل ملاحظة **يوميات (J)** و**تخطيط (P)** في المجلد تقع في الخانة
التي يقع فيها وقت اسم ملفها — بما في ذلك الملاحظات المكتوبة من نموذج الإضافة أو على الهاتف أو
يدويًا. يعرض كل مُدخل وقته وأول سطرين من عنوانه؛ ومرّر المؤشر فوقه لقراءة الملاحظة كاملة.

| لكي… | افعل هذا |
|---|---|
| تغيّر الأسبوع | **‹** / **›** أو **Ctrl+PgUp** / **Ctrl+PgDn**؛ ويعيدك **Today** إلى هذا الأسبوع |
| تضيف مُدخلًا | انقر خانة فارغة. يُفتح نموذج **New calendar entry** (مُدخل تقويم جديد) باليوم والوقت (وكلاهما قابل للتعديل)، والنوع **Journal** (يوميات) لخانة ماضية أو **Planner** (تخطيط) لخانة قادمة، والأولوية والفئة والنص. يحفظ **Ctrl+Enter**. |
| تنقل مُدخلًا | اسحبه إلى خانة أخرى |
| تعدّل مُدخلًا | انقره نقرًا مزدوجًا لتغيير تاريخه أو وقته أو نوعه أو وسومه أو نصه |
| تقرأه أو تحرّره في اللوحة الجانبية | انقره (وتتنقل مفاتيح الأسهم بين المُدخلات كما بين البطاقات) |

تُحفظ الملاحظة بوقت الخانة بدل "الآن"، فتقع يوميات الأمس في الأمس. ونقل مُدخل لا يفعل سوى إعادة
تسمية الملف — فالوقت في اسمه — وتنتقل معه ملفاته المرفقة. وليس للمُدخلات وقت انتهاء. يضيّق
مربع البحث الأسبوع؛ أما مرشحات الشريط الجانبي فلا تنطبق عليه.

## شريط الهاشتاغ { #hashtag-strip }

تحت الحقل النصي، يعرض شريط من سطر واحد كل هاشتاغ في المجلد مع عدده. أوقف
**List every #hashtag under the add field** (عرض كل هاشتاغ تحت حقل الإضافة) في الإعدادات لعرض مجموع مختصر فقط بدلًا من ذلك.

## التحديث { #refresh }

تتحدّث اللوحة من تلقاء نفسها عند تغيّر الملفات على القرص — مثلًا عندما تجلب أداة مزامنة
ملاحظات من جهاز آخر. ويعيد **Ctrl+R** (أو زر التحديث) قراءة المجلد عند الطلب.

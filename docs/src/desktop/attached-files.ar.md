# الملفات المرفقة

يمكن إرفاق ملفات بأي ملاحظة — ملف PDF، أو صور، أو تسجيل، أو مخطط. وهي تعيش في
**المجلد المرافق** للملاحظة: مجلد بجوار الملاحظة يحمل الاسم نفسه مع إضافة `.d`.

```
~/Knotes/
├── 2026_06_10-143025~N~p2~F.md
└── 2026_06_10-143025~N~p2~F.d/
    ├── receipt.pdf
    └── talk.mp3
```

ولأنه مجرد مجلد، تضيف الملفات بمدير الملفات المعتاد لديك، وتنقلها معها أي أداة مزامنة.
راجع [المجلدات المرافقة](../concepts/companion-folders.md) لفهم الفكرة من ورائها.

## إرفاق ملفات بملاحظة { #attach-files-to-a-note }

من التطبيق:

1. اختر بطاقة الملاحظة، وافتح اللوحة الجانبية (**Ctrl+E**) إن كانت مغلقة.
2. في لوحة **Files** (الملفات) تحت الملاحظة، انقر **add files…** (إضافة ملفات…) واختر الملفات —
   أو اسحبها من مدير الملفات وأفلتها على اللوحة.

تُنسخ الملفات إلى المجلد المرافق، الذي يُنشأ لحظة وصول أول ملف.

من مدير الملفات:

1. اختر بطاقة الملاحظة.
2. اضغط **Ctrl+O**، أو انقر **open folder** (فتح المجلد) على البطاقة.
3. يُنشأ المجلد المرافق (إن لم يكن موجودًا بعد) ويُفتح في مدير الملفات.
   أسقط ملفاتك فيه.

لنقل أشياء من مجلد التنزيلات إلى ملاحظة **جديدة**، أشّر عليها في
[قائمة الوارد](writing-notes.md#the-inbox-file-downloads-into-a-note) قبل حفظ الملاحظة.

!!! tip "جلسات التدوين"
    فعّل زر المجلد في شريط الأدوات (**Auto-open the note's files folder after each
    save** — فتح مجلد ملفات الملاحظة تلقائيًا بعد كل حفظ). عندها تفتح كل ملاحظة تحفظها مجلدها المرافق فورًا، جاهزًا للملفات.

## لوحة الملفات { #the-files-panel }

تقع لوحة **Files** (الملفات) تحت الملاحظة في اللوحة الجانبية (**Ctrl+E**) وتعرض المجلد المرافق
للملاحظة المحددة — المجلدات أولًا، ثم الملفات بأحجامها. انقر صفًّا لفتحه بالتطبيق الافتراضي في
نظامك. ويفتح **open folder** (فتح المجلد) المجلد كله في مدير الملفات (**Ctrl+O**). والملاحظة التي
لا ملفات لها تعرض **No files yet — add some, or drop them here** (لا ملفات بعد — أضف بعضها أو
أفلتها هنا)؛ ومجرد النظر إلى ملاحظة لا يُنشئ مجلدًا فارغًا أبدًا.

أما على اللوحة، فيعدّ صف إجراءات البطاقة الملفات بدلًا من ذلك، مثلًا `· 3 files`.

## إيجاد ملاحظة من ملفاتها { #find-a-note-by-its-files }

يطابق [البحث](board-and-filters.md#search) أيضًا أسماء الملفات والمجلدات داخل المجلد المرافق لكل
ملاحظة، على أي عمق — اكتب جزءًا من اسم ملف PDF أو تسجيل لتجد الملاحظة التي ينتمي إليها.

## ما الذي يحدث للملفات عندما… { #what-happens-to-the-files-when-you }

| الإجراء | الملفات المرفقة |
|---|---|
| إعادة وسم الملاحظة | يُعاد تسمية المجلد مع الملاحظة |
| دمج الملاحظات | تنتقل كل الملفات المرفقة إلى مجلد الملاحظة الباقية، وتُدرج أسماء ملفات كل جزء تحت نصه |
| حذف الملاحظة | غير مسموح ما دام المجلد يحتوي ملفات — أفرغه أولًا |

!!! warning "حذف ملاحظة لها ملفات"
    يرفض التطبيق حذف ملاحظة ما زالت لها ملفات مرفقة، حتى لا تنتهي منسية
    في مجلد مخفي. يكون زر الحذف معطّلًا في مثل هذه البطاقات، ويشرح **Ctrl+D** السبب.
    انقل الملفات أو احذفها أولًا (يفتح **Ctrl+O** المجلد)، ثم احذف الملاحظة.

## التسجيلات والعلامات الزمنية { #recordings-and-time-marks }

إذا احتوى مجلد مرافق على ملفات علامات `.tmk` (يكتبها
[مشغّل الصوت](../audio-player/index.md) أو الهاتف)، تعرض الملاحظات الطويلة عدد **time marks** (العلامات الزمنية) على
بطاقاتها. راجع [العلامات (.tmk)](../concepts/bookmarks-tmk.md).

# الملفات المرفقة

يمكن إرفاق ملفات بأي ملاحظة — ملف PDF، أو صور، أو تسجيل، أو مخطط. وهي تعيش في
**المجلد المرافق** للملاحظة: مجلد بجوار الملاحظة يحمل الاسم نفسه مع إضافة `.d`.

```
~/Knotes/
├── 2026_06_10-143025~N~p2~F.md
└── 2026_06_10-143025~N~p2~F.d/
    ├── receipt.pdf
    └── talk.mp3
```

ولأنه مجرد مجلد، تضيف الملفات بمدير الملفات المعتاد لديك، وتنقلها معها أي أداة مزامنة.
راجع [المجلدات المرافقة](../concepts/companion-folders.md) لفهم الفكرة من ورائها.

## إرفاق ملفات بملاحظة { #attach-files-to-a-note }

1. اختر بطاقة الملاحظة.
2. اضغط **Ctrl+O**، أو انقر **open folder** (فتح المجلد) على البطاقة.
3. يُنشأ المجلد المرافق (إن لم يكن موجودًا بعد) ويُفتح في مدير الملفات.
   أسقط ملفاتك فيه.

يتحدّث صف 📎 في البطاقة عند التحديث التالي.

!!! tip "جلسات التدوين"
    فعّل زر المجلد في شريط الأدوات (**Auto-open the note's files folder after each
    save** — فتح مجلد ملفات الملاحظة تلقائيًا بعد كل حفظ). عندها تفتح كل ملاحظة تحفظها مجلدها المرافق فورًا، جاهزًا للملفات.

## فتح الملفات المرفقة { #open-attached-files }

يعرض صف 📎 في البطاقة أسماء ما يصل إلى خمسة ملفات. انقر اسمًا لفتح ذلك الملف بالتطبيق
الافتراضي في نظامك. انقر **…** في آخر الصف أو العدد لفتح المجلد كله؛ ومرّر المؤشر فوقه لرؤية أسماء
كل الملفات.

## ما الذي يحدث للملفات عندما… { #what-happens-to-the-files-when-you }

| الإجراء | الملفات المرفقة |
|---|---|
| إعادة وسم الملاحظة | يُعاد تسمية المجلد مع الملاحظة |
| دمج الملاحظات | تنتقل كل الملفات المرفقة إلى مجلد الملاحظة الباقية |
| حذف الملاحظة | غير مسموح ما دام المجلد يحتوي ملفات — أفرغه أولًا |

!!! warning "حذف ملاحظة لها ملفات"
    يرفض knotes حذف ملاحظة ما زالت لها ملفات مرفقة، حتى لا تنتهي منسية
    في مجلد مخفي. يكون زر الحذف معطّلًا في مثل هذه البطاقات، ويشرح **Ctrl+D** السبب.
    انقل الملفات أو احذفها أولًا (يفتح **Ctrl+O** المجلد)، ثم احذف الملاحظة.

## التسجيلات والعلامات الزمنية { #recordings-and-time-marks }

إذا احتوى مجلد مرافق على ملفات علامات `.tmk` (يكتبها
[مشغّل الصوت](../audio-player/index.md) أو الهاتف)، تعرض الملاحظات الطويلة عدد **time marks** (العلامات الزمنية) على
بطاقاتها. راجع [العلامات (.tmk)](../concepts/bookmarks-tmk.md).

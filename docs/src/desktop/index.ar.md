# knotes لسطح المكتب

**knotes لسطح المكتب** تطبيق صغير لتدوين الملاحظات يعتمد على لوحة المفاتيح أولًا، لنظام Linux (وWindows). تكتب
فكرتك، وتختار النوع والأولوية والفئة، ثم تضغط **Ctrl+Enter** — فتُحفظ كملف Markdown عادي في مجلد
تختاره أنت. لا قاعدة بيانات، ولا حساب، ولا ارتباط بمنصة بعينها.

السر في اسم الملف: وسوم كل ملاحظة مكتوبة في اسمها، هكذا

```
2026_06_10-143025~W~p3~A.md
```

لذلك يعمل المجلد نفسه دون أي تغيير مع [تطبيق knotes للجوال](../mobile/index.md)
و[تطبيق الطرفية](../terminal/index.md) وخادم Nibras. زامن المجلد بين أجهزتك بأي أداة لمزامنة
الملفات، وسترى كل التطبيقات الملاحظات نفسها.

!!! tip "جديد على الأفكار التي يقوم عليها knotes؟"
    اقرأ أولًا [ملاحظات بنص عادي](../concepts/plain-text-notes.md) و
    [أسماء الملفات والوسوم](../concepts/filenames-and-tags.md) — فهما يشرحان نظام تسمية الملفات
    الذي بُني عليه هذا التطبيق.

## ما الذي يمكنك فعله { #what-you-can-do }

- **التدوين السريع** — حقل نصي في الأسفل، ووسوم ثابتة، وحفظ بمفتاح واحد.
  راجع [كتابة الملاحظات](writing-notes.md).
- **الوسم بالنوع والأولوية والفئة** من لوحة المفاتيح، وإعادة وسم عدة ملاحظات متتالية.
  راجع [النوع والأولوية والفئة](tagging.md).
- **التصفح والتصفية** في عرض كانبان أو قائمة أو أعمدة، مع خريطة حرارية للتقويم وسحابة وسوم
  وأعداد حية. راجع [اللوحة والشريط الجانبي والمرشحات](board-and-filters.md).
- **إرفاق ملفات** بالملاحظة في مجلدها المرافق الخاص. راجع [الملفات المرفقة](attached-files.md).
- **دمج الملاحظات والملفات المتفرقة وحذفها وتسويتها** بأمان. راجع
  [تنظيم الملاحظات](organizing-notes.md).
- **البقاء متوافقًا مع رموز الوحدات والأقسام في خادم Nibras**. راجع
  [الاتصال بخادم Nibras](nibras-server.md).

## التثبيت { #install }

knotes لسطح المكتب برنامج مكتوب بلغة Python 3 ويستخدم GTK 3. لا شيء يحتاج إلى تصريف — كل ما تحتاجه
هو Python وروابط GTK ‏(PyGObject).

=== "Debian / Ubuntu / Mint"

    ```bash
    sudo apt install python3-gi gir1.2-gtk-3.0
    ```

=== "Fedora"

    ```bash
    sudo dnf install python3-gobject gtk3
    ```

=== "Arch"

    ```bash
    sudo pacman -S python-gobject gtk3
    ```

=== "Windows"

    لا يحتوي Windows على GTK مثبّت في النظام، لذا ثبّته عبر [MSYS2](https://www.msys2.org/). في
    صدفة **MSYS2 UCRT64**:

    ```bash
    pacman -S mingw-w64-ucrt-x86_64-python \
              mingw-w64-ucrt-x86_64-python-gobject \
              mingw-w64-ucrt-x86_64-gtk3 \
              mingw-w64-ucrt-x86_64-librsvg
    ```

    لا حاجة إلى `librsvg` إلا لأيقونة النافذة. (يعمل أيضًا تثبيت `pygobject` باستخدام `pip`،
    لكن فقط إذا كانت بيئة تشغيل GTK 3 موجودة مسبقًا في `PATH` — وMSYS2 هو الطريق الأسهل.)

ثم ضع مجلد `desktop/` حيث تحب أن تحفظ برامجك.

## التشغيل { #run }

=== "Linux"

    ```bash
    cd desktop
    ./run.sh
    ```

    يتحقق `run.sh` من توفر GTK ويخبرك بما يجب تثبيته إن لم يكن متوفرًا. يمكنك أيضًا
    تشغيله مباشرة باستخدام `python3 knotes.py`.

    **مدخل في القائمة وتثبيت في اللوحة.** شغّل `./install.sh` مرة واحدة. فهو يضيف **knotes** إلى
    قائمة التطبيقات؛ شغّله من هناك، ثم انقر بالزر الأيمن على أيقونته في اللوحة واختر **Pin** (تثبيت).
    أعد تشغيل `install.sh` إذا نقلت المجلد.

=== "Windows"

    انقر نقرًا مزدوجًا على `run.bat` (أو شغّله من صدفة). يفضّل `pythonw.exe`، فلا تبقى نافذة
    طرفية مفتوحة، ويعرض تلميحًا إذا كان Python أو GTK مفقودًا.

    لإضافة مدخل في قائمة ابدأ، انقر بالزر الأيمن على `run.bat` ← **Create shortcut** (إنشاء اختصار)،
    وأعطِ الاختصار أيقونة وانقله إلى `%APPDATA%\Microsoft\Windows\Start Menu\Programs`.

## التشغيل الأول { #first-run }

1. **اختر مجلد ملاحظاتك.** افتراضيًا تُحفظ الملاحظات في `~/knotes`. لاستخدام مجلد آخر، اضغط
   **Ctrl+,** لفتح **Settings** (الإعدادات) وعدّل **Note folders** (مجلدات الملاحظات)، مثلًا `A:~/Knotes`
   (على Windows: ‏`A:C:\Users\you\Knotes` — وتعمل `~` هناك أيضًا). راجع [الإعدادات](settings.md#note-folders).
2. **اكتب ملاحظة.** اكتب في الحقل الموجود في الأسفل واضغط **Ctrl+Enter**.
3. **انظر إلى النتيجة.** تظهر بطاقة على اللوحة، ويظهر في مجلدك ملف باسم مثل
   `2026_06_10-143025~N~p2~F.md`.

!!! note "اللوحة تُفتح على اليوم"
    افتراضيًا يبدأ التطبيق مُصفّى على ملاحظات **اليوم**، لذا يعرض يوم جديد الرسالة
    **No notes entered today** (لم تُدخل أي ملاحظات اليوم). انقر **Clear all filters** (مسح كل المرشحات) أسفل الشريط الجانبي لرؤية
    كل شيء، أو أوقف **Open filtered to today's notes** (الفتح مُصفّى على ملاحظات اليوم) في [الإعدادات](settings.md).

اضغط **F1** في أي وقت لعرض قائمة [اختصارات لوحة المفاتيح](keyboard-shortcuts.md).

## أين تُخزَّن الأشياء { #where-things-are-stored }

| ماذا | أين |
|---|---|
| ملاحظاتك | ملفات `.md` عادية في كل مجلد ملاحظات |
| الملفات المرفقة | مجلد `<note name>.d/` بجوار كل ملاحظة — راجع [الملفات المرفقة](attached-files.md) |
| الملاحظات المحذوفة والمدموجة | مجلدان مخفيان `.deleted/` و`.merged/` داخل مجلد الملاحظات |
| خيارات الوسوم لكل مجلد | ملف مخفي `.knotes.json` داخل كل مجلد ملاحظات |
| إعدادات التطبيق | `config.json` بجوار البرنامج |
| مفردات الوسوم (الهاشتاغ) | `tag-bank.md` بجوار البرنامج (أو مسار تختاره) |

## الاختلافات في Windows { #windows-differences }

كل شيء يعمل بالطريقة نفسها على Windows — أسماء الملفات، ومجلدات الصيانة المخفية، ومجلد
الملاحظات المُزامَن. لا يختلف إلا عدد قليل من عمليات التكامل مع النظام:

| | Linux | Windows |
|---|---|---|
| فتح ملاحظة (**Enter**) | المحرر الذي ضبطته، وإلا فالافتراضي في النظام | المحرر الذي ضبطته، وإلا فالتطبيق الافتراضي للملف |
| فتح مجلد ملفات الملاحظة (**Ctrl+O**) | Nemo (كتبويب جديد)، وإلا فمدير الملفات الافتراضي | Explorer، نافذة جديدة في كل مرة |
| التثبيت في اللوحة | عبر `install.sh` | ثبّت اختصار `run.bat` |

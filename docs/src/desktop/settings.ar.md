# الإعدادات

افتح **Settings** (الإعدادات) بـ **Ctrl+,** أو بزر الترس في شريط الأدوات. انقر **Save** (حفظ) لتطبيق
تغييراتك، أو **Cancel** (إلغاء) للتخلي عنها.

لنافذة الحوار ثلاثة أجزاء: إعدادات التطبيق العامة، وخادم Nibras الافتراضي، وخيارات الوسوم الخاصة
بالمجلد الذي كان نشطًا عند فتحها.

## إعدادات التطبيق العامة { #app-wide-settings }

### مجلدات الملاحظات { #note-folders }

**Note folders (code:path per line; * = active)** (مجلدات الملاحظات: `code:path` في كل سطر؛ `*` = النشط) — مجلد واحد في كل سطر بصيغة `code:path`. علّم
المجلد النشط بـ `*`. مثال:

```
A*:~/Knotes
B:~/Work-notes
```

مع وجود أكثر من مجلد، يظهر منتقٍ بجوار زر الإرسال، ويبدّل **Ctrl+1** … **Ctrl+9**
بينها. راجع [تنظيم الملاحظات](organizing-notes.md#several-note-folders).

### كل إعدادات التطبيق العامة { #all-app-wide-settings }

| الإعداد | ما يفعله | الافتراضي |
|---|---|---|
| **Timestamp format** (صيغة الطابع الزمني) | كيف تبدأ أسماء الملفات الجديدة، كنمط `strftime` في Python | `%Y_%m_%d-%H%M%S` |
| **Open notes with** (فتح الملاحظات بـ) | الأمر الذي يفتح الملاحظة عند **Enter**، مثلًا `xed`. فارغ = الافتراضي في النظام | فارغ |
| **Preview characters (head)** (أحرف المعاينة — البداية) | عدد الأحرف المعروضة من بداية الملاحظة على بطاقتها | 120 |
| **Counts shown from** (عرض الأعداد ابتداءً من) | الملاحظات التي يبلغ طولها هذا الحد على الأقل تعرض أعداد المقاطع المظلَّلة والعلامات الزمنية. 0 = كل البطاقات | 120 |
| **Editor pane starts in** (تبدأ لوحة المحرر في) | **Read (highlights, no editing)** (قراءة — تظليل دون تحرير) أو **Edit (type straight in)** (تحرير — الكتابة مباشرة) | Read |
| **Preview words (head)** (كلمات المعاينة — البداية) | عدد الكلمات من البداية المعروضة على بطاقة **Just added** (أُضيفت للتو) | 2 |
| **Preview words (tail)** (كلمات المعاينة — النهاية) | عدد الكلمات من النهاية المعروضة على بطاقة **Just added** | 2 |
| **Preview characters (tail)** (أحرف المعاينة — النهاية) | عدد الأحرف المعروضة من نهاية الملاحظة الطويلة. 0 = لا شيء | 40 |
| **Saving** (الحفظ) ← **Save on Enter (Shift+Enter for a newline)** (الحفظ بـ Enter، و Shift+Enter لسطر جديد) | مفتاح **Enter** وحده يحفظ الملاحظة | معطّل |
| **Tags** (الوسوم) ← **List every #hashtag under the add field** (عرض كل هاشتاغ تحت حقل الإضافة) | عند تعطيله يُعرض مجموع مختصر بدلًا من ذلك | مفعّل |
| **Startup** (البدء) ← **Open filtered to today's notes** (الفتح مُصفّى على ملاحظات اليوم) | البدء مع تحديد اليوم في التقويم | مفعّل |
| **Highlight colour** (لون التظليل) | اللون خلف المقاطع المظلَّلة | أصفر |
| **Append separator** (فاصل الإلحاق) | يُدرج قبل التعليق المُلحق سريعًا. `$date` = الوقت الحالي، `\n` = سطر جديد | `\n---$date:\n` |
| **Append date format** (صيغة تاريخ الإلحاق) | صيغة `strftime` لـ `$date` | `%Y-%m-%d %H:%M` |
| **Kanban rows** (صفوف كانبان) | عدد الصفوف التي تتوزع عليها أعمدة كانبان (1–3) | 2 |
| **Card max width (columns view)** (أقصى عرض للبطاقة — عرض الأعمدة) | أقصى عرض يمكن أن تبلغه البطاقة في عرض الأعمدة | 340 |

!!! warning "تغيير صيغة الطابع الزمني"
    تتوقع تطبيقات knotes الأخرى الصيغة الافتراضية `YYYY_MM_DD-HHMMSS`. لا تغيّرها إلا إذا كان كل تطبيق
    يقرأ المجلد يستخدم الصيغة نفسها.

## خادم Nibras — الافتراضي { #nibras-backend-default }

**Backend URL** (عنوان الخادم) و**Backend username** (اسم المستخدم) و**Backend password** (كلمة المرور) — الخادم الذي تستخدمه المجلدات التي
ليس لها خادم خاص لمزامنة الرموز. عنوان فارغ = دون اتصال. راجع
[الاتصال بخادم Nibras](nibras-server.md).

## خيارات الوسوم للمجلد النشط { #tag-options-for-the-active-folder }

تُحفظ هذه داخل المجلد (في `.knotes.json`) ولا تنطبق إلا عليه. يذكر العنوان اسم
المجلد، مثلًا **Tag options for folder “A”** (خيارات الوسوم للمجلد “A”).

| الإعداد | ما يفعله |
|---|---|
| **Priority min** (أدنى أولوية) / **Priority max** (أعلى أولوية) | نطاق رقائق الأولوية |
| **Default priority** (الأولوية الافتراضية) | الأولوية التي تبدأ بها الملاحظة الجديدة |
| **Types (code:name per line; * = default)** (الأنواع) | أنواع هذا المجلد؛ و`*` تعلّم الافتراضي |
| **Categories (code:name per line; * = default)** (الفئات) | فئات هذا المجلد؛ و`*` تعلّم الافتراضي |
| **This folder's backend URL** / **username** / **password** (عنوان خادم هذا المجلد / اسم المستخدم / كلمة المرور) | خادم Nibras لهذا المجلد فقط. فارغ = استخدام الخادم الافتراضي |

راجع [النوع والأولوية والفئة](tagging.md#define-your-own-codes).

## إعدادات شريط الأدوات { #toolbar-settings }

تُبدَّل هذه كثيرًا لدرجة أنها تعيش في شريط الأدوات وتُحفظ تلقائيًا:

- العرض: **Kanban** و**Simple list** و**Columns** و**Minimal**
- ترتيب الفرز
- السمة الفاتحة / الداكنة (**Ctrl+T**)
- لوحة المحرر الجانبية مفتوحة أو مغلقة، وعرضها (**Ctrl+E**)
- الشريط الجانبي للمرشحات ظاهر أو مخفي، والأقسام المطوية، ومفتاح **Created** / **Updated** في التقويم (**Ctrl+B**)
- فتح مجلد الملفات تلقائيًا بعد كل حفظ

## ملف الإعدادات { #the-config-file }

تُخزَّن كل الإعدادات في `config.json` **بجوار البرنامج**، لذا يأخذ مجلد البرنامج المنسوخ
إعداداته معه. أغلق التطبيق قبل تحرير الملف يدويًا.

### في ملف الإعدادات فقط { #config-file-only }

بعض الخيارات ليس لها عنصر تحكم في نافذة الحوار:

| المفتاح | ما يفعله | الافتراضي |
|---|---|---|
| `tag_bank_path` | مسار ملف `tag-bank.md` الخاص بك. فارغ = بجوار البرنامج. وجّهه إلى مجلد مُزامَن لمشاركة المفردات بين الأجهزة | فارغ |
| `card_file_chars` | عدد أحرف اسم كل ملف مرفق المعروضة على البطاقة | 12 |
| `editor_autosave_ms` | مدة التوقف (بالمللي ثانية) قبل أن يحفظ المحرر الجانبي | 900 |

# Raccourcis clavier

Tout dans Nibras Notes peut se faire au clavier. Appuyez sur **F1** dans l'application pour
afficher cette liste à tout moment.

Les raccourcis utilisent la touche physique ; ils continuent donc de fonctionner avec une
disposition de clavier arabe (ou toute autre).

## Écriture { #writing }

| Touches | Action |
|---|---|
| **Ctrl+Enter** | Enregistrer la nouvelle note (aussi **Enter**, si **Save on Enter** — enregistrer avec Entrée — est activé ; **Shift+Enter** ajoute alors une nouvelle ligne) |
| **Ctrl+Shift+<letter>** | Définir le type ou la catégorie de la nouvelle note (aucune carte sélectionnée) |
| **Ctrl+Shift+<digit>** | Définir la priorité de la nouvelle note (aucune carte sélectionnée) |
| **Ctrl+N** | Basculer le formulaire d'ajout entre complet (pastilles type / priorité / catégorie) et court (sans pastilles, enregistré en N · P2 · X) |
| **Ctrl+J** / **Ctrl+K** | Aller dans le champ des notes rapides / des tâches rapides (ouvre le panneau latéral et les listes s'ils sont fermés) |
| **Enter** (dans un champ de liste rapide) | Ajouter la ligne et rester dans le champ |
| **Esc** | Basculer entre le champ de texte et le tableau |
| **F12** | Déplacer le focus entre les cartes et le champ de texte (en mode minimal, sélectionner la carte) |
| **#** | Ouvrir les suggestions de la banque d'étiquettes — **↑**/**↓** pour se déplacer, **Enter**/**Tab** pour insérer, **Esc** pour fermer |

## Travailler avec une carte sélectionnée { #working-with-a-selected-card }

| Touches | Action |
|---|---|
| **Clic** / **Touches fléchées** | Sélectionner une carte · se déplacer entre les cartes (↑↓ dans une colonne, ←→ d'une colonne à l'autre) |
| **Enter** / double-clic | Ouvrir la note dans votre éditeur |
| **Ctrl+Shift+<letter>** | Définir le type ou la catégorie de la carte — et de chaque carte marquée (renomme les fichiers) |
| **Ctrl+Shift+<digit>** | Définir la priorité de la carte et de chaque carte marquée |
| **Space** | Ajouter rapidement un commentaire (**Enter** ajoute, **Esc** annule) |
| **Ctrl+O** | Ouvrir le dossier de fichiers de la note (créé si nécessaire) |
| **Ctrl+I** | Importer la note dans le serveur Nibras (demande confirmation ; le fichier est déplacé dans `imported/`) |
| **Ctrl+D** | Déplacer la note — et chaque carte marquée — dans `.deleted/` (demande confirmation ; les notes qui ont des fichiers joints sont conservées) |
| **Ctrl+M** / **Ctrl+clic** | Marquer ou démarquer une carte (la première note marquée est conservée lors d'une fusion) |
| **Ctrl+Shift+M** | Fusionner les notes marquées dans la note conservée |
| **Esc** | Effacer les marques |

## Panneau d'édition latéral { #side-editor-pane }

| Touches | Action |
|---|---|
| **Ctrl+E** | Afficher ou masquer le panneau d'édition latéral |
| **Esc** / **Ctrl+Enter** | Enregistrer et revenir au tableau (pendant l'édition dans le panneau) |

## Fenêtre et vues { #window-and-views }

| Touches | Action |
|---|---|
| **Ctrl+1** … **Ctrl+9** | Passer au 1er … 9e dossier de notes |
| **Ctrl+PgUp** / **Ctrl+PgDn** | Calendrier de la semaine : semaine précédente / suivante |
| **Ctrl+F** | Afficher ou masquer la recherche (**Enter** la lance) |
| **Ctrl+B** | Afficher ou masquer la barre latérale de filtres |
| **Ctrl+L** | Activer/désactiver le mode note latérale minimal |
| **Ctrl+R** | Relire le dossier depuis le disque |
| **Ctrl+T** | Basculer entre thème clair et sombre |
| **Ctrl+,** | Paramètres |
| **F1** | Liste des raccourcis clavier |
| **Ctrl+Q** | Quitter (enregistre d'abord un brouillon non envoyé) |

!!! note
    La priorité utilise **Ctrl+Shift+<digit>** ; un simple **Ctrl+<digit>** change de dossier. Il
    n'y a aucun raccourci `Alt` ni de touche **Delete** seule — la suppression se fait toujours
    avec **Ctrl+D**.

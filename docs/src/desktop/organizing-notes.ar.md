# تنظيم الملاحظات

لا يمسح knotes أي شيء من تلقاء نفسه أبدًا. الحذف والدمج ينقلان الملفات إلى مجلدات مخفية داخل
مجلد ملاحظاتك، لذا يمكن دائمًا تدارك أي خطأ باستخدام مدير الملفات.

## حذف ملاحظة { #delete-a-note }

1. حدد البطاقة.
2. اضغط **Ctrl+D**، أو انقر زر سلة المهملات على البطاقة.
3. تعرض رسالة التأكيد وسوم الملاحظة وأسطرها الأولى. اضغط **Enter** (أو انقر **Yes** (نعم)) للتأكيد.

تنتقل الملاحظة إلى مجلد مخفي `.deleted/` داخل مجلد الملاحظات. لاستعادتها، انقل
الملف إلى الخارج مجددًا.

!!! note
    لا يمكن حذف ملاحظة ما زالت لها [ملفات مرفقة](attached-files.md). أفرغ
    مجلدها المرافق أولًا.

## دمج الملاحظات { #merge-notes }

يضمّ الدمج عدة ملاحظات في ملاحظة واحدة — وهو مفيد عندما تُدوَّن فكرة على أجزاء.

1. حدد الملاحظة التي يجب أن **تبقى** واضغط **Ctrl+M** (أو **Ctrl+click** عليها). البطاقة الأولى
   التي تعلّمها هي الباقية؛ وتحتفظ باسم ملفها ووسومها.
2. علّم الملاحظات الأخرى بالطريقة نفسها، بالترتيب الذي تريد إلحاقها به. يعرض شريط العنوان عدد
   الملاحظات المعلَّمة.
3. اضغط **Ctrl+Shift+M** وأكّد.

يُلحَق بالملاحظة الباقية نص كل ملاحظة مدموجة تحت سطر `---` يذكر الملف
الأصلي، فلا تضيع وسومها القديمة وطابعها الزمني. تنتقل الملاحظات المدموجة إلى مجلد مخفي `.merged/`،
وتنتقل ملفاتها المرفقة إلى المجلد المرافق للملاحظة الباقية.

يمسح **Esc** العلامات دون دمج.

## تسوية الملفات المتفرقة { #settle-loose-files }

يمكنك إسقاط أي شيء في مجلد الملاحظات — ملف نصي، أو PDF، أو مجلد كامل. وإلى أن يحمل
اسم ملاحظة صحيحًا، يعرضه knotes كبطاقة حمراء **needs metadata** (يحتاج إلى بيانات وصفية)، ويُدرجه تحت *اليوم* في
التقويم، ويحسبه في شريط العنوان (`· 3 to settle`).

لتسوية واحد منها، حدد بطاقته واضغط أي اختصار وسم — **Ctrl+Shift+<letter>** لنوع أو
فئة، أو **Ctrl+Shift+<digit>** لأولوية. وما يحدث يعتمد على ماهيته:

| العنصر | يصبح |
|---|---|
| مجلد | ملاحظة جديدة تحمل اسم المجلد، ويتحول المجلد إلى [مجلدها المرافق](attached-files.md) |
| ملف `.md` أو `.txt` | ملاحظة صحيحة؛ ويصبح اسم ملفها القديم السطر الأول من النص |
| أي ملف آخر (PDF، صورة، مخطط، …) | ملاحظة جديدة نصها اسم الملف، مع إرفاق الملف بها |

تحتفظ الملفات المسوّاة بتاريخها الخاص (تاريخ آخر تغيير للملف)، فتستقر في مكانها
الحقيقي في الزمن.

!!! tip "اعثر على كل ما يحتاج إلى تسوية"
    في الشريط الجانبي، اضبط **Non-standard** (غير قياسي) على **Only** (فقط). راجع
    [اللوحة والشريط الجانبي والمرشحات](board-and-filters.md#clean-up-queues).

## عدة مجلدات ملاحظات { #several-note-folders }

يمكنك الاحتفاظ بمجلدات منفصلة — شخصية وللعمل مثلًا — والتبديل بينها.

1. افتح **Settings** (الإعدادات) (**Ctrl+,**).
2. في **Note folders** (مجلدات الملاحظات)، اكتب مجلدًا واحدًا في كل سطر بصيغة `code:path`، وعلّم النشط منها بـ `*`:

    ```
    A*:~/Knotes
    B:~/Work-notes
    ```

3. انقر **Save** (حفظ).

يظهر الآن منتقي مجلدات بجوار زر الإرسال. بدّل المجلدات به، أو بـ
**Ctrl+1** … **Ctrl+9** للمجلدات التسعة الأولى. يحتفظ كل مجلد
[بخيارات وسومه الخاصة](tagging.md#define-your-own-codes) بل ويمكنه التواصل مع
[خادم Nibras الخاص به](nibras-server.md).

## الملفات والمجلدات التي يتجاهلها knotes { #files-and-folders-knotes-ignores }

هذه لا تظهر أبدًا على اللوحة:

- الملفات والمجلدات المخفية (التي تبدأ أسماؤها بـ `.`)، بما فيها `.deleted` و`.merged`
  و`.imported` و`.knotes.json`.
- مجلدات الصيانة المسماة `deleted` أو `merged` أو `imported` أو `trash` أو `trashed`، بأي حالة أحرف.
- مجلدات `.d/` المرافقة التابعة لملاحظة.
- `notes.sqlite` (وملفاته `-wal` و`-shm` و`-journal`) و`claude.md`.

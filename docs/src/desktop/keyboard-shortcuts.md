# Keyboard shortcuts

Everything in Nibras Notes can be done from the keyboard. Press **F1** in the app to see this
list at any time.

Shortcuts use the physical key, so they keep working with an Arabic (or any other) keyboard layout.

## Writing

| Keys | Action |
|---|---|
| **Ctrl+Enter** | Save the new note (also **Enter**, if **Save on Enter** is on — then **Shift+Enter** adds a new line) |
| **Ctrl+Shift+<letter>** | Set the type or category for the new note (with no card selected) |
| **Ctrl+Shift+<digit>** | Set the priority for the new note (with no card selected) |
| **Ctrl+N** | Switch the add form between full (type / priority / category chips) and short (no chips, saved as N · P2 · X) |
| **Ctrl+J** / **Ctrl+K** | Jump into the quick note / quick task field (opens the side pane and the lists if closed) |
| **Enter** (in a quick list field) | Add the line and stay in the field |
| **Esc** | Switch between the text field and the board |
| **F12** | Switch focus between the cards and the text field (in minimal mode, select the card) |
| **#** | Open tag-bank suggestions — **↑**/**↓** move, **Enter**/**Tab** insert, **Esc** closes |

## Working with a selected card

| Keys | Action |
|---|---|
| **Click** / **Arrow keys** | Select a card · move between cards (↑↓ in a column, ←→ across) |
| **Enter** / double-click | Open the note in your editor |
| **Ctrl+Shift+<letter>** | Set the type or category of the card — and of every marked card (renames the files) |
| **Ctrl+Shift+<digit>** | Set the priority of the card and every marked card |
| **Space** | Quick-append a comment (**Enter** adds, **Esc** cancels) |
| **Ctrl+O** | Open the note's files folder (created if needed) |
| **Ctrl+I** | Import the note into the Nibras server (asks first; the file moves to `imported/`) |
| **Ctrl+D** | Move the note — and every marked card — to `.deleted/` (asks first; notes with attached files are kept) |
| **Ctrl+M** / **Ctrl+click** | Mark or unmark a card (the first marked note survives a merge) |
| **Ctrl+Shift+M** | Merge the marked notes into the survivor |
| **Esc** | Clear the marks |

## Side editor pane

| Keys | Action |
|---|---|
| **Ctrl+E** | Show or hide the side editor pane |
| **Esc** / **Ctrl+Enter** | Save and return to the board (while editing in the pane) |

## Window and views

| Keys | Action |
|---|---|
| **Ctrl+1** … **Ctrl+9** | Switch to the 1st … 9th note folder |
| **Ctrl+PgUp** / **Ctrl+PgDn** | Week calendar: previous / next week |
| **Ctrl+F** | Show or hide search (**Enter** runs it) |
| **Ctrl+B** | Show or hide the filter sidebar |
| **Ctrl+L** | Toggle minimal side-note mode |
| **Ctrl+R** | Re-read the folder from disk |
| **Ctrl+T** | Toggle light / dark theme |
| **Ctrl+,** | Settings |
| **F1** | Keyboard shortcut list |
| **Ctrl+Q** | Quit (saves an unsent draft first) |

!!! note
    Priority uses **Ctrl+Shift+<digit>**; plain **Ctrl+<digit>** switches folders. There are no
    `Alt` shortcuts and no bare **Delete** key — deleting is always **Ctrl+D**.

# اختصارات لوحة المفاتيح

يمكن إنجاز كل شيء في knotes لسطح المكتب من لوحة المفاتيح. اضغط **F1** داخل التطبيق لرؤية هذه
القائمة في أي وقت.

تعتمد الاختصارات على المفتاح الفعلي، لذا تبقى تعمل مع تخطيط لوحة مفاتيح عربي (أو أي تخطيط آخر).

## الكتابة { #writing }

| المفاتيح | الإجراء |
|---|---|
| **Ctrl+Enter** | حفظ الملاحظة الجديدة (وكذلك **Enter** إذا كان **Save on Enter** (الحفظ بـ Enter) مفعّلًا — وعندها يضيف **Shift+Enter** سطرًا جديدًا) |
| **Ctrl+Shift+<letter>** | تعيين النوع أو الفئة للملاحظة الجديدة (دون تحديد أي بطاقة) |
| **Ctrl+Shift+<digit>** | تعيين الأولوية للملاحظة الجديدة (دون تحديد أي بطاقة) |
| **Esc** | التبديل بين الحقل النصي واللوحة |
| **F12** | نقل التركيز بين البطاقات والحقل النصي (في الوضع المصغّر: تحديد البطاقة) |
| **#** | فتح اقتراحات بنك الوسوم — **↑**/**↓** للتنقل، **Enter**/**Tab** للإدراج، **Esc** للإغلاق |

## العمل مع بطاقة محددة { #working-with-a-selected-card }

| المفاتيح | الإجراء |
|---|---|
| **Click** (نقرة) / **مفاتيح الأسهم** | تحديد بطاقة · التنقل بين البطاقات (↑↓ داخل العمود، ←→ بين الأعمدة) |
| **Enter** / نقرة مزدوجة | فتح الملاحظة في محررك |
| **Ctrl+Shift+<letter>** | تعيين نوع البطاقة أو فئتها (يعيد تسمية الملف) |
| **Ctrl+Shift+<digit>** | تعيين أولوية البطاقة |
| **Space** | إلحاق تعليق سريع (**Enter** يضيف، **Esc** يلغي) |
| **Ctrl+O** | فتح مجلد ملفات الملاحظة (يُنشأ عند الحاجة) |
| **Ctrl+D** | نقل الملاحظة إلى `.deleted/` (يسأل أولًا؛ ويُرفض ما دامت لها ملفات مرفقة) |
| **Ctrl+M** / **Ctrl+click** | وضع علامة الدمج أو إزالتها (الملاحظة الأولى المعلَّمة هي التي تبقى) |
| **Ctrl+Shift+M** | دمج الملاحظات المعلَّمة في الملاحظة الباقية |
| **Esc** | مسح علامات الدمج |

## لوحة المحرر الجانبية { #side-editor-pane }

| المفاتيح | الإجراء |
|---|---|
| **Ctrl+E** | إظهار لوحة المحرر الجانبية أو إخفاؤها |
| **Esc** / **Ctrl+Enter** | الحفظ والعودة إلى اللوحة (أثناء التحرير في اللوحة الجانبية) |

## النافذة وطرق العرض { #window-and-views }

| المفاتيح | الإجراء |
|---|---|
| **Ctrl+1** … **Ctrl+9** | التبديل إلى مجلد الملاحظات الأول … التاسع |
| **Ctrl+F** | إظهار البحث أو إخفاؤه |
| **Ctrl+B** | إظهار الشريط الجانبي للمرشحات أو إخفاؤه |
| **Ctrl+L** | تبديل وضع الملاحظة الجانبية المصغّر |
| **Ctrl+R** | إعادة قراءة المجلد من القرص |
| **Ctrl+T** | التبديل بين السمة الفاتحة والداكنة |
| **Ctrl+,** | الإعدادات |
| **F1** | قائمة اختصارات لوحة المفاتيح |
| **Ctrl+Q** | الخروج (يحفظ المسودة غير المرسلة أولًا) |

!!! note
    تستخدم الأولوية **Ctrl+Shift+<digit>**؛ أما **Ctrl+<digit>** وحده فيبدّل المجلدات. لا توجد
    اختصارات بـ `Alt` ولا يُستخدم مفتاح **Delete** وحده — الحذف دائمًا بـ **Ctrl+D**.

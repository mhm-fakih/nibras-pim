# التهيئة

تُحفظ كل الإعدادات في `config.json` **بجوار البرنامج**. يُنشأ هذا الملف في التشغيل الأول — منسوخًا
من إعدادات knotes لسطح المكتب إن وُجدت — ويكتب التطبيق فيه مجددًا عندما تبدّل المجلدات أو السمات.
عدّله بأي محرر نصوص والتطبيق مغلق.

## مثال { #example }

```json
{
  "preview_chars": 60,
  "default_repo": "P",
  "default_type": "N",
  "default_priority": 2,
  "default_subject": "Z",
  "theme": "solarized-light",
  "repos": {
    "P": { "path": "~/Knotes", "backend": "https://nibras.example.com" },
    "W": { "path": "~/Work-notes", "backend": "https://work.example.com" }
  }
}
```

## الإعدادات { #settings }

| المفتاح | ما يفعله | القيمة الافتراضية |
|---|---|---|
| `repos` | مجلدات ملاحظاتك. لكل منها رمز من حرف واحد، و`path`، و`backend` خاص به (عنوان الخادم) | مجلد واحد **A** في `~/knotes` |
| `default_repo` | رمز المجلد الحالي. يُحدَّث تلقائيًا عندما تسمّي مجلدًا في سطر ملاحظة | المجلد الأول |
| `default_type` | النوع للملاحظات التي لا تحمل رمز وسم | `N` |
| `default_priority` | الأولوية للملاحظات التي لا تحمل رمز وسم | `2` |
| `default_subject` | الفئة للملاحظات التي لا تحمل رمز وسم | `Z` |
| `theme` | `solarized-light` أو `solarized-dark` — أو استخدم `/theme` | `solarized-light` |
| `preview_chars` | طول معاينات الملاحظات | `60` |

ينبغي أن تكون رموز المجلدات حروفًا مفردة — فهذا ما يستطيع سطر الملاحظة الإشارة إليه
(انظر [كتابة الملاحظات](writing-notes.md)).

!!! tip "مجلد واحد، عدة تطبيقات"
    وجّه `path` الخاص بمجلد إلى المجلد نفسه الذي يستخدمه knotes لسطح المكتب أو هاتفك. فكلها تقرأ
    وتكتب أسماء الملفات نفسها، لذا تظهر الملاحظات في كل مكان. انظر
    [المزامنة](../concepts/sync.md).

## متغيرات البيئة { #environment-variables }

| المتغير | التأثير |
|---|---|
| `NIBRAS_URL` | استخدام عنوان الخادم هذا **لكل** المجلدات في هذا التشغيل، مثل `NIBRAS_URL=https://test.example.com ./run.sh`. مفيد للاختبار |
| `NIBRAS_RESHAPE=1` | تشكيل النص العربي وإعادة ترتيبه من قِبل التطبيق، للطرفيات التي لا تفعل ذلك |

!!! warning
    إذا بدّلت المجلدات أو السمات بينما `NIBRAS_URL` مضبوط، يحفظ التطبيق إعداداته — ومعها عنوان
    الخادم البديل لكل المجلدات. راجع `config.json` بعد ذلك.

## ملفات أخرى { #other-files }

| الملف | الغرض |
|---|---|
| `~/.config/knotes/tokens.json` | جلسات تسجيل دخولك، واحدة لكل خادم. احذفه لتسجيل الخروج من كل مكان |
| `.venv/` | بيئة Python الخاصة التي ينشئها `run.sh`. احذفها لإعادة تثبيت الحزم |

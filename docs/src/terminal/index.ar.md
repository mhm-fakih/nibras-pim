# knotes للطرفية

**knotes للطرفية** أداة لتدوين الملاحظات تعمل في الطرفية. تبدو كالمحادثة: سجلّ لما جرى في الأعلى،
وشريط أوامر من سطر واحد في الأسفل. اكتب ملاحظة واضغط **Enter** — فتُحفظ ملفًا نصيًا بسيطًا،
بأسماء الملفات نفسها التي يستخدمها [knotes لسطح المكتب](../desktop/index.md) و
[تطبيق الهاتف](../mobile/index.md)، لذا يمكنها جميعًا أن تتشارك مجلدًا واحدًا.

ويمكنه أيضًا التواصل مع خادم نبراس: تسجيل الدخول، وعرض أحدث مهامك أو أهدافك أو يومياتك، وإرسال
ملاحظة مباشرة إلى الخادم بوصفها سجلًا.

!!! tip "كيف تُخزَّن الملاحظات"
    الملاحظات ملفات Markdown بسيطة تحمل أسماؤها وسومَها. انظر
    [ملاحظات بنص بسيط](../concepts/plain-text-notes.md) و
    [أسماء الملفات والوسوم](../concepts/filenames-and-tags.md).

- [الأوامر](commands.md) — كل أمر `/command` وكل مفتاح.

## التثبيت والتشغيل { #install-and-run }

تحتاج إلى Python 3. يستخدم التطبيق بضع حزم Python ‏(Textual للواجهة، وhttpx للخادم، إضافةً إلى
أداتين مساعدتين اختياريتين للعربية)؛ ويثبّتها `run.sh` لك في بيئة خاصة.

يعيد تطبيق الطرفية استخدام شيفرة تخزين الملاحظات الخاصة بـ knotes لسطح المكتب، لذا أبقِ المجلد
`terminal/` بجوار المجلد `desktop/`.

=== "Linux / macOS"

    ```bash
    cd terminal
    ./run.sh
    ```

    التشغيل الأول ينشئ المجلد `.venv` ويثبّت الحزم؛ والتشغيلات اللاحقة تبدأ فورًا.

=== "يدويًا"

    `run.sh` سكربت shell. في أي مكان آخر، نفّذ الخطوات نفسها بنفسك:

    ```bash
    cd terminal
    python3 -m venv .venv
    .venv/bin/pip install -r requirements.txt
    .venv/bin/python knotes_tui.py
    ```

    (على Windows توجد برامج البيئة الافتراضية في `.venv\Scripts\` بدلًا من `.venv/bin/`.)

!!! note "تشغيله وحده"
    إذا نسخت `terminal/` إلى مكان ما دون `desktop/`، فانسخ أيضًا `desktop/notes.py` بجوار
    `knotes_tui.py`. من دونه يتوقف التطبيق برسالة توضّح ذلك.

## التشغيل الأول { #first-run }

عند البدء لأول مرة ينشئ التطبيق `config.json` بجوار البرنامج. إذا كان knotes لسطح المكتب مثبّتًا
بجانبه، تُنسخ مجلدات ملاحظاته ووسومه الافتراضية، فتبدأ من حيث توقّف سطح المكتب. وإلا فستحصل على
مجلد واحد، **A**، في `~/knotes`.

تعرض الشاشة:

- **Dashboard** (لوحة المعلومات) (في الأعلى) — مجلدات ملاحظاتك: الرمز، والمسار، والخادم، وعدد
  الملاحظات. وتُميّز **★** المجلد الحالي.
- **Log** (السجلّ) (في الوسط) — الملاحظات المحفوظة، ومخرجات الأوامر، والرسائل.
- **Command bar** (شريط الأوامر) (في الأسفل) — حيث تكتب.
- **Status bar** (شريط الحالة) (تحته) — الخادم الحالي مع نقطة تكون **خضراء** حين يكون متاحًا
  و**حمراء** حين لا يكون، والمجلد الحالي والوسوم الافتراضية، والمدة التي مضت على تشغيل التطبيق،
  وعدد الملاحظات التي حفظتها في هذه الجلسة.

جرّبه: اكتب `hello from the terminal` واضغط **Enter**. يؤكد السجلّ `✓ saved` مع اسم الملف.

للخروج، اكتب `/quit`. (يُتجاهل **Ctrl+C** و**Ctrl+Q** عمدًا حتى لا تُغلق ضغطةُ مفتاح عابرة التطبيق.)

## النص العربي { #arabic-text }

الطرفيات الحديثة تشكّل الحروف العربية وترتّبها بشكل صحيح بنفسها، لذا يطبع التطبيق النص كما هو.
إذا كانت طرفيتك تعرض الحروف العربية منفصلة أو معكوسة، فشغّل التطبيق مع `NIBRAS_RESHAPE=1`:

```bash
NIBRAS_RESHAPE=1 ./run.sh
```

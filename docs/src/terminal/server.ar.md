# أوامر الخادم

عندما يكون مجلد الملاحظات مرتبطًا بخادم نبراس، يستطيع تطبيق الطرفية فحص الخادم، وتسجيل الدخول،
وعرض أحدث سجلاتك. لكل مجلد خادمه الخاص (انظر [التهيئة](configuration.md))، وتستخدم هذه الأوامر
دائمًا خادم المجلد **الحالي** — الظاهر في شريط الحالة.

## هل الخادم يعمل؟ { #is-the-server-up }

يفحص شريط الحالة الخادم الحالي كل بضع ثوانٍ. تعني **● خضراء** بجوار عنوانه أنه متاح؛ و**الحمراء**
أنه غير متاح. للفحص عند الطلب:

```
/heartbeat
```

يجيب السجلّ بـ `up` أو `unreachable`.

## تسجيل الدخول { #log-in }

```
/login <username> <password>
```

عند النجاح يعرض السجلّ `logged in as …` مع اسم المستخدم ودورك. يُتذكَّر تسجيل الدخول — لكل خادم —
عبر إعادة التشغيل حتى تنتهي صلاحيته، لذا نادرًا ما تحتاج إلى تكراره. ويُخزَّن في
`~/.config/knotes/tokens.json`، الذي لا يقرؤه إلا مستخدمك.

يؤدي تسجيل الدخول أيضًا إلى إرسال أي ملاحظات وُضعت في الطابور بالبادئة `+` بينما كنت غير مسجَّل
الدخول.

!!! warning
    كلمة المرور التي تكتبها تظهر في شريط الأوامر وتبقى في سجلّ ↑/↓ للجلسة حتى تخرج. سجّل الدخول
    حين لا يراقب أحد شاشتك.

إذا انتهت صلاحية الجلسة، يقول الأمر التالي `session expired — /login again`.

## عرض السجلات الحديثة { #list-recent-records }

يعرض كل من هذه الأوامر **آخر 20 سجلًا جرى تحديثها** من نوع واحد:

| الأمر | يعرض |
|---|---|
| `/tasks` | المهام |
| `/goals` | الأهداف |
| `/journals` | اليوميات |
| `/planners` | المخطِّطات |
| `/resources` | الموارد |
| `/notes` | الملاحظات |
| `/writings` | الكتابات |

تبدأ المخرجات بالعدد الإجمالي، ثم سطر لكل سجل — رقمه وعنوانه، وحالته إن وُجدت:

```
tasks — 214 total, showing 20
  #812  Renew the domain  In progress
  #809  Draft the quarterly summary  Done
```

إذا لم تكن مسجَّل الدخول، يطلب منك التطبيق تنفيذ `/login` أولًا.

انظر [المزامنة](../concepts/sync.md) لمعرفة كيف تتكامل التطبيقات والخادم.

# كتابة الملاحظات

كل ما تكتبه ولا يبدأ بـ `/` أو `+` يُحفظ ملاحظةً عندما تضغط **Enter**.

## سطر الملاحظة { #the-note-line }

يمكن أن يبدأ سطر الملاحظة بحرف مجلد اختياري ورمز وسم اختياري من ثلاثة محارف:

```
[<folder>] [<type><priority><category>] <text>
```

| الجزء | شكله | معناه |
|---|---|---|
| المجلد | حرف واحد، مثل `s` | أيّ مجلد ملاحظات مُعَدّ يُحفظ فيه |
| رمز الوسم | حرف + رقم + حرف، مثل `t3d` | النوع **T**، والأولوية **3**، والفئة **D** |
| النص | كل ما تبقّى | الملاحظة نفسها |

الحروف لا تميّز بين الكبيرة والصغيرة؛ وتُحفظ الرموز بالأحرف الكبيرة. على سبيل المثال:

| ما تكتبه | يُحفظ بوصفه |
|---|---|
| `s t3d buy new filters` | المجلد **S**، والنوع **T**، والأولوية **3**، والفئة **D**، والنص "buy new filters" |
| `t3d buy new filters` | المجلد الحالي، النوع **T** / الأولوية **3** / الفئة **D** |
| `just a thought` | المجلد الحالي، الوسوم الافتراضية، النص "just a thought" |
| `b x3 note` | `b` ليس مجلدًا و`x3` ليس رمز وسم كاملًا، لذا يكون **السطر كله** هو النص، مع المجلد الحالي والوسوم الافتراضية |

لا يُحتسب حرف المجلد إلا إذا تبعه رمز وسم صالح. وإذا لم يبدأ السطر برمز وسم صالح، فلا يُحذف شيء —
يُحفظ السطر كله ملاحظةً، فلا يضيع أبدًا شيء مما تكتبه.

!!! note
    الأولوية في رمز الوسم رقم واحد، من 0 إلى 9.

## القيم الافتراضية الثابتة { #sticky-defaults }

يتذكّر التطبيق آخر ما استخدمته:

- **المجلد** — تسمية مجلد تجعله المجلد الحالي. يبقى حاليًا للملاحظات التالية ويُتذكَّر عبر إعادة
  التشغيل. ويعرضه شريط الحالة.
- **الوسوم** — يصبح رمز الوسم القيمةَ الافتراضية للملاحظات العادية التالية في هذه الجلسة.

لذا يمكنك ضبط السياق مرة واحدة ثم الاكتفاء بالكتابة:

```
w t3d first point about the plan
second point
third point
```

تذهب الملاحظات الثلاث كلها إلى المجلد **W** بالنوع **T**، والأولوية **3**، والفئة **D**.

يمكن أن يكون لكل مجلد خادمه الخاص، لذا فإن تبديل المجلد يبدّل أيضًا الخادم الذي يفحصه شريط
الحالة. انظر [التهيئة](configuration.md).

## إرسال ملاحظة إلى الخادم: البادئة `+` { #send-a-note-to-the-server-the-prefix }

ابدأ السطر بـ `+` لحفظ الملاحظة **و**إنشاء سجل لها على خادم نبراس:

```
+ s t3d call the supplier about the delivery
```

ما الذي يحدث:

1. تُحفظ الملاحظة دائمًا في المجلد أولًا، فلا تضيع أبدًا.
2. إذا كنت مسجَّل الدخول، يطلب التطبيق من خادم المجلد استيراد ذلك الملف. ينشئ الخادم السجل وينقل
   الملف إلى المجلد الفرعي `imported/` داخل المجلد. ويعرض السجلّ `✓ pushed` مع الوحدة ورقم السجل.
3. إذا لم تكن قد سجّلت الدخول بعد، **توضع الملاحظة في الطابور** وتُرسَل تلقائيًا بعد `/login`.

!!! warning "قبل أن تستخدم `+`"
    - يقرأ الخادم الملف مباشرة من المجلد، لذا يجب أن يكون مجلد الملاحظات مجلدًا يستطيع الخادم
      الوصول إليه (عادةً مجلد الاستيراد الخاص بالخادم).
    - لا يعيش الطابور إلا ما دام التطبيق يعمل. إذا خرجت قبل تسجيل الدخول، تبقى الملاحظات التي في
      الطابور محفوظة في المجلد لكنها لا تُرسَل — استوردها لاحقًا من الخادم.

انظر [أوامر الخادم](server.md) لتسجيل الدخول، و
[التقط الآن، صنّف لاحقًا](../concepts/capture-then-classify.md) للفكرة الكامنة وراء إرسال الملاحظات
لاحقًا.

## مفاتيح مفيدة أثناء الكتابة { #handy-keys-while-typing }

| المفتاح | الإجراء |
|---|---|
| **Enter** | حفظ الملاحظة (أو تنفيذ الأمر) |
| **↑** / **↓** | استرجاع أسطر سابقة من هذه الجلسة |
| **Tab** أو **→** أو **End** | قبول اقتراح الأمر الرمادي |

# الأوامر

السطر الذي يبدأ بـ `/` أمر. وأثناء الكتابة يقترح شريط الأوامر الأمر المطابق باللون الرمادي — اضغط
**Tab** أو **→** أو **End** لقبوله.

## مرجع الأوامر { #command-reference }

| الأمر | أيضًا | ما يفعله |
|---|---|---|
| `/help` | `/h`، `/?` | عرض صيغة سطر الملاحظة وقائمة الأوامر |
| `/repos` | `/repo` | تحديث لوحة مجلدات الملاحظات |
| `/theme` | | عرض السمة الحالية |
| `/theme light` | `/theme l` | التبديل إلى السمة الفاتحة (تُحفظ للمرة القادمة) |
| `/theme dark` | `/theme d` | التبديل إلى السمة الداكنة (تُحفظ للمرة القادمة) |
| `/heartbeat` | | التحقق مما إذا كان خادم المجلد الحالي متاحًا |
| `/login <user> <password>` | | تسجيل الدخول إلى خادم المجلد الحالي |
| `/tasks` | | عرض آخر 20 مهمة جرى تحديثها |
| `/goals` | | … الأهداف |
| `/journals` | | … اليوميات |
| `/planners` | | … المخطِّطات |
| `/resources` | | … الموارد |
| `/notes` | | … الملاحظات |
| `/writings` | | … الكتابات |
| `/quit` | `/exit`، `/q` | إغلاق التطبيق |

أوامر عرض السجلات تتطلب تسجيل الدخول أولًا — انظر [أوامر الخادم](server.md).

## بادئات السطر { #line-prefixes }

| يبدأ بـ | المعنى |
|---|---|
| `/` | أمر (انظر أعلاه) |
| `+` | حفظ الملاحظة **و**إرسالها إلى الخادم — انظر [كتابة الملاحظات](writing-notes.md#send-a-note-to-the-server-the-prefix) |
| أي شيء آخر | حفظ ملاحظة — انظر [كتابة الملاحظات](writing-notes.md) |

## المفاتيح { #keys }

| المفتاح | الإجراء |
|---|---|
| **Enter** | حفظ الملاحظة أو تنفيذ الأمر |
| **↑** / **↓** | التنقل بين الأسطر التي أدخلتها في هذه الجلسة |
| **Tab**، **→**، **End** | قبول الأمر المقترح |
| **Ctrl+C**، **Ctrl+Q** | تُتجاهل عمدًا — اكتب `/quit` للخروج |

يحتفظ شريط الأوامر دائمًا بتركيز لوحة المفاتيح، لذا يمكنك الكتابة في أي وقت.

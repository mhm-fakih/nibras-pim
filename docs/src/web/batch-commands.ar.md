# التعديل الجماعي والإدخال الجماعي

لدى نبراس **لغة أوامر** صغيرة لتعيين الحقول بالكتابة بدلًا من النقر. تعمل الرموز
نفسها عند تعديل سجلات كثيرة دفعةً واحدة (**التعديل الجماعي**)، وعند إنشاء سجلات كثيرة من
أسطر نصية (**الإدخال الجماعي**)، وفي **Import files** (استيراد الملفات)، و— بوصفها عوامل تصفية — في
[البحث الشامل](search.md#global-search).

## الرموز { #the-tokens }

| الرمز | يعيّن | مثال |
|---|---|---|
| `p3` | الأولوية | `p2` |
| `#code` | النوع (رموز أنواع *هذه* الوحدة) | `#art` |
| `?code` | الحالة | `?done` |
| `@code` | السياق | `@home` |
| `dCODE` | القسم | `dA` |
| `cCODE` | المقرر | `cALG` |
| `=code` | حقل الرمز الخاص بالسجل نفسه | `=alg` |
| `*` / `*-` | إضافة إشارة مرجعية / إزالتها | `*` |
| `!` / `!-` | عاجل / غير عاجل | `!` |
| `(DATE` | تاريخ البدء | `(2026-07-17` |
| `)DATE` | تاريخ الانتهاء | `)+3` |
| `'xx` | اللغة | `'en` |

الرموز هي الرموز القصيرة المضبوطة في صفحة [Parameters](administration.md#parameters) وفي
الأقسام والمقررات. تُحلّ الرموز بالنسبة إلى الوحدة التي تعمل فيها، فـ`#art` في
مورد يعني نوعًا من أنواع *الموارد*.

### كتابة التواريخ { #writing-dates }

يقبل `DATE` عدة صيغ؛ والوقت الافتراضي 00:00 والسنة الافتراضية هي السنة الحالية:

| الصيغة | المعنى |
|---|---|
| `2026-07-17` | تاريخ كامل |
| `2026-07-17_1600` | تاريخ كامل في الساعة 16:00 |
| `295` | أسبوع ISO رقم 29، اليوم 5 (الجمعة؛ 1 = الاثنين … 7 = الأحد) |
| `295_25` | الشيء نفسه، في 2025 |
| `295_1600` | الأسبوع 29، الجمعة، 16:00 |
| `-1`، `+3`، `0` | أيام نسبةً إلى اليوم |
| `-1_1600` | أمس في الساعة 16:00 |

### وسوم اللغة { #language-tags }

فاصلة عليا في البداية متبوعة بأحد رموز اللغات من
[الإعدادات](settings.md#tasks-and-other-preferences) (افتراضيًا `ar` و`en` و`fr` و`fa` و`de`) تعيّن
لغة السجل. أي شيء غير موجود في القائمة يبقى نصًا عاديًا، فلا تُعامَل كلمات مثل *don't* أبدًا
على أنها وسم. انظر [اللغات](../concepts/languages.md).

## التعديل الجماعي { #batch-edit }

1. في قائمة وحدة ما، حدّد مربعات اختيار السجلات المراد تغييرها (مربع الاختيار في الرأس
   يحدد الصفحة كلها).
2. يظهر شريط أزرق: **n selected** (n محدد). اكتب أمرًا، مثل `p3 ?done *-`.
3. اضغط **Enter** أو انقر **Apply** (تطبيق). أما **Clear** (مسح) فيلغي التحديد.

تؤكّد رسالةٌ عدد السجلات التي حُدّثت والحقول التي تغيّرت. يُسجَّل كل تغيير
في سجل التدقيق. في التعديل الجماعي يُعدّ الرمز المجهول خطأً، فلا يتغيّر شيء بسبب خطأ مطبعي.

## الإدخال الجماعي { #batch-entry }

ينشئ **Batch entry** (الإدخال الجماعي، من الشريط الجانبي) سجلًا واحدًا لكل سطر.

1. اختر **Default module** (الوحدة الافتراضية).
2. اكتب الأسطر أو الصقها. الرموز تعيّن الحقول؛ والكلمات المتبقية تصبح العنوان. يمكن أن يبدأ السطر
   برمز وحدة ليتجاوز الوحدة الافتراضية:

    ```text
    t p3 ?done @home a task done at home
    n a quick note
    c dA =alg Algebra
    ```

3. انقر **Add n records** (إضافة n سجلات).

تُعرض السجلات المنشأة على شكل بطاقات. أما الأسطر التي فشلت فتبقى في المربع مع خطئها لتتمكن من
إصلاحها وتشغيلها مجددًا.

!!! tip "تلميح"
    في الإدخال الجماعي، إذا لم يطابق `cCODE` أو `dCODE` مقررًا أو قسمًا حقيقيًا فإنه يبقى
    جزءًا من العنوان، فلا تُبتلع كلمة مثل "car".

يمكنك إنشاء المهام واليوميات والخطط والموارد والملاحظات والأهداف والكتابات والمقررات بهذه الطريقة (ما
كان منها مفعّلًا).

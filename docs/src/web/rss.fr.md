# Flux RSS

Chaque module dispose d'un flux RSS de ses fiches **mises en favori**, que vous pouvez suivre dans n'importe quel
lecteur de flux.

## S'abonner { #subscribing }

1. Ouvrez le module voulu (Tasks, Notes, Writings, …).
2. Dans la barre latérale, sous les rapports du module, cliquez sur **RSS (bookmarked)** (RSS des favoris). Le flux
   s'ouvre dans un nouvel onglet.
3. Copiez l'adresse depuis la barre d'adresse du navigateur et ajoutez-la à votre lecteur de flux.

Le flux liste les fiches mises en favori les plus récentes de ce module (jusqu'à 50 par défaut), des plus récentes
aux plus anciennes, avec le texte de chaque fiche comme corps de l'élément. Les titres et textes en écriture de
droite à gauche sont marqués comme tels, afin que les lecteurs qui en tiennent compte les alignent à droite.

!!! warning "Les flux sont publics"
    Les lecteurs de flux ne peuvent pas se connecter, donc **les adresses des flux fonctionnent sans mot de passe**.
    Toute personne qui peut atteindre le serveur et connaît l'adresse peut lire les fiches mises en favori de ce
    module. Gardez-le à l'esprit lorsque vous ajoutez des favoris, et ne diffusez pas largement les adresses des flux.

## Masquer le lien du flux { #hiding-the-feed-link }

Un administrateur peut masquer le lien **RSS (bookmarked)** dans
[Settings → Features](settings.md#pages-and-features) (**RSS feeds**, Flux RSS). Cela masque uniquement le lien dans
la barre latérale ; une adresse de flux déjà connue continue de fonctionner.

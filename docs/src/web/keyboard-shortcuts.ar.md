# اختصارات لوحة المفاتيح

يمكن تشغيل تطبيق الويب بالكامل تقريبًا من لوحة المفاتيح. اضغط **?** في أي وقت لترى
لوحة الاختصارات؛ وتعرض **Help & shortcuts** (المساعدة والاختصارات) في الشريط الجانبي القائمة نفسها، إضافةً إلى ورقة مرجعية
لـMarkdown.

لا تعمل الاختصارات أبدًا وأنت تكتب في مربع — اضغط **Esc** لمغادرة المربع أولًا. كما أنها
تتجاهل تركيبات المفاتيح التي فيها **Ctrl** أو **Alt** أو **⌘**.

## عامة { #global }

| المفاتيح | الإجراء |
|---|---|
| **?** | إظهار / إخفاء لوحة الاختصارات |
| **/** | الانتقال إلى مربع **Search everything…** |
| **g** ثم حرف | الانتقال إلى صفحة (انظر أدناه) |
| **Esc** | إغلاق نافذة حوار أو نموذج، أو إلغاء تحديد السجل الحالي |

## الانتقال إلى (اضغط **g**، ثم…) { #go-to-press-g-then }

اضغط **g**، ثم المفتاح الثاني خلال نحو ثانية ونصف.

| المفاتيح | ينتقل إلى | المفاتيح | ينتقل إلى |
|---|---|---|---|
| **g t** | Tasks (المهام) | **g c** | Calendar (التقويم) |
| **g g** | Goals (الأهداف) | **g k** | Kanban |
| **g n** | Notes (الملاحظات) | **g b** | All bookmarks (كل الإشارات المرجعية) |
| **g j** | Journal (اليوميات) | **g i** | Indicators (المؤشرات) |
| **g p** | Planner (المخطِّط) | **g a** | Admin (الإدارة) |
| **g r** | Resources (الموارد) | **g m** | Import notes (استيراد الملاحظات) |
| **g w** | Writings (الكتابات) | **g s** | Settings (الإعدادات) |

## في قائمة وحدة { #in-a-module-list }

| المفاتيح | الإجراء |
|---|---|
| **j** | تحديد السجل التالي |
| **k** | تحديد السجل السابق |
| **o** | فتح السجل المحدد |
| **n** | سجل جديد |

## مع تحديد سجل { #with-a-record-selected }

| المفاتيح | الإجراء |
|---|---|
| **e** | تعديل السجل |
| **f** ثم **1** / **2** / **3** | فتح مجلد السجل في المستودع 1 / 2 / 3 (على سطح مكتب الخادم) |

### التعديل السريع { #quick-edit }

غيّر حقلًا واحدًا دون فتح النموذج. يُفتح منتقٍ صغير؛ اكتب للتصفية، واختر
قيمة، فتُطبَّق فورًا.

| المفاتيح | يعيّن |
|---|---|
| **p** | الأولوية — اكتب رقمًا، ثم **Enter** |
| **#** | النوع |
| **?** | الحالة (أثناء تحديد سجل، يعيّن **?** الحالة بدلًا من فتح المساعدة) |
| **@** | السياق |
| **d** | القسم |
| **c** | المقرر |
| **\*** | تبديل الإشارة المرجعية |

تحتاج **n** و**e** والتعديلات السريعة إلى صلاحية كتابة المحتوى.

## في مربعات النص { #in-text-boxes }

| المفاتيح | أين | الإجراء |
|---|---|---|
| **Ctrl+Enter** | شريط **Quick note** | إضافة الملاحظة |
| **Ctrl+Enter** | مربع **Append to…** (إلحاق بـ…) تحت حقل | إلحاق النص |
| **Enter** | أمر التعديل الجماعي، ملخص المهمة في هدف، ملخص مؤقّت السباق، معظم حقول النوافذ الحوارية | إرسال |

## المعارض (Highlights وFlash cards) { #galleries-highlights-flash-cards }

| المفاتيح | الإجراء |
|---|---|
| **←** / **→** (أو **Page Up** / **Page Down**) | البطاقة السابقة / التالية |
| **Home** / **End** | البطاقة الأولى / الأخيرة |
| **d** / **r** / **k** / **u** | البطاقات التعليمية: **Reviewed** (روجعت) / **Repeat** (كرّر) / **Keep** (احتفظ) / **Unset** (إلغاء التعيين) |

# لوحات المعلومات والرؤى

## لوحات المعلومات { #dashboards }

**لوحة المعلومات** صفحة تجمعها من **مناطق** جاهزة وتتركها مفتوحة — على شاشة
حائط أو تلفاز أو شاشة احتياطية.

### بناء لوحة معلومات { #building-a-dashboard }

1. افتح **Dashboards** (لوحات المعلومات) من الشريط الجانبي وانقر **New dashboard** (لوحة جديدة).
2. أدخل **Dashboard name** (اسم اللوحة)، وعدد **Columns** (أعمدة) الشبكة، و**Auto-refresh (min)** (التحديث التلقائي بالدقائق؛ 0 يوقفه).
3. انقر **Add region** (إضافة منطقة) لكل كتلة تريدها، واختر **Component** (المكوّن) الخاص بها:

    | المكوّن | يعرض | الإعدادات |
    |---|---|---|
    | **Quote of the day** (اقتباس اليوم) | أحدث ملاحظة ذات إشارة مرجعية من نوع معيّن | **Note type code**، مثل `quote` |
    | **Calendar (filtered by type)** (تقويم مصفّى حسب النوع) | أسبوع من مدخلات اليوميات والمخطِّط | **Event type name** (فارغ للكل)، **Start hour**، **End hour** |
    | **Goals habit heatmap** (خريطة حرارية لعادات الأهداف) | الخرائط الحرارية لعادات الأهداف المعلَّمة بـ*Show habit heatmap on dashboards* | — |
    | **Kanban board** (لوحة Kanban) | لوحة [Kanban](tasks-kanban-sprints.md#kanban) | — |
    | **File content** (محتوى ملف) | نص ملف في أحد المستودعات | **Repo** (1–3)، **Relative path** |

4. اضبط عدد **Columns** الشبكة التي تمتد عليها كل منطقة، واستخدم الأسهم لـ**Move up** / **Move
   down** (تحريك لأعلى / لأسفل). تعرض كل منطقة **Preview** (معاينة) حية.
5. انقر **Save**.

في قائمة لوحات المعلومات، استخدم أيقونة العين لـ**View** (عرض) لوحة، والقلم لـ**Edit**، وسلة المهملات
لـ**Delete**.

!!! tip "مطابقة أنواع التقويم"
    يطابق **Event type name** في منطقة التقويم *اسم* النوع في Journal وPlanner كليهما، لذا
    يمكنك تعريف الاسم نفسه (مثلًا "family") في كلتيهما في صفحة [Parameters](administration.md#parameters)
    — ولكل منهما أن يكون له لونه الخاص.

### عرضها على شاشة { #showing-it-on-a-screen }

يفتح **View** لوحة المعلومات وحدها، دون الشريط الجانبي أو أي عناصر أخرى من التطبيق، في علامة تبويب جديدة.
وهي تحدّث بياناتها كل بضع دقائق وتعيد تحميل نفسها وفق فاصل **Auto-refresh**،
فيمكن أن تعمل دون رقابة لأيام.

!!! warning "روابط عرض لوحات المعلومات لا تتطلب تسجيل الدخول"
    صُممت صفحة العرض لتلفاز لم يسجّل أحد الدخول عليه، لذا **يستطيع أي شخص يمكنه الوصول إلى الخادم
    ويعرف الرابط أن يرى محتوى تلك اللوحة**. لا تضع على لوحة المعلومات إلا مناطق
    ترتاح لعرضها بهذه الطريقة، ولا تنشر رابطها على نطاق واسع.

## الرؤى { #insights }

تساعدك **Insights** (الرؤى) على متابعة مراجعة عملك الأخير. اختر **فترة** (من *Last week*
إلى *Last year*؛ والافتراضي آخر 3 أشهر) ونافذة **reviewed in** (روجعت خلال: من *Last day* إلى *Last
month*؛ والافتراضي الأسبوع الأخير). ويتذكّر متصفحك كليهما.

تعرض الصفحة:

- **Where your records live** (أين تعيش سجلاتك) — مخطط دائري مجوّف للسجلات المنشأة في الفترة، حسب الوحدة.
- **Needs review first** (تحتاج المراجعة أولًا) — لكل وحدة، نسبة سجلات الفترة التي حدّثتها
  خلال نافذة المراجعة، الأدنى أولًا.
- **Activity by type** (النشاط حسب النوع) — بطاقة لكل وحدة فيها أعمدة أسبوعية للسجلات **Created** (المنشأة) و**Updated** (المحدّثة)،
  والسجلات التي تنتظر المراجعة. انقر سجلًا لفتحه.

"روجع" تعني ببساطة *عُدّل* خلال نافذة المراجعة — افتح سجلًا، وحسّنه، واحفظه.

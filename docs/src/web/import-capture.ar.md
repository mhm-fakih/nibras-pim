# صندوق الالتقاط: الاستيراد من الهاتف وسطح المكتب

يعمل نبراس وفق مبدأ **التقط الآن، وصنّف لاحقًا**: يتيح لك تطبيقا الهاتف وسطح المكتب تدوين
الأشياء بسرعة — دون اتصال، على شكل ملاحظات نصية عادية — وتطبيق الويب هو المكان الذي تصبح فيه هذه الالتقاطات
سجلات حقيقية. انظر [التقط ثم صنّف](../concepts/capture-then-classify.md) لفهم الفكرة
الكامنة وراء ذلك.

هناك ثلاثة مداخل:

| المصدر | كيف يصل | أين تتعامل معه |
|---|---|---|
| **تطبيق الهاتف** — ملاحظة *تدفعها* | مباشرةً سجلًا في وحدته، وعليه إشارة مرجعية مسبقًا | الوحدة نفسها (ابحث تحت **★ Bookmarked** أو **Recently created**) |
| **تطبيق سطح المكتب / مجلد الملاحظات** | ملفات Markdown في مجلد الملاحظات الذي يقرؤه الخادم | **Local notes** (الملاحظات المحلية) و**Import notes** (استيراد الملاحظات) |
| **أي ملفات** | تُسقَط في مجلد على الخادم، وتُسمّى كأمر | **Import files** (استيراد الملفات) |

## من الهاتف { #from-the-phone }

عندما تدفع ملاحظة من تطبيق الهاتف، تُنشأ على الخادم سجلًا في الوحدة التي يحددها
نوعها (مهمة، يومية، خطة، ملاحظة، هدف، كتابة أو مورد)، مع أولويتها وقسمها،
و**عليها إشارة مرجعية**. لا حاجة إلى أي استيراد — افتح الوحدة وراجعها. إذا كان الهاتف
غير متصل، فإنه يرسل قائمة انتظاره عند عودة الاتصال. انظر [المزامنة](../concepts/sync.md).

## الملاحظات المحلية { #local-notes }

تعرض **Local notes** مجلد ملاحظات Markdown العادي الذي يكتب فيه تطبيق سطح المكتب — المجلد نفسه
الذي تستورد منه **Import notes**. ولأن الخادم يقرأ المجلد بنفسه، يمكنك تصفحه من
أي متصفح.

- **By day** (حسب اليوم) يجمّع الملاحظات حسب وقت كتابتها؛ و**By subject** (حسب الموضوع) يجمّعها حسب القسم
  والمقرر، باستخدام `#tags` في كل ملاحظة.
- **Filter these notes — text, tag or course…** (تصفية هذه الملاحظات) يضيّق القائمة.
- انقر ملاحظة لفتحها: يمكنك تعديل النص و**Save** لحفظه في الملف، أو **Import as
  ‹module›** (استيراد كـ‹وحدة›) لتحويلها إلى سجل.
- **Add note** (إضافة ملاحظة) يكتب ملاحظة جديدة في المجلد. اختر **Type** (النوع: N — Note، T — Task، J —
  Journal، R — Resource، P — Plan، G — Goal، W — Writing) و**Priority** (الأولوية)، وضع العنوان في
  السطر الأول، وأضف وسمًا مثل `#A.subject` لتصنيفها تحت قسم. انقر **Write note** (كتابة الملاحظة).
- أيقونة التحديث (**Re-read the folder** إعادة قراءة المجلد) تلتقط التغييرات التي أُجريت في مكان آخر.

الاستيراد من هنا يشرح ما سيحدث — يُنشأ سجل (تحت مقرر الملاحظة، إن
كان لها مقرر)، وتُنسخ أي ملفات مرافقة إلى مجلد السجل، وتُنقل الملاحظة إلى
المجلد الفرعي `imported/` فتختفي من القائمة. بعد ذلك، يأخذك **Open the record** (فتح السجل) إليه.

!!! note "كيف تُتعرَّف المواضيع"
    يُطابَق وسم `#A.subject` في الملاحظة مع حقل **Note tags** (وسوم الملاحظات) في **Courses** (المقررات)
    (الوسم المعتمد أولًا، ثم أي أسماء بديلة). أعطِ مقرراتك وسومها وسيسمّيها عرض **By subject**
    تسمية صحيحة. انظر [أسماء الملفات والوسوم](../concepts/filenames-and-tags.md).

## استيراد الملاحظات { #import-notes }

يستورد **Import notes** الملاحظات الموجودة في المجلد دفعةً واحدة، بطاقةً بطاقة.

يحمل **اسم ملف** كل ملاحظة بياناتها الوصفية —
`date~TYPE~pPRIORITY~DEPT.md`، مثلًا `2026_06_15-214006~N~p3~A.md`:

| الجزء | يعيّن |
|---|---|
| التاريخ والوقت | تاريخ إنشاء السجل |
| `TYPE` | الوحدة الهدف، برمزها (`N` ملاحظة، `T` مهمة، …) |
| `p3` | الأولوية |
| `A` | القسم، برمزه الحرفي |

يصبح السطر الأول من الملاحظة العنوان والباقي الوصف. وتُنسخ الملفات الموجودة في
المجلد المرافق للملاحظة إلى مجلد السجل. انظر
[أسماء الملفات والوسوم](../concepts/filenames-and-tags.md) و
[المجلدات المرافقة](../concepts/companion-folders.md).

للاستيراد:

1. تحقّق من **Import folder** (مجلد الاستيراد) في الأعلى (مجلد على الخادم؛ انقر **Save** إن غيّرته).
2. اختياريًا ضيّق البطاقات بعاملي التصفية **Type** و**Priority**.
3. اقرأ كل بطاقة: تعرض شاراتها الوحدة والأولوية والقسم والوقت المأخوذة من
   اسم الملف. ويعرض **Similar existing records** (سجلات موجودة مشابهة) بجانبها سجلات ذات عناوين قريبة — انقر أحدها
   لتتحقق منه قبل استيراد نسخة مكررة.
4. انقر **Import** (استيراد). تظهر بطاقة السجل الجديد مباشرةً تحت الملاحظة، وينتقل ملف الملاحظة إلى
   `imported/`.

البطاقة التي تقول **Missing type, priority, department — can't import** (النوع أو الأولوية أو القسم مفقود) (أو **unrecognized
filename** اسم ملف غير معروف) تحتاج إلى إصلاح اسم ملفها أولًا — أعد تسميته في تطبيق سطح المكتب، ثم أعد تحميل الصفحة.

!!! tip "ملاحظات الموارد تحتاج إلى نوع مورد"
    الملاحظات من النوع **R** تصبح موارد، والمورد يحتاج إلى نوع قبل أن يُصنَّف. اختر
    **Default resource type (for R notes)** (نوع المورد الافتراضي) في أعلى الصفحة، أو انقر إحدى شارات الأنواع في
    بطاقة بعينها لتجاوزه (انقر مجددًا للعودة إلى الافتراضي).

### العثور على النسخ المكررة { #finding-duplicates }

تفحص لوحة **Find duplicates already in the database** (العثور على النسخ المكررة في قاعدة البيانات) وحدة كاملة بحثًا عن سجلات أُدخلت
مرتين. اختر **Module** و**Method** (الطريقة)، ثم انقر **Scan** (فحص):

| الطريقة | ما تفعله |
|---|---|
| **Fast — title match (instant)** | تقارن العناوين. |
| **Cheap AI — embeddings, same language** | تقارن المعنى، ضمن لغة واحدة (نحو دقيقة). |
| **Smart AI — any language** | تحكم على الأزواج المرشحة بنموذج لغوي، عبر اللغات (بضع دقائق). |

لا تتوفر طرق الذكاء الاصطناعي إلا عندما تكون على الخادم خدمة ذكاء اصطناعي محلية مُعدّة؛ وإلا فإنها
تظهر باهتة. يعرض كل زوج يُعثر عليه درجة تشابه وزر **Merge** (دمج)، الذي يفتح
[نافذة الدمج](records.md#merging-duplicates) نفسها التي يفتحها السحب في القائمة.

## استيراد الملفات { #import-files }

يحوّل **Import files** الملفات والمجلدات إلى سجلات دفعةً واحدة. جزؤه العلوي هو
[Pending sync](writings-fulltext.md#pending-sync) (المزامنة المعلّقة)؛ أما الجزء السفلي، **Import files / folders by
name** (استيراد الملفات / المجلدات بالاسم)، فيعمل هكذا:

1. ضع الملفات أو المجلدات في **مجلد إسقاط** على الخادم وسمِّ كلًّا منها بصيغة
   [أمر جماعي](batch-commands.md) — مثلًا `t ?done Final report.pdf`.
2. أدخل **Drop folder** (مجلد الإسقاط، ويُتذكَّر للمرة القادمة) واختر **Default module** للأسماء
   التي لا تبدأ برمز وحدة.
3. انقر **Scan / preview** (فحص / معاينة). يعرض كل عنصر ما سينشئه، وأين سيذهب، أو لماذا لا يمكن
   استيراده.
4. انقر **Import** على عنصر واحد، أو **Import all** (استيراد الكل).

يُنقل **الملف** إلى مجلد المستودع 1 الخاص بالسجل الجديد ويُعاد تسميته بعنوانه؛ أما **المجلد** ف
يصبح مجلد السجل.

## مُعيد تسمية الصور { #image-renamer }

يساعدك **Image renamer** (مُعيد تسمية الصور) على ترتيب مجلد صور (لقطات شاشة، مسوحات، صور فوتوغرافية) على الخادم
قبل تصنيفها.

1. أدخل **Directory path** (مسار المجلد، مجلد على الخادم) وانقر **Load** (تحميل).
2. تنقّل بين الصور وأعطِ كلًّا منها **File name** (اسم ملف) ذا معنى — ويُحتفظ لك بالامتداد.
   إعادة التسمية تنقلك إلى الصورة التالية.

إنه مصمَّم للوحة المفاتيح:

| المفتاح | الإجراء |
|---|---|
| **←** / **h** | الصورة السابقة |
| **→** / **l** / **Space** | الصورة التالية |
| **r** / **F2** / **Enter** | تعديل الاسم |
| **Enter** (أثناء التعديل) | إعادة التسمية والانتقال إلى الصورة التالية |
| **Esc** | إلغاء التعديل |
| **d** / **Del** | حذف — دون تأكيد |
| **u** | التراجع عن آخر حذف أو إعادة تسمية |

تُنقل الصور المحذوفة جانبًا بدلًا من إتلافها، وهذا ما يجعل **u** ممكنًا.

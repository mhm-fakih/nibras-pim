# Raccourcis clavier

L'application web peut se piloter presque entièrement au clavier. Appuyez à tout moment sur **?** pour afficher la
fenêtre des raccourcis ; **Help & shortcuts** (Aide et raccourcis), dans la barre latérale, présente la même liste,
ainsi qu'un aide-mémoire Markdown.

Les raccourcis ne se déclenchent jamais pendant que vous tapez dans un champ — appuyez d'abord sur **Esc** pour en
sortir. Ils ignorent aussi les combinaisons avec **Ctrl**, **Alt** ou **⌘**.

## Généraux { #global }

| Touches | Action |
|---|---|
| **?** | Afficher / masquer la fenêtre des raccourcis |
| **/** | Aller au champ **Search everything…** (Tout rechercher…) |
| **g** puis une lettre | Aller à une page (voir ci-dessous) |
| **Esc** | Fermer une boîte de dialogue ou un formulaire, ou désélectionner la fiche courante |

## Aller à (appuyez sur **g**, puis…) { #go-to-press-g-then }

Appuyez sur **g**, puis sur la seconde touche dans un délai d'environ une seconde et demie.

| Touches | Mène à | Touches | Mène à |
|---|---|---|---|
| **g t** | Tasks (Tâches) | **g c** | Calendar (Calendrier) |
| **g g** | Goals (Objectifs) | **g k** | Kanban |
| **g n** | Notes | **g b** | All bookmarks (Tous les favoris) |
| **g j** | Journal | **g i** | Indicators (Indicateurs) |
| **g p** | Planner (Planificateur) | **g a** | Admin (Administration) |
| **g r** | Resources (Ressources) | **g m** | Import notes (Importer des notes) |
| **g w** | Writings (Écrits) | **g s** | Settings (Paramètres) |

## Dans la liste d'un module { #in-a-module-list }

| Touches | Action |
|---|---|
| **j** | Sélectionner la fiche suivante |
| **k** | Sélectionner la fiche précédente |
| **o** | Ouvrir la fiche sélectionnée |
| **n** | Nouvelle fiche |

## Avec une fiche sélectionnée { #with-a-record-selected }

| Touches | Action |
|---|---|
| **e** | Modifier la fiche |
| **f** puis **1** / **2** / **3** | Ouvrir le dossier de la fiche dans le dépôt 1 / 2 / 3 (sur le bureau du serveur) |

### Modification rapide { #quick-edit }

Changez un seul champ sans ouvrir le formulaire. Un petit sélecteur s'ouvre ; tapez pour filtrer, choisissez une
valeur, et elle est appliquée immédiatement.

| Touches | Définit |
|---|---|
| **p** | Priorité — tapez un nombre, puis **Enter** |
| **#** | Type |
| **?** | Statut (lorsqu'une fiche est sélectionnée, **?** définit le statut au lieu d'ouvrir l'aide) |
| **@** | Contexte |
| **d** | Département |
| **c** | Cours |
| **\*** | Activer / désactiver le favori |

**n**, **e** et les modifications rapides nécessitent l'autorisation d'écrire du contenu.

## Dans les zones de texte { #in-text-boxes }

| Touches | Où | Action |
|---|---|---|
| **Ctrl+Enter** | Barre **Quick note** (Note rapide) | Ajouter la note |
| **Ctrl+Enter** | Zone **Append to…** (Ajouter à…) sous un champ | Ajouter le texte à la suite |
| **Enter** | Commande de modification par lot, résumé de tâche sur un objectif, résumé du minuteur de sprint, la plupart des champs de dialogue | Valider |

## Galeries (Highlights, Flash cards) { #galleries-highlights-flash-cards }

| Touches | Action |
|---|---|
| **←** / **→** (ou **Page Up** / **Page Down**) | Carte précédente / suivante |
| **Home** / **End** | Première / dernière carte |
| **d** / **r** / **k** / **u** | Cartes mémoire : **Reviewed** / **Repeat** / **Keep** / **Unset** |

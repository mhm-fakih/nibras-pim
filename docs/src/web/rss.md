# RSS feeds

Each module has an RSS feed of its **bookmarked** records, so you can follow them in any feed
reader.

## Subscribing

1. Open the module you want (Tasks, Notes, Writings, …).
2. In the sidebar, under the module's reports, click **RSS (bookmarked)**. The feed opens in a new
   tab.
3. Copy the address from the browser's address bar and add it to your feed reader.

The feed lists the most recent bookmarked records of that module (up to 50 by default), newest
first, with each record's text as the item body. Titles and text in right-to-left scripts are marked
so that readers which honour it display them right-aligned.

!!! warning "Feeds are public"
    Feed readers can't sign in, so **feed addresses work without a password**. Anyone who can reach
    the server and knows the address can read the bookmarked records of that module. Keep that in
    mind when bookmarking, and don't share feed addresses widely.

## Hiding the feed link

An administrator can hide the **RSS (bookmarked)** link in
[Settings → Features](settings.md#pages-and-features) (**RSS feeds**). This only hides the link in
the sidebar; a feed address that is already known keeps working.

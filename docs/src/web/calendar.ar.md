# التقويم

لدى نبراس تقويمان: التقويم الصغير في الشريط الجانبي لكل وحدة، للانتقال إلى يوم ما، و
صفحة **Calendar** (التقويم) الكاملة، لتخطيط أسبوعك.

## التقويم المصغّر { #the-mini-calendar }

في أي عرض لوحدة، يعرض الشريط الجانبي تقويمًا مضغوطًا تحت مربع البحث.

- يعرض افتراضيًا **Last 2 weeks** (آخر أسبوعين: الأسبوع الماضي وهذا الأسبوع، بدءًا من الاثنين). انقر سهم
  التوسيع لرؤية **الشهر كاملًا** مع أرقام أسابيع ISO؛ ويُتذكَّر اختيارك.
- **نقطة** صغيرة تحت تاريخ تعني أن سجلات من الوحدة الحالية أُنشئت في ذلك اليوم.
- التاريخ **العريض** له مدخل يومية.
- اليوم الحالي محاط بدائرة.

**النقر على تاريخ** يفتح **اليومية الملخّصة** لذلك اليوم في وحدة Journal (اليوميات) — وينشئها إن
لم تكن موجودة بعد، فيكون هناك دائمًا يومية واحدة بالضبط لكل يوم تكتب فيها. إذا كانت وحدة Journal
معطّلة، فالنقر على تاريخ لا ينشئ شيئًا؛ وبدلًا من ذلك تسرد اللوحة الوسطى كل سجل من ذلك
اليوم في وحداتك المفعّلة.

!!! tip "تلميح"
    لتصفية القائمة الحالية على يوم واحد دون فتح يومية، استخدم بدلًا من ذلك عامل التصفية **On day** (في يوم) في
    أعلى القائمة.

## صفحة Calendar { #the-calendar-page }

افتح **Calendar** من الشريط الجانبي (أو اضغط **g c**). تعرض أسبوعًا (أو يومًا) من مدخلات **Journal** و
**Planner** (المخطِّط)، إضافةً إلى **السباقات** (sprints)، على شبكة زمنية.

### التنقّل { #moving-around }

- **‹** و**›** ترجعان أو تتقدمان أسبوعًا (أو يومًا)؛ و**Today** (اليوم) يعيدك إلى الحاضر.
- يعرض العنوان نطاق التواريخ ورقم **أسبوع ISO**.
- تقويم الشهر على اليمين ينقلك إلى أي تاريخ.
- خط أحمر يحدد الوقت الحالي.

### ضبط العرض { #adjusting-the-view }

| عنصر التحكم | الخيارات |
|---|---|
| **Week** / **Day** (أسبوع / يوم) | سبعة أيام بدءًا من الاثنين، أو يوم واحد |
| **Slot** (الخانة) | 15 أو 30 أو 60 دقيقة لكل صف |
| **From** / **To** (من / إلى) | أول ساعة وآخر ساعة معروضتين (افتراضيًا 07:00–21:00) |

يتذكّر متصفحك هذه الإعدادات.

### كيف تبدو المدخلات { #how-entries-look }

يُلوَّن كل مدخل حسب **نوعه** (تُضبط الألوان في صفحة
[Parameters](administration.md#parameters)). أما الإطار فيميّز بين الوحدات: مدخلات **المخطِّط**
لها إطار متقطع، ومدخلات **اليوميات** إطار متصل، و**السباقات** إطار مزدوج. مرّر المؤشر فوق مدخل
لترى وقته ووصفه؛ وتُعلَّم الخطط المتكررة بـ**⟳**.

### إضافة مدخل { #adding-an-entry }

1. انقر خانة — أو اضغط واسحب إلى الأسفل عبر عدة خانات لاختيار نطاق زمني.
2. في **New calendar entry** (مدخل تقويم جديد)، اختر **Module** (الوحدة: **Planner** أو **Journal**) واختياريًا
   **Type** (النوع). ويُتذكَّر آخر وحدة استخدمتها.
3. أدخل **Summary** (الملخص) و**Description** (الوصف) اختياريًا؛ واضبط **Start** (البدء) و**End** (الانتهاء) عند الحاجة.
4. اختياريًا **Link to goal** (ربط بهدف) أو **Link to task** (ربط بمهمة) (تُعرض العناصر ذات الإشارة المرجعية).
5. انقر **Create** (إنشاء).

تُضاف إلى المدخلات المنشأة هنا إشارة مرجعية تلقائيًا.

### تغيير مدخل { #changing-an-entry }

- **انقر** مدخلًا لفتحه في صفحة القراءة في علامة تبويب جديدة (السباق يفتح صفحة
  [Sprints](tasks-kanban-sprints.md#sprints)). استخدم **Edit** هناك لتغييره.
- **اسحب الحافة العليا أو السفلى** لمدخل لتغيير وقت بدئه أو انتهائه.

يستطيع مستخدمو القراءة فقط المشاهدة دون الإضافة أو تغيير الحجم أو الإزالة.

## الخطط المتكررة { #repeating-plans }

مدخل المخطِّط الذي يكون مفتاح **Repeats** (يتكرر) فيه مفعّلًا هو *سلسلة*: يرسم التقويم كل تكرار في
الوقت نفسه من اليوم دون تخزين كل واحد منها. ولا يصبح التكرار سجلًا مستقلًا إلا عندما
تفتحه أو تنقله أو تضيف إليه تعليقًا — فلا يكلّف عامٌ كامل من عادة يومية شيئًا حتى تلمسه.

لإزالة تكرار واحد، مرّر المؤشر فوقه وانقر **×** في زاويته (**Remove just this
occurrence** إزالة هذا التكرار فقط). لتغيير السلسلة كلها أو إنهائها، عدّل سجل المخطِّط الأصلي — انظر
[المهام والخطط المتكررة](records.md#repeating-tasks-and-plans).

## التقويمات في أماكن أخرى { #calendars-elsewhere }

- يمكن أن تتضمن [لوحة المعلومات](dashboards.md) منطقة **Calendar (filtered by type)** (تقويم مصفّى حسب النوع) — مثلًا
  أحداث "family" فقط — لعرضها على شاشة احتياطية.
- مدخلات المخطِّط التي مرّ تاريخ انتهائها، أو اقترب، تظهر في تقريري وحدة Planner
  **Overdue** (متأخرة) و**Due soon (7d)** (مستحقة قريبًا)، وفي
  [إشعارات سطح المكتب](settings.md#notifications) إذا فعّلتها.

# الحسابات والصلاحيات والإدارة

هذه الصفحة موجّهة إلى من يتولّون **المستخدمين** و**المفردات** في تثبيت نبراس:
المسؤولون، ومحررو المعاملات فيما يخص صفحة Parameters. إذا لم تكن إحدى الصفحات الموصوفة هنا في
شريطك الجانبي، فأنت لا تملك القدرة التي تحتاجها.

## الأدوار والقدرات { #roles-and-capabilities }

لكل مستخدم **دور** واحد. وما يستطيع الدور فعله هو مجموعة من **القدرات**:

| القدرة | تتيح لك |
|---|---|
| **Write content** (كتابة المحتوى) | إنشاء السجلات وتعديلها وحذفها واستيرادها؛ واستخدام Batch entry وImport files وImport notes وImage renamer وStatic website وMaintenance وTrash. |
| **Write parameters** (كتابة المعاملات) | تعديل الحالات والأنواع والسياقات في صفحة **Parameters** (المعاملات). |
| **Manage users** (إدارة المستخدمين) | استخدام صفحتي **Users** (المستخدمون) و**Roles & permissions** (الأدوار والصلاحيات). |
| **Admin tools** (أدوات الإدارة) | استخدام صفحة **Admin** (الإدارة). |
| **Settings** (الإعدادات) | استخدام صفحة **Settings**. |
| **Audit log** (سجل التدقيق) | عرض صفحة **Audit log** وقسم **History** (السجل التاريخي) لكل سجل. |

يستطيع أي مستخدم مسجّل الدخول قراءة كل الوحدات والبحث فيها وتصفحها، وكذلك صفحات القراءة (Today وCalendar
وKanban وDashboards وInsights وSprints وReports وBookmarks وHighlights وFlash cards وLocal notes).

تبدأ الأدوار الأربعة على النحو التالي:

| الدور | القدرات الافتراضية |
|---|---|
| **Admin** (مسؤول) | كل شيء — دائمًا، ولا يمكن تقليصها |
| **Data entry** (إدخال البيانات) | Write content |
| **Parameters data entry** (إدخال المعاملات) | Write parameters |
| **Read only** (للقراءة فقط) | لا شيء — القراءة فقط |

### تغيير ما يستطيع الدور فعله { #changing-what-a-role-can-do }

افتح **Roles & permissions** (من الشريط الجانبي). تعرض الشبكة الأدوار على الجانب والقدرات في
الأعلى. حدّد مربعًا أو ألغِ تحديده — يُحفظ التغيير ويسري فورًا. صف **Admin**
مقفل.

## المستخدمون { #users }

افتح **Users** لترى لكل شخص **Username** (اسم المستخدم) و**Name** (الاسم) و**Role** (الدور) و**Status** (الحالة: **Active** نشط /
**Disabled** معطّل).

- **Add user** (إضافة مستخدم) — أدخل **Username**، و**Display name** (الاسم المعروض) اختياريًا، و**Role**، و**Password**، و
  أبقِ **Active** مفعّلًا. انقر **Save** (حفظ).
- **Edit** (تعديل، أيقونة القلم) — غيّر أيًّا مما سبق. اترك **New password (leave blank to keep)** فارغًا للإبقاء على
  كلمة المرور الحالية.
- **عطّل** حساب شخص بإيقاف **Active** — فلا يعود قادرًا على تسجيل الدخول، لكن سجلّه التاريخي
  يبقى سليمًا.
- **Delete** (حذف، أيقونة سلة المهملات) يزيل الحساب بعد التأكيد.

!!! tip "تلميح"
    أعطِ كل شخص حسابه الخاص. يسجّل سجل التدقيق *من* غيّر ماذا، وهذا لا يفيد إلا إذا لم تكن
    الحسابات مشتركة.

## المعاملات { #parameters }

**Parameters** (المعاملات) هي المكان الذي تعيش فيه المفردات المشتركة: **الحالات** و**الأنواع** و**السياقات**
التي تُصنَّف بها السجلات، لكل وحدة. (الأقسام والمقررات وحدات كاملة قائمة بذاتها؛
انظر [الوحدات والسجلات](records.md).)

لكل قائمة:

- اكتب اسمًا في **New value…** (قيمة جديدة) و**رمزًا** قصيرًا، ثم انقر **Add value** (إضافة قيمة). الرموز هي ما
  تكتبه في [الأوامر](batch-commands.md) — `?done` و`#art` و`@home`.
- **انقر نقرًا مزدوجًا** على قيمة (أو استخدم **Rename** إعادة التسمية) لإعادة تسميتها.
- انقر مربع اللون (**Recolour** تغيير اللون) لاختيار لونها. تُستخدم الألوان في الشارات وفي
  [التقويم](calendar.md).
- انقر ★ (**Set as default for blank records** تعيينها افتراضية للسجلات الفارغة) لجعل القيمة افتراضية: تحصل عليها السجلات
  الجديدة المتروكة فارغة.
- **Remove this value** (إزالة هذه القيمة) يحذفها بعد التأكيد؛ وتظل السجلات الموجودة تعرضها إلى أن
  تُغيَّر.
- **Fill empty colours** (ملء الألوان الفارغة) يعطي كل قيمة بلا لون لونًا دفعةً واحدة.

## صفحة Admin { #admin-page }

تعطي **Admin** (وعنوانها **Administration**) نظرة عامة على البيانات:

- بطاقة لكل وحدة فيها **عدد السجلات**، ولكل حقل مصنَّف، عدد القيم المتاحة
  **المستخدَمة** فعلًا.
- **Rebuild search index** (إعادة بناء فهرس البحث) — يعيد بناء الفهرس الذي يقوم عليه [البحث الشامل](search.md#global-search). شغّله
  مرة واحدة على تثبيت جديد، أو إذا بدت نتائج البحث ناقصة. يُعرض التقدّم وسطر
  بالنتيجة.
- **Synced to clients** (ما يُزامَن إلى العملاء) — بالضبط ما ينبغي أن تعرضه تطبيقات الهاتف والطرفية وسطح المكتب:
  الأقسام ذات الأولوية 2 فما فوق، وأنواع كل وحدة مفعّلة بترتيب مزامنتها.
  قارنه بجهاز ما لاكتشاف نسخة قديمة. انظر [المزامنة](../concepts/sync.md).

## سجل التدقيق { #audit-log }

يسرد **Audit log** كل تغيير على كل سجل: عمليات الإدراج، وكل حقل حُدّث (القديم → الجديد)
وعمليات الحذف، مع وقتها ومن قام بها. ضيّق النتائج حسب **Module** (الوحدة)، و**Operation** (العملية: **Insert**، **Update**،
**Delete**)، و**Field** (الحقل)، وتاريخي **From** / **To** (من / إلى). استخدم **Previous** / **Next** (السابق / التالي) للتنقل بين الصفحات.

يظهر السجل التاريخي نفسه لسجل واحد في لوحة تفاصيله تحت **History**.

## سلة المهملات { #trash }

تسرد **Trash** (سلة المهملات) السجلات التي حُذفت — أو التي استُوعبت بالدمج (**Merged → #id**) — في جميع
الوحدات. انقر أيقونة الاستعادة لإعادة أحدها إلى مكانه. انظر
[الحذف والاستعادة](records.md#deleting-and-restoring).

## الصيانة { #maintenance }

تعرض **Maintenance** (الصيانة) أين تذهب مساحة التخزين وتقدّم طريقتين لاستعادتها. تعمل كلتاهما بالطريقة
نفسها: جدول مرتّب، ومربع اختيار لكل صف، و**Select all** / **Clear** (تحديد الكل / مسح)، وزر يذكر ما
سيستعيده قبل أن تنقره.

=== "مجلدات المستودع 1"

    يسرد **Heaviest repository 1 folders** (أثقل مجلدات المستودع 1) السجلات التي لها أكبر عدد من الملفات في
    مستودع العمل. حدّد بعضها وانقر **Move n to repo 2 — reclaims …** لنقل ملفاتها إلى
    مستودع الأرشيف. تبقى الأغلفة وملفات السحب (checkout) في مكانها. **Rescan** (إعادة الفحص) يحدّث القائمة.

=== "النص الكامل للموارد"

    يسرد **Longest resource full text** (أطول نص كامل للموارد) الموارد التي نصها المخزَّن هو الأكبر. حدّد بعضها وانقر
    **Move n to file — … out of the database**. يُكتب كل نص إلى ملف في مجلد المستودع 1
    الخاص بالمورد، ويُتحقَّق منه، وبعد ذلك فقط يُمسح من السجل. لا يعود النص يظهر
    في البحث في السجلات، لكنه يبقى على القرص. أي ملف موجود بالاسم نفسه يُنحّى جانبًا، ولا
    يُكتب فوقه أبدًا.

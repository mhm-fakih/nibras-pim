# الأهداف والعادات والمؤشرات

**الأهداف** تحدد ما تسعى إليه؛ و**المؤشرات** تقيس الأشياء عبر الزمن — من عادة
تسجّلها بيدك إلى رقم يحسبه لك الخادم كل ليلة.

## الأهداف { #goals }

الهدف سجل كأي سجل آخر (انظر [الوحدات والسجلات](records.md))، له **Code** (الرمز) و**Status** (الحالة)
و**Type** (النوع) و**% complete** (نسبة الإنجاز) و**Start** (البدء) و**End** (الانتهاء) وتاريخ **Completed** (الإنجاز).

ما يميّز الأهداف:

- **ضع إشارة مرجعية** على الأهداف التي تسعى إليها فعليًا. لا تُعرض إلا الأهداف ذات الإشارة المرجعية في منتقي
  **Goal** (الهدف) في المهمة، وعلى لوحة [Kanban](tasks-kanban-sprints.md#kanban) وفي مربع
  **Link to goal** في التقويم.
- تسرد لوحة تفاصيل الهدف مهامه تحت **Related** (ذات صلة)، وفيها مربع **+ Add a task to this goal…** (إضافة مهمة إلى هذا الهدف)
  — اكتب ملخصًا واضغط **Enter**.
- انقر الدائرة **✓** لتعليم الهدف منجزًا (وهذا يزيل إشارته المرجعية أيضًا).

## تتبّع العادات في هدف { #habit-tracking-on-a-goal }

يمكن أن يحمل الهدف **عادة** واحدة أو أكثر — مؤشرات يومية مرتبطة به.

1. افتح الهدف.
2. إن لم تكن له عادة بعد، فانقر **Track this goal** (تتبّع هذا الهدف). يضيف هذا مؤشر عادة يوميًا مرتبطًا
   بالهدف.
3. في كل يوم، أدخل **Value** (القيمة) (واختياريًا **Date** التاريخ و**Note** ملاحظة — *What did you do
   today?* ماذا فعلت اليوم؟)، ثم انقر **Log** (تسجيل). استخدم **Log another** (تسجيل آخر) لمزيد من المدخلات في اليوم نفسه.

يعرض الهدف بعد ذلك خريطة حرارية لأيامك، ملوّنة بحسب مقدار ما سجّلته — الأحمر لعدم وجود مدخل،
والبرتقالي للقليل، ودرجات الأخضر للأكثر — مع سجل يومي تحتها.

!!! tip "عرض العادات على شاشة"
    فعّل **Show habit heatmap on dashboards** في نموذج الهدف، ثم أضف منطقة **Goals habit
    heatmap** إلى [لوحة معلومات](dashboards.md).

## المؤشرات { #indicators }

افتح **Indicators** (المؤشرات) من الشريط الجانبي (أو **g i**). للصفحة أربعة أجزاء:

1. **KPI cards** (بطاقات مؤشرات الأداء) — أرقام قياسية تُقرأ بلمحة عبر سجلاتك.
2. **Needs data** (تحتاج بيانات) — مؤشرات مراقَبة ليست لها قيمة بعد للفترة الحالية (يوم، أسبوع…).
   تعرض كل بطاقة آخر قيمة وتاريخها؛ أدخل قيمة (أو اقبل **Proposed value** القيمة المقترحة) وانقر
   **Confirm** (تأكيد).
3. **Monitored indicators** (المؤشرات المراقَبة) — مخطط خطي لكل مؤشر. المؤشرات التي تشترك في **Category** (الفئة)
   تُرسم معًا في مخطط واحد.
4. **All indicators** (كل المؤشرات) — كل مؤشر معرَّف؛ وتعلّم ★ المؤشرات المراقَبة. انقر أيًّا منها لتعديله.

### إنشاء مؤشر { #creating-an-indicator }

انقر **New indicator** (مؤشر جديد) واملأ:

| الحقل | المعنى |
|---|---|
| **Name**، **Code**، **Description** | ما الذي يقيسه |
| **Frequency (daily / weekly)** | كم مرة تُتوقَّع قيمة (يوميًا / أسبوعيًا) |
| **Scale / unit** | مثل *minutes* أو *pages* أو *kg* |
| **Category** | رمز قصير؛ المؤشرات ذات الفئة نفسها تتشارك مخططًا |
| **Colour** | لون الخط (يُملأ تلقائيًا إن تُرك فارغًا) |
| **Actively monitored** | مراقبته في هذه الصفحة وفي **Needs data** |
| **Goal** | ربطه بهدف لاستخدامه متتبّعًا للعادة |

يحصل المؤشر على أرقامه بإحدى أربع طرق، تظهر شارةً على كل بطاقة:

| النوع | من أين تأتي القيمة |
|---|---|
| **MANUAL** | تكتبها بنفسك. |
| **QUERY** | استعلام على سجلاتك، يُضبط في حقل **Query**. |
| **FILE** | عدد الملفات في مجلد على الخادم (**Folder path**، مصفّاة حسب **Extensions**). |
| **SCRIPT** | أمر shell صغير على الخادم يطبع رقمًا. |

لمؤشرات QUERY وFILE وSCRIPT **يقترح** التطبيق قيمة وينتظر منك تأكيدها.
فعّل **Auto-collect** (الجمع التلقائي) ليحسب الخادم القيمة ويحفظها بنفسه مرة يوميًا، في
الوقت المضبوط في [Settings → Indicator auto-collection](settings.md#indicator-auto-collection).

!!! note "ملاحظة"
    مؤشرات الاستعلام والمجلد والسكربت تعمل على الخادم، لذا يُعدّها عادةً من
    يتولّى أمره.

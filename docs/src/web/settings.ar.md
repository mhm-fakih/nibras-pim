# الإعدادات

تضبط **Settings** (الإعدادات؛ من الشريط الجانبي، أو **g s**) تطبيق الويب لكل من يستخدم هذا التثبيت.
تحتاج إلى قدرة **Settings** لفتحها — وعادةً لا يملكها إلا المسؤولون. تُحفظ معظم التغييرات
فور تبديل مفتاح أو الضغط على **Enter** أو مغادرة حقل؛ أما الأقسام التي فيها زر **Save** فتُحفظ
عندما تنقره.

!!! note "بعض التفضيلات خاصة بمتصفحك"
    تُتذكَّر بعض الأشياء لكل متصفح بدلًا من حفظها في Settings: عرض الشريط الجانبي و
    القائمة، وما إذا كان الشريط الجانبي مطويًا، وعدد السجلات **Per page**، وحجم التقويم المصغّر، و
    عرض صفحة Calendar، وحالة طيّ شريط **Quick note**، وأحجام النص في صفحات القراءة،
    وفترات Insights — وما إذا كنت *أنت* تتلقى إشعارات سطح المكتب.

## التطبيق { #application }

**App name** (اسم التطبيق) هو الاسم الظاهر في أعلى الشريط الجانبي وفي علامة تبويب المتصفح (الافتراضي
*Nibras*).

## الصفحات والميزات { #pages-and-features }

تُظهر **Pages** (الصفحات) صفحات الأدوات في الشريط الجانبي أو تخفيها: Calendar وKanban وDashboards وAll bookmarks و
Indicators وInsights وSprints وReports وMaintenance وParameters وAdmin وBatch entry وImport files و
Import notes وImage renamer وStatic website وAudit log. أما Settings وHelp فمتاحتان دائمًا.
إخفاء صفحة يزيلها من الشريط الجانبي فقط.

تعطّل **Features** (الميزات) أجزاءً من الواجهة ليست صفحات:

| الميزة | ما تتحكم فيه |
|---|---|
| **RSS feeds** (موجزات RSS) | رابط **RSS (bookmarked)** في الشريط الجانبي. |
| **Standard reports per module** (التقارير القياسية لكل وحدة) | اختصارات التقارير المدمجة في الشريط الجانبي (تبقى عمليات بحثك المحفوظة). |
| **Release codename** (الاسم الرمزي للإصدار) | لقب الإصدار بجانب رقم الإصدار. |
| **Resource detail fields** (حقول تفاصيل الموارد) | Full text وHighlights وComments وURL وRead on، في الموارد. إخفاؤها لا يغيّر أي بيانات. |
| **Repository 2** / **Repository 3** (المستودع 2 / 3) | زرّا **Repo2** / **Repo3** في السجلات. |
| **New resource from a URL** (مورد جديد من رابط) | زر الرابط بجانب **New** في Resources. |

## الإشعارات { #notifications }

- **Enable desktop notifications (overdue tasks/planners, missing journal entry)** (تفعيل إشعارات سطح المكتب) — يفعّل
  إشعارات متصفحك لهذا التطبيق. في المرة الأولى، يطلب المتصفح الإذن. وإذا قال
  **Notifications are blocked for this site** (الإشعارات محظورة لهذا الموقع)، فاسمح بها في إعدادات الموقع في المتصفح.
- **Journal reminder hour** (ساعة تذكير اليومية) — بعد هذه الساعة (بنظام 24 ساعة، الافتراضي 17)، تُذكَّر مرة واحدة في
  اليوم إن لم تكتب مدخل يومية. انقر **Save**.

عند تفعيل الإشعارات، يتحقق التطبيق كل بضع دقائق من المهام والخطط **المتأخرة** أو **المستحقة خلال أسبوع**،
وينبّهك كل 15 دقيقة عندما لا يكون أي [مؤقّت](tasks-kanban-sprints.md#time-tracking)
قيد التشغيل.

!!! note "ملاحظة"
    لا تعمل الإشعارات إلا أثناء فتح تطبيق الويب في علامة تبويب في المتصفح. ويُخزَّن مفتاح التشغيل/الإيقاف
    في متصفحك، فيختار كل شخص (وكل متصفح) على حدة.

## الجمع التلقائي للمؤشرات { #indicator-auto-collection }

**Run time** (وقت التشغيل) هو الوقت الذي تحسب فيه المؤشرات التي فُعّل فيها **Auto-collect** قيمتها وتحفظها كل
يوم (الافتراضي 23:50). انظر [الأهداف والعادات والمؤشرات](goals-indicators.md#creating-an-indicator).

## الإلحاق بالوصف { #append-to-description }

**Prefix** (البادئة) و**Suffix** (اللاحقة) اللتان تحيطان بالنص المضاف عبر مربع **Append to…** تحت وصف السجل
أو ملاحظاته. اكتب `\n` لسطر جديد؛ والبادئة الافتراضية تبدأ فقرة جديدة.

## الوحدات { #modules }

يسرد جدول **Modules** (الوحدات) كل أنواع السجلات. لكل منها:

| العمود | المعنى |
|---|---|
| **Module** | مفتاحها الداخلي (ثابت). |
| **Label** | الاسم الظاهر في الشريط الجانبي والقوائم. |
| **Code** | رمز قصير يصل إلى 4 أحرف (مثل `T`) يُستخدم في الأوامر وأسماء الملفات وفي التطبيقات. يجب أن يكون فريدًا. |
| **Color** | لون تمييز الوحدة، ويظهر شريطًا على صفوف القوائم. |
| **Order** | الموضع في الشريط الجانبي. |
| **Sync order** | الترتيب الذي تُسلَّم به معاملات الوحدة إلى تطبيقي الهاتف وسطح المكتب. |
| **Enabled** | إظهار الوحدة أو إخفاؤها في كل مكان. |
| **Bucket /100**، **Bucket by type** | كيف تُرتَّب مجلدات سجلات الوحدة في المستودعات (مجمّعة حسب مئات المعرّفات، و/أو حسب النوع). |

عدّل **Label** أو **Code** أو **Order** أو **Sync order**، ثم اضغط **Enter** أو انقر
**Save** في الصف. أما المفاتيح والألوان فتُحفظ فورًا.

!!! warning "تعطيل وحدة"
    تختفي الوحدة المعطّلة من الشريط الجانبي وصفحة Today وقوائم الأنواع في التطبيقات.
    لا تُحذف سجلاتها — أعد تفعيلها فتعود. وعندما تكون **Journal** معطّلة، فإن النقر
    على يوم في التقويم المصغّر لا يعود ينشئ يومية لذلك اليوم.

لا تُضبط الحالات والأنواع والسياقات هنا بل في صفحة [Parameters](administration.md#parameters).

## المستودعات { #repositories }

المجلدات على الخادم التي تعيش فيها ملفات السجلات:

- **Repo 1 — sandbox / portable**، **Repo 2 — main**، **Repo 3 — dismissed**.
- **Checkout folder — bookmark symlinks** (مجلد السحب) — حيث توضع روابط مجلدات السجلات ذات الإشارة المرجعية.
- **File-explorer command** (أمر مستكشف الملفات) — البرنامج الذي تشغّله أزرار **Repo** على سطح مكتب الخادم.

انقر **Save**. هذه مسارات على جهاز الخادم، لذا يضبطها عادةً مرة واحدة من
ثبّته.

## الملاحظات المحلية { #local-notes }

**Notes folder** (مجلد الملاحظات) هو مجلد ملاحظات Markdown المعروض في [Local notes](import-capture.md#local-notes)
— مسار على الخادم؛ اتركه فارغًا للقيمة الافتراضية. يذكر التلميح تحت الحقل عدد الملاحظات
التي عُثر عليها، أو أن المجلد غير موجود. أما **Tag bank file (fallback only)** (ملف بنك الوسوم، احتياطي فقط) فلا حاجة إليه إلا إذا
لم تكن مقرراتك تحمل **Note tags** بعد.

## التصدير { #export }

- **Open the file after "Export to file"** (فتح الملف بعد التصدير إلى ملف) — فتح ملف السحب على سطح مكتب الخادم بعد
  تصدير يدوي.
- **Open the file after a new calendar-day journal is auto-exported** (فتح الملف بعد التصدير التلقائي ليومية يوم جديد) — الشيء نفسه، عندما ينشئ النقر على يوم
  يومية جديدة لذلك اليوم.

## عند وضع إشارة مرجعية { #on-bookmarking }

إجراءان اختياريان عند وضع إشارة مرجعية على سجل (كلاهما **Off** معطّل افتراضيًا):

- **Create a symbolic link in the checkout folder** (إنشاء رابط رمزي في مجلد السحب) — رابط إلى مجلد المستودع 1 الخاص بالسجل،
  مسمّى برمز وحدته ومعرّفه (مثل `W18`)، مع كتابة نص السحب الخاص به بجانبه.
- **Open the record's checkout text** (فتح نص السحب للسجل) — كتابة ملف نص السجل وفتحه.

إزالة الإشارة المرجعية تزيل رابطها دائمًا.

## المهام وتفضيلات أخرى { #tasks-and-other-preferences }

| الإعداد | المعنى |
|---|---|
| **Auto-stop a timer after (minutes)** (إيقاف المؤقّت تلقائيًا بعد) | أقصى مدة لجلسة تتبّع الوقت (الافتراضي 60). |
| **Language codes** (رموز اللغات) | رموز مفصولة بفواصل يمكن استخدامها وسومَ `'xx` في الأوامر والبحث (الافتراضي `ar,en,fr,fa,de`). انظر [اللغات](../concepts/languages.md). |
| **Today page: records per column** (صفحة Today: سجلات لكل عمود) | عدد السجلات المنشأة والمعدّلة التي تعرضها كل وحدة في Today (الافتراضي 5، وبحد أقصى 50). |
| **Status on completion** (الحالة عند الإنجاز) | الحالة التي تنتقل إليها المهمة عند تحديد مربع إنجازها — في السجل، أو في مراجعة السباق أو من الهاتف. **Leave unchanged** (اتركها دون تغيير) للإبقاء على الحالة كما هي. |

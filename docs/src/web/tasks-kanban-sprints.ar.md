# المهام وKanban والسباقات

المهام هي حيث يُنجز العمل. تتناول هذه الصفحة الميزات الخاصة بالمهام، ولوحة **Kanban**
التي تعرض المهام تحت أهدافها، و**تتبّع الوقت**، و**السباقات** (Sprints) للالتزام بكتلة من
العمل.

## المهام باختصار { #tasks-in-brief }

إلى جانب الحقول المشتركة، للمهمة:

| الحقل | الاستخدام |
|---|---|
| **Status** (الحالة) | أين تقف (قائمة حالاتك الخاصة — انظر [Parameters](administration.md#parameters)). |
| **Goal** (الهدف) | الهدف ذو الإشارة المرجعية الذي تخدمه. |
| **% complete** (نسبة الإنجاز) | التقدّم. |
| **Planned duration (min)** (المدة المخطط لها بالدقائق) | تقديرك بالدقائق؛ وتجمعها السباقات. |
| **Start**، **End** (البدء، الانتهاء) | التواريخ. المهمة التي تجاوزت تاريخ انتهائها تظهر في تقرير **Overdue**. |
| **Urgent** (عاجل) | علامة منفصلة عن الأولوية. |
| **Order #** (رقم الترتيب) | الموضع بين مهام الهدف. |
| **Repeats** (يتكرر) | انظر [المهام المتكررة](records.md#repeating-tasks-and-plans). |
| **People** (الأشخاص) | جهات الاتصال التي تتعلق بها المهمة (عندما تكون Contacts مفعّلة). |

### إنجاز مهمة { #completing-a-task }

انقر الدائرة **✓** في لوحة التفاصيل (**Click to mark complete** انقر لتعليمها منجزة). يسجّل هذا تاريخ
الإنجاز ويزيل الإشارة المرجعية عن المهمة. وإذا ضبط المسؤول **Status on completion** في
[الإعدادات](settings.md#tasks-and-other-preferences)، فإن المهمة تنتقل أيضًا إلى تلك الحالة. انقر مجددًا
لإعادة فتحها.

### ربط المهام بالأهداف { #linking-tasks-to-goals }

اختر هدفًا في منتقي **Goal** في نموذج المهمة (لا تُعرض إلا الأهداف ذات الإشارة المرجعية). ويمكنك أيضًا
إضافة مهام مباشرةً من هدف: افتح الهدف واكتب في **+ Add a task to this goal…**، ثم اضغط
**Enter**.

المهمة التي لها هدف تحصل على زر **+ Subtask** (مهمة فرعية). يطلب **Summary** (ملخصًا) وينشئ مهمة جديدة
على الهدف نفسه، مرتّبة مباشرةً بعد المهمة الأم.

## تتبّع الوقت { #time-tracking }

في لوحة تفاصيل المهمة:

1. انقر **Track** (تتبّع) لبدء جلسة. تظهر ساعة تعمل.
2. اختياريًا اكتب **Summary (optional)** (ملخصًا اختياريًا) لما فعلته.
3. انقر **Stop** (إيقاف) (أو اضغط **Enter** في مربع الملخص).

الإيقاف ينشئ مدخل **Journal** مرتبطًا بالمهمة، يغطي الجلسة — ويظهر تحت سجلات
**Related** للمهمة وعلى التقويم. وبدء مؤقّت على مهمة أخرى يوقف المؤقّت
الحالي ويحفظه أولًا.

!!! note "المؤقّتات المنسية"
    تتوقف الجلسة من تلقاء نفسها بعد مدة قصوى (60 دقيقة ما لم تُغيَّر في
    [الإعدادات](settings.md#tasks-and-other-preferences))، وتُحفظ على أنها انتهت عند ذلك الحد.
    ومع تفعيل [إشعارات سطح المكتب](settings.md#notifications)، يذكّرك التطبيق أيضًا كل
    15 دقيقة عندما لا يعمل أي مؤقّت.

## Kanban { #kanban }

تعرض **Kanban** (من الشريط الجانبي، أو **g k**) **الأهداف ذات الإشارة المرجعية ومهامها**، عمودًا لكل
**قسم**.

- يسرد كل عمود **Goals** (أهدافه)، مع مهام كل هدف المفتوحة متداخلةً تحت بطاقة الهدف.
- يسرد **Tasks — no goal** (مهام بلا هدف) المهام في ذلك القسم غير المرتبطة بهدف معروض.
- تظهر المهام إذا كانت عليها إشارة مرجعية *أو* كانت تنتمي إلى هدف عليه إشارة مرجعية.
- تبقى المهام المنجزة 7 أيام، مشطوبةً، ثم تختفي.
- داخل القائمة، تأتي المهام المفتوحة أولًا، ثم حسب الأولوية والأحدث.

انقر بطاقة للانتقال إلى وحدتها. إذا كانت اللوحة فارغة، فضع إشارات مرجعية على بعض الأهداف أو المهام.

!!! tip "أبقِ المهام مرتبطة بالأهداف"
    صُممت اللوحة لإبراز المهام التي بلا هدف. ربط مهمة بهدف ينقلها تحت
    بطاقة ذلك الهدف.

## السباقات { #sprints }

**السباق** (sprint) كتلة مؤرَّخة من العمل الملتزَم به — مثلًا *صباح الثلاثاء* — مأخوذة من مهامك
ذات الإشارة المرجعية. افتح **Sprints** (السباقات) من الشريط الجانبي.

### إنشاء سباق { #creating-a-sprint }

1. انقر **New sprint** (سباق جديد).
2. أعطه **Name** (اسمًا، اختياريًا)، و**Start** (بداية) و**End** (نهاية).
3. انقر **Create**.

يظهر السباق أيضًا على [التقويم](calendar.md) كتلةً.

### الالتزام بالمهام { #committing-tasks }

تسرد اللوحة اليمنى، **Bookmarked tasks** (المهام ذات الإشارة المرجعية)، المهام غير المنجزة ذات الإشارة المرجعية التي ليست في السباق بعد،
والأكثر تأجيلًا أولًا. حدّد ما تريده وانقر **Commit n (time)** (التزم بـn).

تعرض لوحة السباق بعد ذلك:

- **Planned** (المخطَّط) — إجمالي المدة المخطط لها للمهام الملتزَم بها.
- **Window** (النافذة) — طول السباق. إذا كانت الخطة أطول من النافذة، فيذكر تحذير ذلك.
- **n/m done** (n/m منجزة) وشريط تقدّم.
- ملاحظة تسرد أي مهام **counted at the default** (محسوبة بالقيمة الافتراضية) لأنها بلا مدة مخطط لها.
- **slipped n×** (تأجّلت n مرة) على المهام التي التُزم بها في سباقات سابقة ولم تُنجز.

لكل مهمة ملتزَم بها زر **Track** لتتبّع الوقت و× لـ**Remove from this
sprint** (إزالتها من هذا السباق).

### المراجعة { #reviewing }

حدّد مربع اختيار المهمة عند إنجازها — فالتحديد *هو* المراجعة، وهو ينجز المهمة. عندما
ينتهي السباق، انقر **Close review** (إغلاق المراجعة) لقفله (**Reviewed** روجع). و**Re-open** (إعادة الفتح) يفتح قفله.

!!! warning "تحذير"
    أيقونة سلة المهملات (**Delete this sprint** حذف هذا السباق) تحذف السباق فورًا، دون سؤال.

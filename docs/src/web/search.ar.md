# البحث وعوامل التصفية والتقارير

هناك أربع طرق للعثور على السجلات، من الأسرع إلى الأقوى:

1. **عوامل تصفية القائمة** في الوحدة التي أنت فيها.
2. **اختصارات التقارير** و**عمليات البحث المحفوظة** في الشريط الجانبي.
3. صفحة **Search** (البحث)، عبر كل الوحدات وملاحظاتك المحلية والملفات على الخادم.
4. صفحة **Reports** (التقارير)، لجداول تختار أعمدتها ويمكنك طباعتها.

## تصفية قائمة وحدة { #filtering-a-modules-list }

في أعلى كل قائمة وحدة:

| عنصر التحكم | ما يفعله |
|---|---|
| مربع **Search …** (بحث) | يجد السجلات التي يحتوي نصها على ما تكتبه. تأتي أولًا السجلات التي يبدأ عنوانها بما كتبت، ثم التي يحتوي عنوانها عليه، ثم البقية. أثناء نشاط البحث، يعرض كل صف *أين* وقعت المطابقة (مثل **Description:** …) مع الكلمة بخط عريض. |
| **Active only** (النشطة فقط — Tasks وGoals) | مفعّل افتراضيًا: يعرض فقط السجلات التي حالتها مُعلَّمة نشطة، والسجلات التي لا حالة لها. وعندئذ لا تعرض قائمة **Status** إلا الحالات النشطة. ألغِ تحديده لترى العمل المنتهي أيضًا. |
| **Status**، **Type** (الحالة، النوع) | عرض حالة واحدة أو نوع واحد (في الوحدات التي تملكهما). و**Any** (أي) يلغي ذلك. |
| **Context** (السياق — Tasks) | عرض مهام سياق واحد. |
| **Priority** (الأولوية) | عرض أولوية واحدة، **P0**–**P5**. |
| ☆ (**Bookmarked only** ذات الإشارة المرجعية فقط) | عرض السجلات ذات الإشارة المرجعية فقط. |
| **On day** (في يوم) | عرض السجلات التي تنتمي إلى تاريخ واحد. تستخدم اليوميات والخطط تاريخها الخاص؛ وتستخدم الوحدات الأخرى تاريخ الإنشاء. |

عندما تفتح قائمة **Status** أو **Type** أو **Context** أو **Priority**، يعرض كل خيار عدد السجلات التي
سيعطيها، محسوبًا مع عوامل التصفية الأخرى التي ضبطتها؛ والرقم بجانب **Any** هو المجموع. والخيار الذي
يعرض 0 سيُفرغ القائمة.

تظهر عوامل تصفية التقارير والأيام النشطة شاراتٍ تحت عوامل التصفية؛ انقر × على الشارة لإزالتها.
ويُعرض عدد السجلات المطابقة (**n items**) في الأسفل، بجانب أداة التنقل بين الصفحات، ومعه اختيار
**Per page** (لكل صفحة) — 10 أو 25 أو 50 أو 100 أو 200 صف، ويتذكّره متصفحك.

## اختصارات التقارير في الشريط الجانبي { #report-shortcuts-in-the-sidebar }

تحت **‹Module› reports** (تقارير الوحدة) يقدّم الشريط الجانبي عوامل تصفية جاهزة للوحدة الحالية. يعرض كل منها
عدد السجلات المطابقة؛ وتظهر الفارغة منها باهتة.

| التقرير | يعرض |
|---|---|
| **★ Bookmarked** | السجلات ذات الإشارة المرجعية |
| **🚩 Urgent** | المهام العاجلة |
| **No status** / **No type** | السجلات التي لا يزال ينقصها ذلك التصنيف (بلا حالة / بلا نوع) |
| **No department** / **No priority** | السجلات التي لم تُصنَّف بقسم أو لم تُعطَ أولوية بعد |
| **With tags** | السجلات التي لها وسم واحد على الأقل |
| **Overdue** / **Due soon (7d)** | السجلات التي مرّ تاريخ انتهائها / يقع خلال أسبوع |
| **High priority (≥3)** | الأولوية 3 فما فوق |
| **Recently created** / **Recently updated** | النشاط الحديث (المنشأة مؤخرًا / المحدّثة مؤخرًا) |

لا تُسرد إلا التقارير المنطقية للوحدة (مثلًا، **Overdue** فقط حيث يكون
للسجلات تاريخ انتهاء). ويستطيع المسؤول إخفاء هذا القسم في
[Settings → Features](settings.md#pages-and-features).

رابط **RSS (bookmarked)** تحت التقارير موصوف في [موجزات RSS](rss.md).

## عمليات البحث المحفوظة { #saved-searches }

تحت التقارير، تسرد **Saved searches** (عمليات البحث المحفوظة) عمليات البحث الخاصة بك للوحدة الحالية. انقر إحداها
لتشغيلها. انقر الترس (**Manage saved searches** إدارة عمليات البحث المحفوظة) لإضافتها أو تعديلها أو حذفها:

1. انقر **New report** (تقرير جديد).
2. أعطه **Name** (اسمًا) و**Priority** (أولوية، تُستخدم للترتيب).
3. اختر **Query type** (نوع الاستعلام):
    - **Search form** (نموذج بحث) — مجموعة من عوامل تصفية القائمة، مكتوبة معاملاتٍ، مثل
      `bookmarked=true&highPriority=true`. تشغيله يصفّي القائمة فحسب.
    - **HQL** — استعلام على سجلات التطبيق، مثل `from Task where bookmarked = true`. وتظل عمليات البحث
      المحفوظة المكتوبة لتطبيق نبراس القديم تعمل: تُكيَّف استعلاماتها مع السجلات الحالية عند تشغيلها.
    - **SQL (native)** — استعلام خام على قاعدة البيانات.
4. انقر **Preview** (معاينة) لتجربته، ثم **Save**.

الاستعلامات التي تُرجع سجلات تعرضها بطاقاتٍ في اللوحة الوسطى — انقر إحداها لفتحها، أو ×
للعودة إلى القائمة. أما النتائج الأخرى (الأعداد، الأعمدة) فتُفتح في نافذة جدول.

!!! warning "SQL أداة قوية"
    عملية بحث محفوظة بـSQL أصلي تنفّذ بالضبط ما تكتبه. والعبارة التي تغيّر البيانات تُبلغ
    "*n* row(s) affected" — وقد غيّرتها فعلًا. استخدم **Preview** بحذر، وفضّل
    **Search form** أو **HQL** عندما تريد الاطلاع فقط.

## البحث الشامل { #global-search }

تبحث صفحة **Search** (البحث) في كل الوحدات دفعةً واحدة، وكذلك في
[مجلد ملاحظاتك المحلية](import-capture.md#local-notes) وفي الملفات المحفوظة على الخادم. افتحها بالعدسة المكبّرة
(**Search everything**، ابحث في كل شيء) في السطر الأخير من الشريط الجانبي، أو اضغط **/** من أي مكان.

املأ ما تعرفه واضغط **Enter** في أي حقل، أو انقر **Search**:

| الحقل | المعنى |
|---|---|
| **Words** (الكلمات) | النص المراد البحث عنه. |
| **Priority** (الأولوية) | أولوية واحدة، **P1**–**P5**، أو **Any** (أي). |
| **Status code**، **Type code**، **Context code** (رمز الحالة، النوع، السياق) | الرمز القصير لحالة أو نوع أو سياق — الذي يظهر بجانب اسمه، مثل `done` و`art` و`home`. |
| **Bookmarked only** (ذات الإشارة المرجعية فقط) | السجلات ذات الإشارة المرجعية فقط. |
| **Near-duplicates** (شبه المكررة) | البحث عن سجلات تقول الشيء نفسه مسبقًا — انظر النصيحة أدناه. |

بجانب زر **Search** تعرض الصفحة البحث سطرًا نصيًا واحدًا (مثلًا `linux p4 ?done *`). ويدخل هذا السطر
نفسه في عنوان الصفحة، فيمكن حفظ البحث في إشارات المتصفح المرجعية أو تكراره.

تحت النموذج، يختار **Search in** (البحث في) أين يُبحث عن النص. **All** (الكل) هو الافتراضي؛ انقر واحدًا
أو أكثر من الخيارات الأخرى للتضييق:

| الشارة | تبحث في |
|---|---|
| **Title / summary** (العنوان / الملخص) | عناوين السجلات وملخصاتها؛ والسطر الأول للملاحظة المحلية واسم ملفها ووسومها. |
| **Description / notes** (الوصف / الملاحظات) | أوصاف السجلات وملاحظاتها ونصوصها الأخرى؛ وبقية الملاحظة المحلية. |
| **File names** (أسماء الملفات) | أسماء الملفات والمجلدات في المستودعات وفي المجلدات المرافقة للملاحظات. |
| **File contents** (محتوى الملفات) | النص المقروء من تلك الملفات (PDF والمستندات والنصوص…). |

تُجمَّع النتائج حسب الوحدة، مع تمييز الكلمات المطابقة؛ وتظهر المطابقات من مجلد ملاحظاتك تحت
**Local notes**، والملفات تحت **Files** (الملفات). انقر نتيجة لفتحها.

### الملفات { #files }

تسرد مجموعة **Files** الملفات المطابقة مع مصدرها ومجلدها وحجمها (**name match** حين يطابق الاسم وحده)،
ومقتطفًا من النص حول المطابقة.

- ضيّق القائمة بشارات المصدر (**Repo 1** و**Repo 2** و**Repo 3** و**Note files** — ملفات الملاحظات) وبقائمة
  **Type** (**PDF** و**Documents** — مستندات، و**Spreadsheets** — جداول بيانات، و**Slides** — شرائح،
  و**Text** و**Audio** و**Video** و**Images**).
- الشارة في طرف الملف تسمّي السجل (أو الملاحظة) الذي ينتمي إليه — انقرها لفتح ذلك السجل.
- الأيقونتان **Open the file** (فتح الملف) و**Open its folder** (فتح مجلده) تفتحانهما على الحاسوب الذي
  يعمل عليه الخادم.

تُضبط المجلدات التي يُبحث فيها، وأنواع الملفات التي يُقرأ محتواها، في
[Settings → File search](settings.md#file-search). لا يُبحث في الملفات إلا عن الكلمات الحرة؛ أما الرموز
وعوامل التصفية فتنطبق على السجلات.

### رموز التصفية { #filter-tokens }

يقبل مربع **Words** أيضًا **رموز التصفية**، ممزوجةً بالنص الحر — وحقول النموذج الأخرى تكتب بعضها نيابةً
عنك فحسب:

| الرمز | المعنى | مثال |
|---|---|---|
| `p4` | الأولوية 4 | `p4 linux` |
| `#code` | رمز النوع | `#art budget` |
| `?code` | رمز الحالة | `?done report` |
| `@code` | رمز السياق | `@home` |
| `dCODE` | رمز القسم | `dA` |
| `cCODE` | رمز المقرر | `cALG` |
| `*` / `*-` | عليه إشارة مرجعية / ليس عليه | `* travel` |
| `!` / `!-` | عاجل / غير عاجل | `! invoice` |
| `'xx` | اللغة (رموز من الإعدادات) | `prayer 'ar` |

لا يُعامَل `d…` و`c…` عاملَي تصفية إلا عندما يكون الرمز موجودًا فعلًا، فتظل الكلمات العادية التي تبدأ
بهذين الحرفين تُبحث نصًا.

!!! tip "تحقّق من النسخ المكررة قبل الإضافة"
    حدّد **Near-duplicates** (أو ابدأ الكلمات بـ`~`) للعثور على سجلات *مشابهة* بدلًا من المطابقات التامة، مثل
    `~ hand over the old laptop`. تعرض كل نتيجة نسبة تشابه مئوية — وهذا مفيد قبل أن تنشئ سجلًا قد يكون
    موجودًا بالفعل. ولا تدخل الملاحظات والملفات في البحث عن شبه المكرر.

!!! note "لا نتائج على الإطلاق؟"
    إذا لم تجد صفحة Search شيئًا وعرضت تحذيرًا بأن **the search index is empty** (فهرس البحث فارغ)، فعلى
    المسؤول أن ينقر **Rebuild search index** في صفحة [Admin](administration.md#admin-page)
    مرة واحدة.

## يوم عبر كل الوحدات { #a-day-across-all-modules }

انقر تاريخًا في التقويم المصغّر في الشريط الجانبي. عندما تكون وحدة Journal مفعّلة، يفتح هذا يومية ذلك
اليوم (انظر [التقويم](calendar.md#the-mini-calendar)). وعندما تكون Journal معطّلة، تعرض اللوحة الوسطى
بدلًا من ذلك كل سجل من ذلك اليوم عبر كل الوحدات المفعّلة.

## صفحة Reports { #the-reports-page }

تبني **Reports** (من الشريط الجانبي) جداول يمكنك تشغيلها مجددًا وطباعتها.

1. انقر **New report**.
2. أدخل **Report name** (اسم التقرير)، واختر **Record type** (نوع السجل) و**Rows per page** (صفوف لكل صفحة).
3. تحت **Tick what to show** (حدّد ما يُعرض)، اختر الأعمدة؛ ورتّبها بسهمي الأعلى والأسفل
   تحت **Order, left to right** (الترتيب من اليسار إلى اليمين).
4. تحت **Which records** (أي السجلات)، اختر:
    - **Point and click** (أشِر وانقر) — **Contains text**، **Status**، **Type**، **Tag**، **Created from** /
      **Created to**، إضافةً إلى أي من إعدادات تقارير الشريط الجانبي الجاهزة؛ أو
    - **Query** (استعلام) — اكتب استعلام HQL بنفسك، مثل `from Book where type.code = 'art' order by id
      desc`. وعبارة `order by` في الاستعلام نفسه هي التي تحدد الترتيب.
5. اختر **Sort by** (الترتيب حسب) والاتجاه، وأضف **Notes** (ملاحظات) اختيارية، وتحقّق من المعاينة ثم **Save**.

في قائمة التقارير، استخدم **Run** (تشغيل) لعرضه في التطبيق، و**Printable view** (عرض للطباعة) لفتح صفحة نظيفة
بالأسود على الأبيض في علامة تبويب جديدة (ثم انقر **Print** طباعة)، و**Edit** أو **Delete**.

!!! note "ملاحظة"
    تظهر القيم بأسمائها الكاملة (نوع المورد يُقرأ "Article"، لا رمزه). التقارير الكبيرة جدًا
    تُقتطع عند حجم آمن في العرض المعدّ للطباعة، وتذكر الصفحة ذلك.

# Keyboard shortcuts

The web app can be driven almost entirely from the keyboard. Press **?** at any time to see the
shortcut overlay; **Help & shortcuts** in the sidebar shows the same list, plus a Markdown
cheatsheet.

Shortcuts never fire while you are typing in a box — press **Esc** to leave the box first. They also
ignore key combinations with **Ctrl**, **Alt** or **⌘**.

## Global

| Keys | Action |
|---|---|
| **?** | Show / hide the shortcuts overlay |
| **/** | Jump to the **Search everything…** box |
| **g** then a letter | Go to a page (see below) |
| **Esc** | Close a dialog or form, or deselect the current record |

## Go to (press **g**, then…)

Press **g**, then the second key within about a second and a half.

| Keys | Goes to | Keys | Goes to |
|---|---|---|---|
| **g t** | Tasks | **g c** | Calendar |
| **g g** | Goals | **g k** | Kanban |
| **g n** | Notes | **g b** | All bookmarks |
| **g j** | Journal | **g i** | Indicators |
| **g p** | Planner | **g a** | Admin |
| **g r** | Resources | **g m** | Import notes |
| **g w** | Writings | **g s** | Settings |

## In a module list

| Keys | Action |
|---|---|
| **j** | Select the next record |
| **k** | Select the previous record |
| **o** | Open the selected record |
| **n** | New record |

## With a record selected

| Keys | Action |
|---|---|
| **e** | Edit the record |
| **f** then **1** / **2** / **3** | Open the record's folder in repository 1 / 2 / 3 (on the server's desktop) |

### Quick edit

Change a single field without opening the form. A small picker opens; type to filter, choose a
value, and it is applied straight away.

| Keys | Sets |
|---|---|
| **p** | Priority — type a number, then **Enter** |
| **#** | Type |
| **?** | Status (while a record is selected, **?** sets the status instead of opening help) |
| **@** | Context |
| **d** | Department |
| **c** | Course |
| **\*** | Toggle the bookmark |

**n**, **e** and the quick edits need permission to write content.

## In text boxes

| Keys | Where | Action |
|---|---|---|
| **Ctrl+Enter** | **Quick note** bar | Add the note |
| **Ctrl+Enter** | **Append to…** box under a field | Append the text |
| **Enter** | Batch edit command, task summary on a goal, sprint timer summary, most dialog fields | Submit |

## Galleries (Highlights, Flash cards)

| Keys | Action |
|---|---|
| **←** / **→** (or **Page Up** / **Page Down**) | Previous / next card |
| **Home** / **End** | First / last card |
| **d** / **r** / **k** / **u** | Flash cards: **Reviewed** / **Repeat** / **Keep** / **Unset** |

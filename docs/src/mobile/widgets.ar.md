# أدوات الشاشة الرئيسية

يأتي نبراس محمول مع إحدى عشرة أداة للشاشة الرئيسية. لإضافة واحدة، اضغط مطولًا على مكان فارغ في شاشتك الرئيسية، واختر **Widgets** (الأدوات)، وابحث عن **نبراس محمول**، واسحب الأداة التي تريدها إلى مكانها. معظمها قابل لتغيير الحجم.

| الأداة (الاسم في قائمة الاختيار) | تعرض | تحتاج إلى خادم Nibras؟ |
|---|---|---|
| [أحدث الملاحظات](#recent-notes) | ملاحظاتك الأخيرة، للقراءة | لا |
| [مهام اليوم](#todays-tasks) | مهام اليوم ذات الأولوية القصوى، مع شريط إضافة | لا |
| [يوميات اليوم](#todays-journal) | إدخالات يوميات اليوم، مع شريط إضافة | لا |
| [الأولوية القصوى](#top-priority) | كل ملاحظة بأولويتك القصوى | لا |
| [لوحة المهام](#tasks-board) | كل المهام بأعلى أولويتين لديك، حسب القسم | لا |
| [مؤشرات نبراس محمول](#nibras-mobile-kpis) | أعداد بنظرة سريعة | جزئيًا |
| [الخطط القادمة](#upcoming-plans) | أحداثك المخطط لها التالية | نعم |
| [السجلات المرجعية](#bookmarked-records) | السجلات التي وضعت عليها نجمة | نعم |
| [مواقيت الصلاة](#prayer-times) | التاريخ الهجري، والعدّ التنازلي، وأوقات اليوم | لا |
| [العد التنازلي للمنبّهات](#alarms-countdown) | الوقت المتبقي حتى منبّهات اليوم | لا |
| [حالة الهاتف](#phone-status) | مستويات الصوت | لا |

!!! tip "اضغط العنوان للتحديث"
    لا تتحدث الأداة إلا عندما يعيد شيء رسمها. في معظم الأدوات، **الضغط على العنوان** يعيد رسمها الآن. وفي الأدوات التي تعرض بيانات الخادم (**مؤشرات الأداء**، و**الخطط القادمة**، و**السجلات المرجعية**)، يجلب أيضًا بيانات جديدة من الخادم أولًا. أما الضغط في مكان آخر من الأداة فيفتح التطبيق عادة.

## أحدث الملاحظات { #recent-notes }

سلسلة للقراءة فقط لما كتبته مؤخرًا، الأقدم في الأعلى والأحدث في الأسفل، كمحادثة تمرّ عليها. يكون العنوان **ملاحظات اليوم** أو **آخر N يوم**.

تُقطع الملاحظات الطويلة بعد عدد محدد من الكلمات مع **اقرأ المزيد**. **اضغط على ملاحظة** لتوسيعها في مكانها، واضغط مجددًا لطيّها. هذا هو عنصر التحكم الوحيد؛ لا توجد عوامل تصفية ولا أزرار.

اضبطها في [الإعدادات](settings.md) ← **التقويم والأدوات**، ضمن **أداة الملاحظات الأخيرة**:

| الإعداد | النطاق | الافتراضي |
|---|---|---|
| المدى إلى الوراء (**اليوم فقط** / **آخر N يوم**) | 1–30 يومًا | 3 أيام |
| **N كلمة، ثم «اقرأ المزيد»** | 10–200 كلمة | 40 |
| **حجم النص N sp** | 10–28 sp | 15 sp |

يُعاد رسم الأداة عندما تضغط **حفظ** في الإعدادات، فيظهر الحجم الجديد فورًا.

## مهام اليوم { #todays-tasks }

المهام المكتوبة **اليوم** بـ **الأولوية القصوى** لديك (بعنوان مثل **مهام اليوم p4**). تفرغ نفسها خلال الليل، فهي قائمة بعمل اليوم، لا أرشيف.

اضغط **+  أضف مهمة…** في الأعلى لكتابة مهمة جديدة مباشرة من الشاشة الرئيسية. انظر [التدوين السريع](capture.md#add-a-task-or-journal-entry-from-the-home-screen).

## يوميات اليوم { #todays-journal }

إدخالات يوميات اليوم، بكل الأولويات. وكأداة المهام تبدأ من جديد كل يوم. اضغط **+  اكتب يوميات اليوم…** لإضافة إدخال.

## الأولوية القصوى { #top-priority }

كل ملاحظة في مجلدك بـ **الأولوية القصوى** لديك (الأولوية 4 ما لم تغيّر **الأولوية القصوى (الأدوات)** في الإعدادات ← **عام**)، من أي نوع وأي تاريخ. إن لم توجد أي منها تقول **لا توجد ملاحظات بأولوية 4**. الضغط على العنوان يعيد رسمها. هذه ملاحظات على هاتفك، فلا حاجة إلى مزامنة.

## لوحة المهام { #tasks-board }

أداة صُممت لتملأ صفحة من الشاشة الرئيسية: كل المهام (ملاحظات من النوع `T`) بأعلى أولويتين لديك، أيًّا كان تاريخ كتابتها. مع الإعدادات الافتراضية هما p4 وp3، ويكون العنوان **المهام p3–p4** وبجانبه العدد. تُجمَّع المهام حسب الأولوية، ثم حسب القسم (الفئة)؛ وما لا قسم له يوضع تحت **بلا قسم**.

وبخلاف **مهام اليوم**، ليس فيها شريط إضافة ولا تفرغ خلال الليل: إنها الصورة الدائمة لما يهمّ. وتأخذ كل مهمة اتجاه نصها الخاص، فتُقرأ المهام العربية من اليمين إلى اليسار. اضغط العنوان لإعادة رسمها، أو مهمة لفتح التطبيق على **المهام**.

اضبطها في [الإعدادات](settings.md) ← **التقويم والأدوات**، ضمن **أداة لوحة المهام**:

| الإعداد | النطاق | الافتراضي |
|---|---|---|
| **حجم النص N sp** | 10–24 sp | 13 sp |
| **عدد الأعمدة** | 1–4 | 2 |

وتتبع الأولويتان إعداد **الأولوية القصوى (الأدوات)** في [الإعدادات](settings.md) ← **عام**.

## مؤشرات نبراس محمول { #nibras-mobile-kpis }

أداة صغيرة للأعداد، مع تسمية مختصرة بجانب كل رقم كي تتسع لخانة ضيقة:

| تقرأ | المعنى |
|---|---|
| `5 ملاحظة اليوم / 1204` | الملاحظات المكتوبة اليوم / إجمالي الملاحظات |
| `862 ملف` | الملفات في مجلد ملاحظاتك، بما فيها المرفقات |
| `12 ملف اليوم` | كم من تلك الملفات من اليوم |
| `7.7 غ.ب متاح` | المساحة الحرة على الهاتف، بالغيغابايت |
| `9 p4` | الملاحظات بأولويتك القصوى |
| `3 خطة` | الخطط القادمة (من الخادم) |

بعض الأرقام يتغير لونها كتحذير: ملاحظات كثيرة جدًا بالأولوية القصوى، أو خطط قليلة جدًا قادمة.

## الخطط القادمة { #upcoming-plans }

أحداثك التالية من مخطِّط Nibras، معنونة باليوم والوقت (**غدًا 09:00** تعني غدًا الساعة 09:00). مرّر لرؤية المزيد. اضغط العنوان لجلب خطط جديدة من الخادم. اضغط على صف لفتح التطبيق.

## السجلات المرجعية { #bookmarked-records }

الخطط والأهداف والمهام التي وضعت عليها نجمة في [صفحات الخادم](server-pages.md#bookmark-the-star) في التطبيق (السجلات المحفوظة على هذا الهاتف)، في قائمة قابلة للتمرير. اضغط العنوان للمزامنة وإعادة الرسم.

## مواقيت الصلاة { #prayer-times }

شريط عريض فيه التاريخ الهجري، وعدّ تنازلي حتى الوقت التالي، وعمود لكل صلاة اخترت عرضها، مع تمييز التالية. وهو بالعربية ومن اليمين إلى اليسار، مكتوب بخط كبير يُقرأ من طرف الغرفة.

لا يظهر العدّ التنازلي إلا حين تقترب الصلاة التالية. ومدى القرب هو إعداد **العدّ التنازلي في الأداة** في صفحة [مواقيت الصلاة](prayer.md#reminders-and-countdown) (ساعة واحدة افتراضيًا). وحين يحين الوقت، يعدّ الشريط تصاعديًا منه بدلًا من ذلك (**منذ 4:12**) طوال مدة **مؤقّت «منذ»** في صفحة مواقيت الصلاة (30 دقيقة افتراضيًا). اضغط التاريخ لإعادة الرسم؛ واضغط في مكان آخر لفتح صفحة مواقيت الصلاة.

## العد التنازلي للمنبّهات { #alarms-countdown }

بطاقة بعنوان **المنبّهات · N اليوم** تعرض كل منبّه من [منبّهات](alarms.md) اليوم المتبقية: وقته، وكم بقي حتى يرنّ، وتسميته (**07:00 · بعد 2 س 15 د — استيقاظ**). وحين لا يبقى شيء تقول **لا شيء متبقٍّ اليوم**. تتحدث تلقائيًا كل دقيقة ما دامت على شاشتك الرئيسية. اضغطها لفتح صفحة المنبّهات.

## حالة الهاتف { #phone-status }

بعنوان **مستويات الصوت**: مستويات صوت **الرنين** و**الإشعارات** و**المنبّه** و**الوسائط** كأشرطة. تتحدث عند تغيّر مستوى الصوت أو وضع الرنين. اضغط العنوان للتحديث. واضغط في مكان آخر لفتح إعدادات الصوت في الهاتف.

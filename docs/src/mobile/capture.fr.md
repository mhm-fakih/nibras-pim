# Capture rapide et partage

En plus de la [barre d'ajout rapide](notes.md#quick-add) de la page Notes, il existe trois autres façons de faire entrer quelque chose dans Nibras Mobile sans l'ouvrir d'abord.

## Partager du texte depuis une autre application { #share-text-from-another-app }

Dans toute application capable de partager du texte (un navigateur, une messagerie, une liseuse) :

1. Sélectionnez ou choisissez le texte et touchez **Partager**.
2. Choisissez **Nibras Mobile** dans la feuille de partage.

L'application s'ouvre sur la page [Ajouter une note](notes.md#the-full-form-add-note) avec le texte déjà placé dans la zone. Les puces de type, de priorité et de catégorie conservent les dernières valeurs utilisées : vérifiez-les, puis touchez la flèche d'envoi pour enregistrer. Rien n'est enregistré tant que vous ne l'avez pas fait, vous pouvez donc d'abord modifier le texte.

!!! note
    L'application accepte le **texte** partagé. Pour importer des images, des captures d'écran ou des enregistrements, utilisez [Collecter des fichiers](collect.md).

## Ouvrir de l'audio et de la vidéo avec Nibras Mobile { #open-audio-and-video-with-nibras-mobile }

Dans un gestionnaire de fichiers ou toute application qui propose **Ouvrir avec**, choisissez **Nibras Mobile** pour un fichier audio ou vidéo. Il s'ouvre directement dans le [lecteur](player.md), avec les signets et la reprise de lecture qui fonctionnent comme d'habitude. Si le gestionnaire de fichiers n'indique pas où se trouve le fichier, l'application le retrouve sur le téléphone par son nom et sa taille, pour que ses signets fonctionnent ; à défaut, elle lit une copie temporaire.

## Ajouter une tâche ou une entrée de journal depuis l'écran d'accueil { #add-a-task-or-journal-entry-from-the-home-screen }

Deux [widgets](widgets.md) ont une barre d'ajout en haut :

| Widget | Barre d'ajout | Enregistré comme |
|---|---|---|
| **Tâches du jour** | **+  Ajouter une tâche…** | Une note de type `T` à votre **Priorité maximale** |
| **Journal du jour** | **+  Écrire le journal du jour…** | Une note de type `J` à votre **Priorité par défaut** |

Touchez la barre : un champ d'une ligne apparaît juste au-dessus du clavier, intitulé **Tâche · p4** ou **Journal · aujourd’hui**, avec **Que faut-il faire ?** ou **Que s’est-il passé ?** comme invite. Saisissez votre texte et appuyez sur la touche **OK** (Terminé) du clavier. Il n'y a pas de bouton Ajouter. La note est écrite dans votre dossier de notes et le widget se met à jour aussitôt (une nouvelle tâche apparaît aussi sur le widget [Tableau des tâches](widgets.md)).

Le texte saisi n'est jamais perdu :

- Toucher en dehors de la barre ne la ferme que si elle est vide. Si elle contient du texte, le toucher est refusé et la barre indique **Conservé. Appuyez sur Retour pour quitter — votre saisie est enregistrée comme brouillon.**
- Si vous appuyez sur Retour ou Accueil, ce que vous avez saisi est conservé comme brouillon et réapparaît la prochaine fois que vous touchez la barre d'ajout.

!!! tip
    Ces entrées sont des notes ordinaires, avec un nom de fichier ordinaire : elles apparaissent donc aussi sur la page Notes, ainsi que sur votre ordinateur si votre dossier de notes est synchronisé.

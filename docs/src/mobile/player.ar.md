# مشغّل الوسائط

يتضمن knotes مشغّل صوت وفيديو مصممًا للتعامل مع التسجيلات الطويلة: المحاضرات، والكتب الصوتية، والمذكرات الصوتية. يتذكر أين توقفت في كل ملف، ويتيح لك وضع علامات مؤرَّخة بالوقت مع ملاحظة لكل منها، ويمكنه أن يختار لك ما يُشغَّل بعد ذلك.

## مكتبة الوسائط { #the-media-library }

افتح **الوسائط** (أيقونة سماعة الرأس) من الشريط الجانبي. تتصفح كل ملفات الصوت والفيديو ضمن **مجلدات مكتبة الصوت** لديك (تُضبط في جولة الإعداد أو في [الإعدادات](settings.md)؛ ويمكنك إضافة عدة مجلدات).

ثلاث تبويبات:

| التبويب | كيف يعرض ملفاتك |
|---|---|
| **المكتبة** | حسب وسوم الملفات نفسها: **الأنواع**، ثم الفنان، ثم الألبوم. الملفات غير الموسومة تظهر تحت **نوع غير معروف** أو **فنان غير معروف** أو **ألبوم غير معروف**، ولا تُخفى أبدًا. |
| **المجلدات** | شجرة المجلدات، مستوى واحدًا في كل مرة. يعرض كل مجلد لمحة عن أولى مقاطعه (**…و N ملف آخر**)، و**عليها علامات مؤخرًا هنا** في الأعلى. |
| **ذات العلامات** | كل ملف له علامات، الأحدث علامةً أولًا، مع عدد علاماته. أسرع طريقة لمتابعة استماع لم يكتمل. |

**تصفية بالاسم…** في الأعلى تبحث في المكتبة كلها كقائمة مسطّحة واحدة. تطابق أسماء الملفات والفنان والألبوم والنوع. **إعادة فحص المكتبة** (سهم دائري) يعيد قراءة المجلدات بعد إضافة ملفات.

اضغط على أي ملف لتشغيله. يُفتح في المشغّل ويستأنف من حيث توقفت آخر مرة.

تشمل الملفات المدعومة صوت MP3 وM4A/M4B وAAC وOpus وOGG وWAV وFLAC وAMR، وفيديو MP4 وMKV وWebM وAVI وMOV و3GP.

!!! tip "طرق أخرى للتشغيل"
    - الصوت أو الفيديو **المرفق بملاحظة** يُشغَّل هنا عندما تضغط عليه في بطاقة الملاحظة.
    - من تطبيق آخر (مدير ملفات مثلًا)، اختر **Open with → knotes** (فتح باستخدام ← knotes) على ملف صوت أو فيديو.

## شاشة المشغّل { #the-player-screen }

من الأعلى إلى الأسفل:

- **التقدّم**: مقدار ما قطعته من الملف كنسبة مئوية، ومن المجلد (الملفات مرتبة بالاسم).
- **النص** (فقط عندما يكون للملف نص). انظر [الترجمة والنصوص](#subtitles-and-transcripts).
- **شريط التقديم** مع الوقت الحالي والمدة الكلية. يسير الوقت من اليسار إلى اليمين في كل اللغات.
- **اسم الملف**، وتحته رابط أحمر صغير **حذف هذا الملف**.
- **ملاحظة العلامة (اختياري)**: اكتب هنا تسمية للعلامة التالية.
- الزر الكبير **إضافة علامة**.
- **أزرار التحكم**:

    | الصف العلوي | | |
    |---|---|---|
    | **+10** قفز للأمام | **تشغيل** / **إيقاف مؤقت** | **−10** قفز للخلف |

    | الصف السفلي | | | |
    |---|---|---|---|
    | **التالي** (⏭) | قائمة **في هذا المجلد** | مفتاح **الصوت فقط** | **−5** قفز للخلف |

    يمكن ضبط مسافة القفز **+10/−10** (انظر [إعدادات المشغّل](#player-settings)). **الصوت فقط** يوقف صورة الفيديو، أثناء القيادة مثلًا، ويعرض **صوت** وهو مفعّل. ويحمل زر ⏭ أيقونة صغيرة تبيّن ما سيفعله **التشغيل التالي**.

يستمر التشغيل في الخلفية والشاشة مطفأة. وتظهر أدوات التحكم المعتادة في الإشعار، وعلى شاشة القفل، وفي سماعات البلوتوث. يعيدك الرجوع إلى التطبيق ويترك [المشغّل المصغّر](navigation.md#the-mini-player) في الأسفل.

## العلامات { #bookmarks }

العلامة لحظة في الملف مع سطر نصي اختياري.

1. أثناء الاستماع، اكتب إن شئت تسمية في **ملاحظة العلامة (اختياري)**.
2. اضغط **إضافة علامة**.

توضع العلامة قبل اللحظة الحالية **ببضع ثوانٍ** (7 ثوانٍ افتراضيًا)، لأنك تريد عادة الجملة التي سمعتها للتو. يقفز المشغّل إلى تلك النقطة ويؤكد بـ **✓ أُضيفت علامة −7 ث**.

- **مع تفعيل الترجمة**، تأخذ العلامة التي لا تسمية مكتوبة لها سطر الترجمة المنطوق تسميةً لها (**✓ أُضيفت علامة −7 ث · مع نص الجملة**).
- **اضغط مجددًا بسرعة لرفع أولويتها.** النقرة الثانية خلال بضع ثوانٍ (3 افتراضيًا)، وأنت في الموضع نفسه، لا تضيف علامة أخرى، بل تضيف تسمية أولوية: `p2`، ثم `p3` في النقرة الثالثة، وهكذا (**✓ أُضيفت الأولوية p2**).
- **علامة عند الإيقاف المؤقت**: عند تحديد هذا الخيار في إعدادات المشغّل، يضع كل إيقاف مؤقت (على الشاشة، أو من سلك السماعة، أو من البلوتوث) علامة. يُظهر زر الإيقاف المؤقت شارة علامة صغيرة وهو مفعّل. مفيد إن كنت قد تغفو أثناء الاستماع.

افتح لوحة **العلامات** (أيقونة العلامة، أسفل أدوات التحكم) لترى علامات الملف، الأحدث أولًا. اضغط على إحداها للانتقال إليها، أو اضغط أيقونة السلة لحذفها.

### أين تُحفظ العلامات { #where-bookmarks-are-stored }

تُحفظ العلامات في ملف نصي صغير بجانب ملف الوسائط، بالاسم نفسه والامتداد `.tmk`:

```
lecture.mp3
lecture.tmk
```

```
[12:04] p2 the key definition
[1:03:15] summary starts here
```

ولأنه ملف عادي بجانب التسجيل، تنتقل العلامات معه إلى حاسوبك وتعود. والأسطر التي لا يتعرف عليها التطبيق تُحفظ، ولا يُكتب فوقها أبدًا. انظر [العلامات (.tmk)](../concepts/bookmarks-tmk.md).

## اللوحات { #the-panels }

صف من الأيقونات تحت أدوات التحكم يفتح لوحة واحدة في كل مرة. اضغط الأيقونة نفسها مجددًا لإغلاقها.

| الأيقونة | اللوحة |
|---|---|
| علامة | **العلامات**: علامات هذا الملف (مفتوحة افتراضيًا) |
| مجلد | **في هذا المجلد**: الملفات الأخرى في المجلد نفسه؛ اضغط على أحدها لتشغيله |
| مجلد مفتوح | **المجلدات الأخيرة**: المجلدات التي شغّلت منها؛ اضغط على أحدها لاستئناف أحدث ملف فيه |
| ساعة | **شُغّل مؤخرًا**: الملفات التي شغّلتها مؤخرًا |
| ترس | **إعدادات المشغّل** |

يتذكر التطبيق اللوحة التي كانت مفتوحة.

## إعدادات المشغّل { #player-settings }

| الإعداد | النطاق | ما يفعله |
|---|---|---|
| **القفز N ث** | 5–60 ث (الافتراضي 10) | مسافة أزرار القفز الكبيرة. |
| **السرعة** | 0.75×–1.25× | سرعة التشغيل. |
| **العلامة −N ث** | 0–20 ث (الافتراضي 7) | كم إلى الوراء توضع العلامة. |
| **أولوية النقرتين N ث** | 1–10 ث (الافتراضي 3) | مدى سرعة النقرة الثانية لترفع الأولوية بدل إضافة علامة. |
| **الصوت** | من −20 إلى +50 dB | رفع صوت هذا المشغّل أو خفضه، للتسجيلات الخافتة. |
| **التشغيل التالي** | انظر أدناه | ما يحدث عند انتهاء الملف، وما يفعله ⏭. |
| **مؤقّت النوم** | **إيقاف**، 15 د، 30 د، 45 د، 60 د | يوقف التشغيل مؤقتًا بعد تلك المدة. يعرض **يتوقف بعد …** أثناء عمله. يعمل والشاشة مطفأة. |
| **علامة عند الإيقاف المؤقت** | تشغيل/إيقاف | كل إيقاف مؤقت يضيف علامة. |

لكل منزلق أيضًا زرّا − و+ للخطوات الدقيقة. وتُحفظ هذه الإعدادات بين الجلسات.

### التشغيل التالي { #play-next }

| الوضع | ما يُشغَّل بعد ذلك |
|---|---|
| **إيقاف** | لا يبدأ شيء تلقائيًا عند انتهاء الملف. |
| **نفس المجلد** | يُشغَّل الملف التالي في المجلد تلقائيًا. |
| **قديم عشوائي** | ملف من أي مكان في مجلدات مكتبتك لم تضع عليه علامة قط ولم تلمسه منذ 90 يومًا. إن لم يوجد ملف بهذا القِدم بعد، تُستخدم الأقدم. |
| **عشوائي هنا** | الاختيار نفسه، لكن فقط من المجلد المحيط بما يُشغَّل، بما فيه مجلداته الفرعية. وداخل مجلد مرفقات ملاحظة، يبحث في المجلد الذي يضم كل الملاحظات، فيمرّ على مرفقات كل الملاحظات. |
| **الأحدث هنا** | المجلد نفسه كما في **عشوائي هنا**، لكن الملفات الأحدث التي لا علامات عليها بدل الأقدم، لمتابعة ما وصل للتو. |

إن لم يبقَ شيء للاختيار، يخبرك المشغّل بذلك، مثلًا **لم يبقَ شيء هنا — كل ملفات هذا المجلد عليها علامات أو شُغّلت من قبل.**

## الترجمة والنصوص { #subtitles-and-transcripts }

يلتقط المشغّل نوعين من الملفات النصية المرافقة الموجودة بجانب ملف الوسائط بالاسم نفسه:

- **الترجمة** (`.srt`): `lecture.en.srt` أو `lecture.fr.srt` أو `lecture.srt` البسيط. يعرض صف **الترجمة** شريحة لكل لغة إضافة إلى **إيقاف**، ويظهر السطر الحالي تحت شريط التقديم، للصوت والفيديو على حد سواء.
- **النصوص** (`.ai.txt`): `lecture.en.ai.txt` أو `lecture.ar.ai.txt` أو `lecture.ai.txt` البسيط، مثل النصوص الآلية المُعدّة على حاسوبك. ليس لها توقيتات، لذا يُعرض النص كله في مربع **النص** القابل للتمرير فوق أدوات التحكم، مع شريحة لكل لغة. استخدم **إخفاء النص** / **عرض النص** لطيّه.

النصوص للقراءة فقط على الهاتف، لكن يمكنك تحديد النص منها ونسخه. ويمكن إزالة نص بزر الحذف الخاص به (**حذف النص …**).

## حذف تسجيل { #deleting-a-recording }

اضغط **حذف هذا الملف** تحت اسم الملف. يعرض مربع الحوار **حذف هذا الملف؟** كل ما يُحذف معه: ملفات نصوصه وعلاماته. لا توجد سلة محذوفات، فلا يمكن استعادة الملف. بعد الحذف، ينتقل المشغّل إلى غيره.

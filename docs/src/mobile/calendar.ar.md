# التقويم

**التقويم** (أيقونة التقويم) يعرض إدخالات **الخطط** و**اليوميات** من خادم Nibras على شبكة أيام، ويتيح لك إضافتها ونقلها بإصبعك. يقع في جانب **على هذا الهاتف** من الشريط الجانبي لأنه يعمل دون اتصال: تُحفظ الإدخالات الجديدة على الهاتف أولًا وتُرسل إلى الخادم عند توفر الاتصال.

!!! note
    يعرض التقويم بيانات الخادم، لذا يحتاج إلى [اتصال بـ Nibras](sync.md). وبدونه لا يعرض إلا الإدخالات التي تضيفها على الهاتف.

## قراءة الشبكة { #reading-the-grid }

- يعرض الشريط العلوي التاريخ (أو نطاق التواريخ) المعروض.
- **السابق** / **اليوم** / **التالي** للتنقل بين الأيام.
- **1 ي** / **3 ي** لعرض يوم واحد أو ثلاثة أيام متجاورة.
- تُرسم **الخطط** بالأخضر وإدخالات **اليوميات** بالأزرق الفاتح. والمواعيد المستقبلية لخطة متكررة تُرسم بلون أبهت.
- خط رفيع عبر عمود اليوم يشير إلى الوقت الحالي.
- الساعات المعروضة تمتد من **ساعة بداية التقويم** إلى **ساعة نهاية التقويم** في [الإعدادات](settings.md) (من 5 إلى 22 افتراضيًا). يتسع النطاق كله للشاشة دون تمرير.
- **الفترة** (15 د / 30 د / 60 د) أسفل الشبكة تحدد حجم الفترة الزمنية، وهي الخطوة التي تلتصق بها الإدخالات الجديدة وعمليات السحب.

### التقويم المصغّر { #mini-calendar }

حين يكون **تقويم مصغّر** مفعّلًا في الإعدادات (وهو كذلك افتراضيًا)، يعرض شريط في الأعلى الأسبوع الماضي وهذا الأسبوع، ويبدأ كل صف برقم الأسبوع (**أ41**). تشير نقطة إلى الأيام التي فيها إدخالات. اضغط على يوم للانتقال إليه.

## إضافة إدخال { #add-an-entry }

أيٌّ مما يلي يفتح نموذج **إدخال جديد**:

- اضغط على فترة فارغة: يبدأ الإدخال هناك ويستمر فترة واحدة.
- **اضغط مطولًا واسحب** نزولًا على الشبكة لتغطية نطاق زمني أطول.
- اضغط **+** (**إضافة إدخال**) في الشريط العلوي.

في النموذج:

| الحقل | |
|---|---|
| **النوع** | **خطة** أو **يوميات**. يكون آخر نوع استخدمته محددًا مسبقًا. |
| **التاريخ** | مع سهمي **اليوم السابق** / **اليوم التالي**. |
| **البداية**، **النهاية** | الأوقات. |
| **الملخّص** | العنوان. تُفتح لوحة المفاتيح هنا. يُحاذى النص العربي إلى اليمين تلقائيًا. |
| **الوصف** | تفاصيل اختيارية. |

اضغط **حفظ**. سترى **تم الحفظ في التقويم**، أو **تم الحفظ — ستتم المزامنة عند الاتصال** إن كنت غير متصل.

## تغيير إدخال { #change-an-entry }

- **اضغط** على إدخال لفتحه للتعديل (**تعديل الإدخال**). لا يمكن تغيير النوع بعد إنشاء الإدخال.
- **اسحب الشريط الرفيع** عند الحافة العليا أو السفلى لتغيير وقت البداية أو النهاية.
- **اضغط مطولًا واسحب** الإدخال لنقله إلى وقت آخر في اليوم نفسه.

أثناء السحب، تُظهر معاينة أين سيستقر. لا يتغير شيء حتى ترفع إصبعك.

!!! note "الخطط المتكررة دون اتصال"
    الموعد المستقبلي لخطة متكررة ليس سجلًا على الخادم بعد. وتعديله ينشئ سجلًا، لذا لا يمكن فعل ذلك دون اتصال. سترى **لا يمكن تعديل موعد متكرر دون اتصال — حاول مجددًا عند الاتصال**.

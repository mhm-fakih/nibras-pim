# knotes لأندرويد

**knotes** هو تطبيق الهاتف ضمن منظومة Nibras للمعرفة الشخصية. إنه قبل كل شيء أداة سريعة لتدوين الملاحظات: شاشة واحدة فيها ملاحظاتك ومربع لكتابة الملاحظة التالية. وحول ذلك يضيف ما تحتاجه على الهاتف خلال يومك: مشغّل وسائط يتذكر أين توقفت، ومواقيت الصلاة مع الأذان، والمنبّهات، والتقويم، وأدوات الشاشة الرئيسية، واتصالًا اختياريًا بخادم Nibras.

## ما الذي يميّزه { #what-makes-it-different }

- **ملاحظاتك ملفات نصية عادية.** كل ملاحظة ملف Markdown واحد (`.md`) في مجلد تختاره أنت. لا توجد قاعدة بيانات خاصة بالتطبيق تحبسها فيها. الملفات نفسها تُفتح على حاسوبك، وتُزامَن بأي أداة لمزامنة المجلدات، وتبقى بعد التطبيق. انظر [ملاحظات نصية عادية](../concepts/plain-text-notes.md).
- **اسم الملف يحمل البيانات الوصفية.** وقت كتابة الملاحظة ونوعها وأولويتها وفئتها كلها في اسم الملف، فتستطيع أي أداة ترتيبها وتصفيتها. انظر [أسماء الملفات والوسوم](../concepts/filenames-and-tags.md).
- **دوّن الآن وصنّف لاحقًا.** حفظ الملاحظة يحتاج نقرة واحدة، ويمكنك ترتيب الوسوم متى شئت. انظر [دوّن ثم صنّف](../concepts/capture-then-classify.md).
- **يعمل دون اتصال.** كل ما في قسم **على هذا الهاتف** من التطبيق يعمل دون أي شبكة. قسم الخادم اختياري، ويعرض آخر ما تمت مزامنته حين تكون غير متصل.
- **ثلاث لغات.** الإنجليزية (English) والعربية والفرنسية (Français). في العربية تتحول الواجهة كلها إلى الاتجاه من اليمين إلى اليسار.

## التثبيت { #install }

يُوزَّع knotes كحزمة تطبيق أندرويد (`.apk`). ويحتاج إلى أندرويد 6.0 أو أحدث.

1. نزّل ملف `.apk` إلى هاتفك.
2. افتحه. إن سألك أندرويد، فاسمح للمتصفح أو مدير الملفات بتثبيت التطبيقات غير المعروفة.
3. اضغط **Install** (تثبيت)، ثم **Open** (فتح).

!!! note "التحديث"
    للتحديث، ثبّت ملف `.apk` الأحدث فوق القديم. ملاحظاتك ملفات في مجلدك الخاص، لذا لا يمسّها التحديث أبدًا. وتبقى إعداداتك كما هي أيضًا.

## التشغيل الأول { #first-run }

### 1. منح الوصول إلى الملفات { #1-grant-file-access }

في الشاشة الأولى يشرح knotes أنه يحفظ ملاحظاتك كملفات نصية عادية ويطلب إذن الوصول إليها. اضغط **منح الوصول إلى الملفات**. في أندرويد 11 وما بعده يفتح هذا صفحة النظام **All files access** (الوصول إلى جميع الملفات)؛ فعّلها لـ knotes ثم عُد.

يلزم الوصول الكامل إلى الملفات لأن ملاحظاتك ووسائطك وصورك موجودة في مجلدات عادية تختارها أنت، لا داخل التطبيق.

### 2. جولة الإعداد { #2-the-setup-tour }

عند التثبيت الجديد، ترشدك جولة قصيرة عبر المجلدات التي يقرؤها التطبيق. أعلى كل صفحة يظهر **الخطوة N من 9**. زر **التالي** ينتقل إلى الأمام، و**رجوع** يعود، و**تخطي الإعداد** موجود في كل صفحة إن فضّلت الاستكشاف أولًا. لا شيء في الجولة نهائي: يمكن تغيير كل إجابة لاحقًا في [الإعدادات](settings.md).

| الصفحة | ما تختاره |
|---|---|
| **Language · اللغة · Langue** | **English** أو **عربي** أو **Français**. يتحول التطبيق فورًا. لا تُترجم ملاحظاتك وملفاتك أبدًا. |
| **مرحبًا بك في knotes** | مقدمة قصيرة. |
| **أين تُحفظ ملاحظاتك** | **مجلد الملاحظات**. الشاشة الرئيسية تكتب الملاحظات هنا وتعرضها منه. إن كنت تحتفظ بملاحظات في مجلد من قبل (مُزامَن من حاسوب مثلًا)، فوجّه هذا الحقل إليه وستظهر فورًا. |
| **تجميع الملفات في ملاحظات** | أين تذهب لقطات الشاشة والصور والتسجيلات المجمّعة (**تُحفظ الملاحظات المجمّعة في**). انظر [جمع الملفات](collect.md). |
| **مكتبة الوسائط** | **مجلد الوسائط** للصوت والفيديو. انظر [مشغّل الوسائط](player.md). |
| **الصور** | **مجلد الصور** الذي يعرضه المعرض. انظر [المعرض](gallery.md). |
| **الاتصال بـ Nibras** | **عنوان الخادم** الاختياري لخادم Nibras. اتركه فارغًا للتخطي. انظر [مزامنة Nibras](sync.md). |
| **التذكيرات والرنين** | مفاتيح **رنين كل ربع ساعة** و**إبقاء إشعار الحالة** و**المزامنة مع Nibras في الخلفية**، إضافة إلى **السماح بالإشعارات**. |
| **اكتمل الإعداد** | ملخص لكل مجلد سيقرؤه التطبيق. اضغط **ابدأ استخدام knotes**. |

بجانب كل حقل مجلد، تتحقق الجولة مما هو موجود فعلًا: **عُثر على المجلد، وفيه ملفات.** أو **عُثر على المجلد — إنه فارغ حاليًا.** أو **هذا المجلد غير موجود بعد.** (اضغط **إنشاء** لإنشائه)، أو **هذا المسار ملف، وليس مجلدًا.** اضغط **اختيار** لانتقاء مجلد بدل كتابة المسار.

!!! tip "خيار افتراضي جيد"
    مجلد باسم `Notes` في أعلى ذاكرة هاتفك مكان مناسب للبدء. وإن كنت تنوي المزامنة مع حاسوب، فوجّه أداة المزامنة إلى المجلد نفسه.

!!! note "الترقية من إصدار أقدم"
    إن كان knotes مُعدًّا من قبل على هذا الهاتف، فلن تظهر الجولة. يمكنك فتحها في أي وقت من أسفل الإعدادات عبر **عرض جولة الإعداد**.

### 3. السماح بالإشعارات { #3-allow-notifications }

في أندرويد 13 وما بعده، يطلب knotes مرة واحدة إذن عرض الإشعارات. اسمح به. فبدونه لن يعرض أندرويد التذكيرات ولا الرنين ولا إشعار الأذان ولا أزرار التحكم في المشغّل.

## تغيير اللغة لاحقًا { #changing-the-language-later }

قائمة اللغات هي أول عنصر في [الإعدادات](settings.md). كل لغة مكتوبة بخطها الخاص، فتجد لغتك أيًّا كانت لغة الشاشة. وفي أندرويد 13 وما بعده يمكنك تغييرها أيضًا من صفحة النظام **App languages** (لغات التطبيقات). المزيد في [اللغات](../concepts/languages.md).

في العربية تبقى الأرقام بالأرقام الغربية (0–9)، فتظل الأوقات وأسماء الملفات والعلامات مقروءة للأدوات الأخرى.

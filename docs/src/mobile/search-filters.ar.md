# العثور على الملاحظات

في صفحة الملاحظات ثلاث أدوات للعثور على الأشياء: **البحث**، و**الترتيب والتجميع**، و**لوحة التصفية**. وهي تعمل معًا: تُطبَّق عوامل التصفية فوق البحث، وتعرض القائمة ما يجتاز الاثنين.

## البحث { #search }

اضغط العدسة المكبّرة (**بحث**) في الشريط العلوي واكتب في **ابحث في الملاحظات…**. تضيق القائمة أثناء الكتابة.

يبحث في:

- نص كل ملاحظة (تُتجاهل علامات التمييز، فتظل العبارة مطابقة حتى إن امتد عليها تمييز)، و
- **رموز** النوع والفئة في اسم الملف، مثل `W` أو `P`. يطابق الرموز القصيرة، لا الأسماء الكاملة المعروضة في الإعدادات.

البحث لا يميّز بين الأحرف الكبيرة والصغيرة.

!!! note "فتح البحث يمسح عوامل التصفية"
    عند فتح البحث، تُمسح عوامل التصفية كي تبحث في كل شيء. وإلا فقد تختفي ملاحظة بسبب عامل تصفية نسيته، فتكون النتيجة الفارغة مضلِّلة. اضغط **×** لإغلاق البحث ومسح النص.

## الترتيب والتجميع { #sort-and-group }

زر **ترتيب الملاحظات** (أيقونة الخطوط) يفتح قائمة من جزأين.

**الترتيب**

| الخيار | الترتيب |
|---|---|
| **ترتيب حسب التاريخ** | الأقدم في الأعلى والأحدث في الأسفل، كالمحادثة. تُفتح القائمة من الأسفل. |
| **ترتيب حسب الفئة** | حسب رمز الفئة. الملاحظات بلا فئة تأتي أخيرًا. |
| **ترتيب حسب الأولوية** | حسب رقم الأولوية. الملاحظات بلا أولوية تأتي أخيرًا. |
| **ترتيب حسب النوع** | حسب رمز النوع. الملاحظات بلا نوع تأتي أخيرًا. |

**التجميع**

| الخيار | النتيجة |
|---|---|
| **بلا تجميع** | قائمة واحدة بسيطة. |
| **تجميع حسب النوع** / **تجميع حسب الأولوية** / **تجميع حسب الفئة** | تنقسم القائمة إلى أقسام قابلة للطي مثل **بلا نوع** أو **الأولوية 3** أو **بلا فئة**، لكل منها عدد. اضغط رأس القسم لطيّه أو توسيعه. |

## لوحة التصفية { #the-filter-panel }

فوق القائمة شريط عنوانه **عوامل التصفية**. عندما تكون عوامل التصفية مفعّلة يصبح **عوامل التصفية (N)**، حيث N عددها، ويعرض *المعروض/الإجمالي* على الجانب، فلا تُحسب القائمة القصيرة ملاحظاتٍ مفقودة. اضغط الشريط لفتح اللوحة أو إغلاقها.

!!! tip "تبدأ باليوم"
    عند بدء التطبيق، يكون اليوم محددًا مسبقًا في التقويم، فتعرض القائمة ملاحظات اليوم. اضغط **مسح الكل** لترى كل شيء.

### التقويم { #calendar }

تقويم شهري يبدأ بيوم الإثنين. يعرض كل يوم تاريخه، وبين قوسين عدد الملاحظات فيه، بتظليل أغمق للأيام الأكثر ازدحامًا.

- اضغط على يوم لعرض ملاحظات ذلك اليوم فقط. اضغط أيامًا أخرى لإضافتها؛ واضغط يومًا محددًا مجددًا لإزالته.
- سهما **الشهر السابق** / **الشهر التالي** يحرّكان التقويم؛ و**اليوم** يعيدك. التنقل بين الأشهر لا يغيّر ما هو محدد.
- **الإنشاء** / **التحديث** يختار أي تاريخ يُحتسب:
    - **الإنشاء** هو الوقت في اسم ملف الملاحظة، أي وقت كتابتها. لا يتغير عند تعديل الملاحظة أو إعادة وسمها.
    - **التحديث** هو آخر وقت تغيّر فيه الملف.

### الأولوية، النوع، الفئة { #priority-type-category }

يعرض كل منها قيمه كشرائح مع عدد بين قوسين. اختر واحدة أو أكثر لعرض تلك الملاحظات فقط. تعرض الأعداد دائمًا ما *ستحصل* عليه باختيار تلك القيمة مع بقاء عوامل التصفية الأخرى كما هي، فلا يظهر الخيار غير المحدد بصفر.

### الوسوم { #tags }

سحابة من `#hashtags` المكتوبة داخل ملاحظاتك. النص الأكبر يعني أن الوسم يُستخدم أكثر. اضغط على وسم لعرض الملاحظات التي تحتويه فقط، واضغطه مجددًا لإزالته. تُطابق الوسوم دون اعتبار لحالة الأحرف، فـ `#Work` و`#work` وسم واحد.

### أسماء غير قياسية { #non-standard-names }

للملفات في المجلد التي لا تتبع أسماؤها نظام الملاحظات، مثل ملف أسقطه جهاز آخر في مجلد مُزامَن.

| الخيار | يعرض |
|---|---|
| **الكل** | كل شيء |
| **الملاحظات فقط** | الملاحظات المسمّاة بشكل صحيح فقط |
| **غير المسمّاة فقط** | الملفات غير القياسية فقط، وهي قائمة مهام لإعادة تسميتها |

### تصنيف غير صالح { #bad-taxonomy }

للملاحظات ذات الاسم السليم لكنها تستخدم نوعًا أو أولوية أو فئة غير معرّفة في [الإعدادات](settings.md) (مثلًا رمز حذفته منذ ذلك الحين).

| الخيار | يعرض |
|---|---|
| **الكل** | كل شيء |
| **الصالحة فقط** | الملاحظات التي كل وسومها معرّفة |
| **غير الصالحة فقط** | الملاحظات ذات نوع أو أولوية أو فئة غير معرّفة |

**مسح الكل** يوقف كل عوامل التصفية. ويُبقي على اختيارك بين **الإنشاء** / **التحديث**.

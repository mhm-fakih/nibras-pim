# التنقل: الشريط الجانبي

يمتد عمود ضيق من الأيقونات على الجانب الأيسر من كل صفحة (وعلى الأيمن في العربية). هذا هو **الشريط الجانبي**، وبه تتنقل بين الصفحات.

## قسمان، واحد مفتوح في كل مرة { #two-bands-one-open-at-a-time }

ينقسم الشريط الجانبي إلى قسمين ملوّنين:

| القسم | الأيقونة | ما فيه |
|---|---|---|
| **على هذا الهاتف** | هاتف | صفحات تعمل كليًا على هاتفك، بشبكة أو بدونها. |
| **من الخادم** | سحابة | صفحات تعرض سجلات من خادم Nibras. ودون اتصال تعرض آخر ما تمت مزامنته. |

لا يُفتح إلا قسم واحد في كل مرة، كي يتسع القسم الذي تستخدمه للشاشة. اضغط عنوان القسم المغلق (تحته سهم صغير) لفتحه. وعندما تفتح صفحة من مكان آخر، كأداة أو إشعار، يفتح الشريط الجانبي القسم الذي تنتمي إليه تلك الصفحة.

**الإعدادات** في الأسفل، خارج القسمين، وتظهر دائمًا.

## على هذا الهاتف { #on-this-phone }

من الأعلى إلى الأسفل:

| الأيقونة | الصفحة | انظر |
|---|---|---|
| مسجد | **مواقيت الصلاة** | [مواقيت الصلاة والأذان](prayer.md) |
| منبّه | **المنبّهات** | [المنبّهات والتذكيرات والرنين](alarms.md) |
| ملاحظة | **الملاحظات**: ملاحظاتك، الشاشة الرئيسية | [كتابة الملاحظات وتعديلها](notes.md) |
| روبوت | **إجابات الذكاء الاصطناعي**: مجلد ملاحظات ثانٍ للقراءة فقط | [إجابات الذكاء الاصطناعي](ai-answers.md) |
| تقويم | **التقويم** | [التقويم](calendar.md) |
| صور | **المعرض** | [المعرض](gallery.md) |
| سماعة رأس | **الوسائط**: مكتبة الصوت والفيديو لديك | [مشغّل الوسائط](player.md) |
| مجلد بسهم | **جمع الملفات** | [جمع الملفات](collect.md) |

يمكن إيقاف **مواقيت الصلاة** و**جمع الملفات**. والصفحة الموقوفة تختفي من الشريط الجانبي.

## من الخادم { #from-the-server }

| الخانة | الصفحة |
|---|---|
| **T**، **P**، **J**، **G**، **N**، **W**، **R** | أنواع السجلات السبعة: **المهام**، **الخطط**، **اليوميات**، **الأهداف**، **الملاحظات**، **الكتابات**، **المصادر**. الرقم بين القوسين هو عدد سجلات ذلك النوع الموجودة على الهاتف. |
| بطاقات | **البطاقات التعليمية** |
| علامة اقتباس | **المقتطفات** |
| أشخاص | **جهات الاتصال** |
| كرة أرضية بعدسة مكبّرة | **البحث في الخادم** |
| سهم دائري | **تحديث صفحات الخادم**. يعيد تحميل كل صفحات الخادم من الخادم. ولا يفتح صفحة. |

كل هذه مشروحة في [صفحات الخادم](server-pages.md).

## زر الرجوع { #the-back-button }

من أي صفحة غير الملاحظات، تعيدك إيماءة الرجوع في النظام إلى الملاحظات بدل مغادرة التطبيق. وداخل صفحة (ملاحظة مفتوحة، سجل مفتوح)، يغلق الرجوع ذلك أولًا.

تتذكر كل صفحة حالتها الخاصة وأنت في مكان آخر: موضع التمرير، والسجل الذي كان مفتوحًا، والمجموعات المطوية، ونص البحث، كلها تبقى كما هي حين تعود.

## المشغّل المصغّر { #the-mini-player }

بمجرد تشغيل شيء ما، يظهر شريط رفيع أسفل كل صفحة. اضغط الشريط لفتح [المشغّل](player.md) كاملًا؛ واضغط زر التشغيل/الإيقاف المؤقت فيه لتبديل التشغيل دون مغادرة الصفحة التي أنت فيها.

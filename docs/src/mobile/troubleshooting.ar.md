# النسخ الاحتياطي واستكشاف الأخطاء والأسئلة الشائعة

## النسخ الاحتياطي { #backing-up }

### ملاحظاتك ملفات أصلًا { #your-notes-are-already-files }

كل ما تكتبه موجود في ملفات عادية داخل مجلدات اخترتها:

| ماذا | أين |
|---|---|
| الملاحظات | ملف `.md` لكل منها، في **مجلد الملاحظات** |
| مرفقات الملاحظات والمجموعات | مجلد `.d` بجانب كل ملاحظة |
| التمييزات في الملاحظات | داخل ملف الملاحظة نفسه (`==…==`) |
| علامات الوسائط | ملف `.tmk` بجانب كل ملف صوت أو فيديو |
| الصور المعلَّمة | الصورة نفسها؛ والأصول في مجلد مخفي `.scr-backup` بجانبها |

لنسخها احتياطيًا، انسخ المجلدات إلى حاسوب أو أبقِها متزامنة بأداة لمزامنة المجلدات مثل Syncthing. إلغاء تثبيت knotes لا يحذفها.

### ما يوجد داخل التطبيق { #what-lives-inside-the-app }

بعض الأشياء يحفظها التطبيق لا مجلداتك:

- إعداداتك، بما فيها مسارات المجلدات، والأنواع والفئات، وتفاصيل الخادم،
- المنبّهات، وإعدادات مواقيت الصلاة،
- إعدادات المشغّل وآخر موضع في كل ملف وسائط،
- الحالة الخاصة بالهاتف لسجلات الخادم: مقروء/غير مقروء وقائمة النجوم المختصرة الخاصة،
- النسخة المحفوظة من سجلات الخادم، والتغييرات التي لا تزال تنتظر الإرسال.

تضيع هذه إن ألغيت تثبيت التطبيق أو مسحت بياناته. قبل فعل أيٍّ منهما، دع التغييرات المنتظرة تُزامَن إلى الخادم، ودوّن إعداداتك. كل ما على الخادم يُعاد تنزيله عند الاتصال مجددًا.

## استكشاف الأخطاء { #troubleshooting }

### صفحة الملاحظات فارغة { #the-notes-page-is-empty }

- تبدأ القائمة على **اليوم**. إن لم تكتب شيئًا اليوم، تكون فارغة. افتح شريط **عوامل التصفية** واضغط **مسح الكل**.
- تحقق من **الإعدادات ← مجلد الملاحظات**. المسار الذي يبدو صحيحًا لكنه غير موجود (خطأ كتابي، `notes` بدل `Notes`، بطاقة ذاكرة غير مُدخلة) يعطي تطبيقًا فارغًا دون أي خطأ. وجولة الإعداد (**الإعدادات ← عرض جولة الإعداد**) تبيّن ما إذا كان كل مجلد موجودًا وما فيه.
- تأكد من أن الوصول إلى الملفات لا يزال ممنوحًا (انظر أدناه).

### «تعذّرت كتابة الملاحظة. تحقّق من أن إذن الوصول إلى الملفات لا يزال ممنوحًا.» { #could-not-write-the-note-check-that-file-access-is-still-granted }

يحتاج knotes إلى **All files access** (الوصول إلى جميع الملفات). افتح إعدادات أندرويد ← التطبيقات ← knotes ← الأذونات (أو **Special app access → All files access**) وفعّله. إن كان متوقفًا عند بدء التطبيق، يعرض التطبيق **منح الوصول إلى الملفات** مجددًا.

### المنبّهات أو التذكيرات أو الرنين تأتي متأخرة، أو لا تأتي { #alarms-reminders-or-the-chime-come-late-or-not-at-all }

- إن قالت صفحة المنبّهات **المنبّهات الدقيقة غير مسموحة لهذا التطبيق**، فاسمح بـ **المنبّهات والتذكيرات** لـ knotes في إعدادات أندرويد.
- اسمح بالإشعارات لـ knotes. بدونها يخفي أندرويد التذكيرات والرنين وإشعار الأذان.
- أبقِ **إشعار دائم** مفعّلًا (الإعدادات ← **الحالة والرنين**). فهو يُبقي التطبيق يعمل كي ترنّ المنبّهات في وقتها.
- بعض الهواتف توقف التطبيقات في الخلفية لتوفير البطارية. إن ظلت المنبّهات تتأخر، فاستثنِ knotes من تحسين البطارية في إعدادات أندرويد.

### لم يُرفع الأذان { #the-athan-didnt-sound }

في صفحة [مواقيت الصلاة](prayer.md)، افتح **الأذان** وتحقق من أن:

- **تفعيل التنبيهات** مفعّل. وإلا تعرض الصفحة **التنبيهات متوقفة**.
- تلك الصلاة محددة تحت **رفع الأذان عند**.
- مستوى صوتها تحت **مستوى الصوت لكل صلاة** ليس 0، وأن مستوى صوت **المنبّه** في الهاتف ليس صفرًا. يمكن أن يكون الأذان أخفض من مستوى صوت المنبّه، لا أعلى منه أبدًا.
- اضغط **استماع** لتجربة الصوت.

### لم يُسكَت الهاتف للصلاة { #the-phone-wasnt-silenced-for-prayer }

**الصامت ← الوضع الصامت في هذه الأوقات** يحتاج إلى إذن «عدم الإزعاج». إن عرضت اللوحة **لا يسمح أندرويد لأي تطبيق بتغيير الرنين دون إذن «عدم الإزعاج».**، فاضغط **منح الإذن**. وتحقق أيضًا من أن الصلاة محددة تحت **في هذه الأوقات**.

### مواقيت الصلاة لا تطابق مسجدي { #prayer-times-dont-match-my-mosque }

تدرّج في **الطريقة**: اضبط **موقعك**، ثم **المذهب** (العصر)، ثم **طريقة الحساب**. واضبط الباقي بدقة عبر **الأوقات ← تعديل كل وقت**. فرق دقيقة أو دقيقتين في كل وقت أمر طبيعي بين الطرق.

### «لا يمكن حذف هذه الملاحظة» { #cant-delete-this-note }

للملاحظة ملفات في مجلد مرفقاتها. افتحه عبر **فتح مجلد الملفات**، وانقل الملفات أو احذفها، ثم احذف الملاحظة. انظر [حذف ملاحظة](notes.md#delete-a-note).

### صفحات الخادم فارغة أو قديمة { #server-pages-are-empty-or-out-of-date }

- تحقق من حالة الاتصال في أعلى صفحة سجلات (**متصل** / **غير متصل**).
- **فشل تسجيل الدخول — تحقّق من اسم المستخدم وكلمة المرور في الإعدادات**: صحّحهما في **الإعدادات ← خادم Nibras**.
- لا تصل إلى الهاتف إلا السجلات **ذات العلامات** (المحفوظة). للحصول على سجل آخر، استخدم [البحث في الخادم](server-pages.md#search-server) وعلّمه.
- اضغط **تحديث صفحات الخادم** في أسفل الشريط الجانبي لإعادة تحميل كل شيء.

### البحث في الخادم يعرض خطأ { #search-server-shows-an-error }

| تذكر الرسالة | المعنى |
|---|---|
| **401** | اسم المستخدم أو كلمة المرور خاطئة. |
| **403** | أنت مسجّل الدخول، لكن الحساب غير مسموح له بالبحث. |
| **404** | يعمل الخادم بإصدار أقدم بلا بحث. حدّث الخادم. |
| **تعذّر الوصول** | تحقق من العنوان في الإعدادات ومن أن الخادم يعمل. |

### صفحة إجابات الذكاء الاصطناعي تقول إن المجلد مفقود { #the-ai-answers-page-says-the-folder-is-missing }

لم يصل المجلد إلى الهاتف بعد، أو هو في مكان آخر. تحقق من أداة مزامنة المجلدات، أو اضبط **الإعدادات ← مجلد إجابات الذكاء الاصطناعي** على مكانه الفعلي.

### «لم يبقَ شيء هنا» في المشغّل { #nothing-left-here-in-the-player }

لم يجد **التشغيل التالي** ملفًا لتشغيله: كل ما في ذلك المجلد عليه علامات أو شُغّل من قبل. اختر وضعًا آخر، أو افتح ملفًا من صفحة الوسائط.

## الأسئلة الشائعة { #faq }

**هل يحتاج knotes إلى اتصال بالإنترنت؟**
لا. الملاحظات، والمشغّل، والمعرض، والجمع، ومواقيت الصلاة، والمنبّهات، والأدوات تعمل كلها دون اتصال. صفحات الخادم والمزامنة وحدها تحتاج إلى خادم Nibras، وتعرض آخر نسخة مُزامَنة حين يتعذّر الوصول إليه.

**هل يمكنني استخدام مجلد ملاحظات لدي من قبل؟**
نعم. وجّه **مجلد الملاحظات** إليه. تظهر ملفات `.md` و`.txt` العادية فورًا، وتصبح ملاحظات موسومة بالكامل حين تعطيها نوعًا وأولوية وفئة.

**هل يمكنني تعديل ملاحظاتي على حاسوب؟**
نعم. إنها ملفات نصية عادية. أبقِ المجلد متزامنًا بأداة مزامنة، فتُفتح الملاحظات نفسها في تطبيق Nibras لسطح المكتب أو أي محرر نصوص. انظر [ملاحظات نصية عادية](../concepts/plain-text-notes.md).

**هل يغادر هاتفي أي شيء؟**
فقط ما ترسله إلى خادم Nibras الخاص بك، إن أعددت واحدًا. ويُقرأ الموقع لمواقيت الصلاة فقط عند ضغطك **استخدام موقعي**، ولا يُبحث عن شيء عبر الإنترنت.

**لماذا تبقى الأرقام 0–9 في العربية؟**
عن قصد. الأوقات وأسماء الملفات وملفات العلامات مشتركة مع أدوات أخرى، وإبقاء الأرقام الغربية يجعلها مقروءة في كل مكان.

**لماذا لا توجد سلة محذوفات؟**
الملاحظة أو الصورة أو التسجيل المحذوف ملف محذوف. إن كنت تزامن مجلداتك مع حاسوب، فقد تحتفظ أداة المزامنة بإصدارات قديمة. تحقق من إعداداتها.

**هل يمكنني إيقاف الميزات التي لا أستخدمها؟**
يمكن إيقاف **مواقيت الصلاة** (في صفحتها، تحت **الأذان**) و**تجميع الملفات** (في الإعدادات)، فتختفيان من الشريط الجانبي. وصفحات الخادم تبقى ببساطة فارغة إن لم يُعدّ خادم.

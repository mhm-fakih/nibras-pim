# جمع الملفات

تتراكم لقطات الشاشة وصور الكاميرا والتنزيلات والتسجيلات الصوتية في المجلدات التي تكتب فيها التطبيقات الأخرى. تجمع **جمع الملفات** هذه الملفات في ملاحظة واحدة، مع إرفاقها وإعادة تسميتها كي تُرتَّب حسب التاريخ. فتصبح لقطة الشاشة المتناثرة شيئًا يمكنك أن تعطيه عنوانًا ووسومًا وتعثر عليه لاحقًا.

افتحها من الشريط الجانبي (أيقونة المجلد ذي السهم، الأخيرة في **على هذا الهاتف**).

## كيف تعمل { #how-it-works }

1. عند فتح الصفحة، تفحص مجلداتك المصدر (**جارٍ فحص المجلدات المصدر…**) وتعرض ما وجدته، كل ملف مع اسمه الجديد.
2. يبيّن الشريط الإعلامي أين ستذهب الملفات: **ستُنقل إلى مجلد فرعي جديد مؤرَّخ داخل … وتُعاد تسميتها بالطابع الزمني القياسي.**
3. اضغط **اجمع N ملف**. تُنقل الملفات وتُعرض النتيجة (**نُقل N من N ملف**).
4. اضغط **افحص مجددًا** (أو سهم **إعادة الفحص** في الأعلى) لإعادة البحث.

!!! warning "الملفات تُنقل ولا تُنسخ"
    تُزال الملفات المجمّعة من مجلداتها الأصلية. وتصبح موجودة الآن في المجموعة.

## ما الذي تحصل عليه { #what-you-get }

كل مجموعة هي [ملاحظة عادية بمرفقات](notes.md#attachments):

```
2026_06_11-095700~W~p2~P.md        the note: "Collected 3 files" and a list
2026_06_11-095700~W~p2~P.d/        the files
    2024_01_15-123045_Screenshot_Chrome.png
    2026_06_11-095700_notes.pdf
    …
```

- تستخدم الملاحظة **النوع والأولوية والفئة** الافتراضية لديك للملاحظات الجديدة، تمامًا كالملاحظة السريعة. أعد وسمها كأي ملاحظة أخرى.
- يُعاد تسمية كل ملف بحيث **يتصدّر الطابع الزمني اسمه**. إن احتوى الاسم الأصلي على تاريخ ووقت يمكن تمييزهما (كما في معظم أسماء الكاميرا ولقطات الشاشة والمسجّلات)، يُستخدم ذلك الوقت. وإلا يُستخدم وقت آخر تعديل للملف، وتُعلِّمه القائمة بـ **تاريخ التعديل**.

مثلًا، يصبح `Screenshot_2024-01-15-12-30-45_Chrome.png` هو `2024_01_15-123045_Screenshot_Chrome.png`.

!!! tip "ضع المجموعات في مجلد ملاحظاتك"
    افتراضيًا تذهب المجموعات إلى مجلد ملاحظاتك، فتظهر في صفحة الملاحظات ويقرؤها حاسوبك كملاحظات. وإن اخترت وجهة أخرى، تحذّرك جولة الإعداد: *لن تظهر الملاحظات المجمّعة في الشاشة الرئيسية.*

## اختيار المجلدات { #choosing-the-folders }

في [الإعدادات](settings.md)، ضمن **تجميع الملفات**:

- **المجلدات المصدر**: المجلدات التي تُفحص. افتراضيًا هي الأماكن المعتادة للقطات الشاشة وصور الكاميرا والصور والتنزيلات والتسجيلات. أضف مجلداتك عبر **إضافة مجلد**. ألغِ تحديد مجلد لتخطيه مع إبقائه في القائمة.
- **مجلد الوجهة (New)**: حيث تُكتب المجموعات.

## الجمع تلقائيًا كل يوم { #collect-automatically-every-day }

فعّل **التجميع تلقائيًا كل يوم** واختر وقتًا (**عند 15:00** افتراضيًا). عندها تُجرى المجموعة نفسها تلقائيًا كل يوم. ويصلك إشعار (**جُمع N ملف**) فقط عندما يُجمع شيء فعلًا.

## إيقاف الميزة { #switching-the-feature-off }

مفتاح **تجميع الملفات** في الإعدادات يزيل صفحة الجمع من الشريط الجانبي ويوقف التشغيل اليومي، بغض النظر عن الإعداد التلقائي.

# المنبّهات والتذكيرات والرنين

يمكن لـ knotes أن يُصدر صوتًا في لحظة معينة بأربع طرق:

- **المنبّهات** التي تضبطها بنفسك: وقت على الساعة، أو عدّ تنازلي، أو فارق عن وقت صلاة.
- **تذكيرات الخطط** قبل الأحداث في مخطِّط Nibras.
- **رنين كل 15 دقيقة** يشير إلى مرور الوقت.
- **الأذان**، وتشرحه صفحة [مواقيت الصلاة والأذان](prayer.md).

كلها تستمر في العمل والتطبيق مغلق، ويُعاد تفعيلها بعد إعادة تشغيل الهاتف.

## المنبّهات { #alarms }

افتح **المنبّهات** (أيقونة المنبّه) من الشريط الجانبي. يعرض الرأس **المنبّهات** وعدد المنبّهات المفعّلة (**N مفعّل**).

### إضافة منبّه { #add-an-alarm }

اضغط زر **+** (**إضافة منبّه**). يُفتح نموذج **منبّه جديد**:

1. **التسمية**: اختيارية، تظهر في القائمة وفي الإشعار.
2. **النوع**: اختر **وقت** أو **عدّ تنازلي** أو **صلاة**. تتغير الحقول أدناه تبعًا لذلك. تغيير النوع يحتفظ بما كتبته في الأنواع الأخرى.
3. اضبط التوقيت (انظر أدناه).
4. **الصوت**: **اختيار…** أي ملف صوتي على الهاتف، أو **الافتراضي** لاستخدام **صوت المنبّه الافتراضي**.
5. **التكرار: N×**: عدد مرات تشغيل الصوت (1–20).
6. **مستوى الصوت: N%**: مدى الارتفاع، لهذا المنبّه وحده.
7. احفظ.

#### وقت { #time }

**الساعة** و**الدقيقة**، و**الأيام** التي يتكرر فيها. **الأيام — دون اختيار يعني مرة واحدة**: إن لم تختر أي يوم، يرنّ مرة واحدة في أقرب موعد لذلك الوقت، كما يفعل منبّه الهاتف.

#### عدّ تنازلي { #countdown }

اختر **المدة** (5 أو 10 أو 15 أو 20 أو 30 دقيقة، أو 1 س، أو 1 س 30 د، أو 2 س)، أو اكتب أي رقم في **أو بالدقائق**.

العدّ التنازلي لا يبدأ بمجرد حفظه. ابدأه بزر التشغيل في صفّه. يظهر **يعمل** أثناء العدّ و**لم يبدأ** في غير ذلك. وإن كان الهاتف مطفأً حين كان يجب أن يرنّ، فلن يرنّ متأخرًا عند عودة الهاتف.

#### صلاة { #prayer }

اختر إحدى الصلوات و**الفارق — السالب يعني «قبل»**، مثلًا −30 لنصف ساعة قبل الفجر، أو **عند** للوقت نفسه. ويمكنك أيضًا قصره على **أيام** معينة. يتحرك المنبّه مع وقت الصلاة كل يوم ويستخدم إعدادات صفحة [مواقيت الصلاة](prayer.md)، فيتوافق دائمًا مع ما تعرضه تلك الصفحة.

### القائمة { #the-list }

كل صف يبيّن ماهية المنبّه و**متى سيرنّ فعلًا في المرة القادمة**، مثلًا **يرنّ غدًا 05:10**. وإن كان المنبّه مفعّلًا لكن لا موعد له (عدّ تنازلي لم يبدأ مثلًا)، يظهر **غير مجدول**، كي لا يبدو جاهزًا وهو ليس كذلك.

في كل صف:

- مفتاح لتفعيله أو إيقافه،
- زر تشغيل/إيقاف (للعدّ التنازلي فقط)،
- زر حذف، يسأل أولًا **حذف هذا المنبّه؟**،
- **تعديل**.

عندما يرنّ المنبّه، يعرض إشعار تسميته، ويُشغَّل الصوت بعدد المرات التي حددتها وبمستوى صوت ذلك المنبّه، على قناة المنبّهات.

!!! warning "المنبّهات ترنّ متأخرة؟"
    إن عرضت الصفحة **المنبّهات الدقيقة غير مسموحة لهذا التطبيق، لذا قد ترنّ متأخرة.**، فافتح إعدادات أندرويد الخاصة بـ knotes واسمح بـ **المنبّهات والتذكيرات**.

تعرض [أداة العد التنازلي للمنبّهات](widgets.md#alarms-countdown) الوقت المتبقي حتى منبّهات اليوم المتبقية.

## تذكيرات الخطط { #plan-reminders }

إن كنت متصلًا بـ[خادم Nibras](sync.md)، يذكّرك knotes قبل أحداث **الخطط** و**اليوميات** القادمة التي لها وقت بداية. اضبطها في [الإعدادات](settings.md) ← **تذكيرات الخطط**:

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| **المهل المسبقة (بالدقائق)** | `60, 5` | الدقائق قبل البداية. يُسمح بعدة قيم، ولكل منها تنبيه مستقل. `60, 5` تعني قبل ساعة وقبل خمس دقائق. |
| **صوت التذكير** | الافتراضي | **اختيار الصوت** لانتقاء صوت. |
| **يتطلب الإيقاف** | متوقف | مفعّل: منبّه بملء الشاشة يتكرر صوته حتى تضغط **إغلاق**. متوقف: يُشغَّل الصوت بعدد التكرار أدناه ثم يتوقف. |
| **تكرار الصوت (مرات)** | 4 | عدد مرات تشغيل الصوت حين يكون **يتطلب الإيقاف** متوقفًا. |

يعرض إشعار التذكير الخطة وموعد بدايتها (**بعد 5 دقيقة · 14:30**). ويبقى حتى تتصرف حياله:

- **إغلاق** يزيل هذا التذكير. أما التذكيرات اللاحقة للحدث نفسه فتأتي كالمعتاد.
- **إيقاف التذكيرات** يلغي التذكيرات المتبقية لهذا الموعد، حين تكون قد وصلت بالفعل. تذكيرات الأسبوع القادم لخطة متكررة لا تتأثر.

وإن كانت هناك مهام على الخادم تجاوزت موعد استحقاقها، ينشر knotes أيضًا إشعارًا واحدًا **N مهمة متأخرة**.

## رنين كل 15 دقيقة { #the-15-minute-chime }

رنين خفيف عند **‎:00 و‎:15 و‎:30 و‎:45**، لتشعر بمرور الوقت دون أن تنظر إلى شيء. اضبطه في [الإعدادات](settings.md) ← **الحالة والرنين**:

- **رنين كل 15 دقيقة**: تشغيل أو إيقاف (مفعّل افتراضيًا؛ ويُعرض أيضًا في جولة الإعداد باسم **رنين كل ربع ساعة**).
- **ساعة بداية الرنين** و**ساعة نهاية الرنين**: لا يرنّ إلا داخل هذه الفترة (من 8 إلى 22 افتراضيًا).
- **اختيار ملف الرنين**: أي ملف صوتي. إن لم تختر شيئًا، يُستخدم رنين قصير مدمج في التطبيق.

يُشغَّل الرنين بمستوى صوت **الإشعارات** في هاتفك، فيكون بارتفاع إشعاراتك الأخرى ويلتزم بذلك المنزلق.

## إشعار الحالة { #the-status-notification }

**إشعار دائم** (في **الحالة والرنين**، مفعّل افتراضيًا) يُبقي إشعارًا هادئًا مستمرًا يعرض عدد ملاحظات اليوم (**اليوم: N · الإجمالي: M**)، وعند المزامنة مع Nibras، ما إذا كنت متصلًا ومتى كانت آخر مزامنة.

كما يُبقي التطبيق يعمل في الخلفية، مما يساعد التذكيرات والرنين على العمل في وقتها. إن أوقفته وبدأت المنبّهات تصل متأخرة، فأعد تفعيله.

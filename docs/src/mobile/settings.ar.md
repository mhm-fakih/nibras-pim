# مرجع الإعدادات

افتح **الإعدادات** من الترس في أسفل الشريط الجانبي.

تنقسم الإعدادات إلى تبويبات، واحد لكل ميزة، تظهر صفًّا من الشرائح في الأعلى: **عام**، و**الخادم**، و**أوقات الصلاة**، و**الوسائط**، و**جمع الملفات**، و**قوائم التحقق**، و**التنبيهات**، و**التقويم والأدوات**. ويتذكّر كل تبويب موضع التمرير الذي تركته فيه.

تبويبات الميزات الاختيارية تبدأ بمفتاح يشغّل الميزة كلها أو يوقفها. عند إيقافها تختفي صفحاتها من الشريط الجانبي ولا يعمل شيء منها في الخلفية؛ وتُخفى بقية إعدادات ذلك التبويب حتى تعيد تشغيلها.

!!! warning "اضغط «حفظ»"
    تسري التغييرات عندما تضغط **حفظ** في الأعلى. وزر **حفظ** واحد يشمل كل التبويبات. و**رجوع** يغادر دون حفظ. الاستثناءان هما **اللغة** و**لون السمة**، فهما يُطبَّقان لحظة الضغط عليهما.

إعدادات مواقيت الصلاة موجودة في صفحة [مواقيت الصلاة](prayer.md) نفسها، وإعدادات المشغّل في [المشغّل](player.md#player-settings). تغطي هذه الصفحة كل ما عدا ذلك، تبويبًا تبويبًا.

## عام { #general }

### اللغة { #language }

**English** أو **عربي** أو **Français**. تُطبَّق فورًا. في العربية تكون الواجهة كلها من اليمين إلى اليسار. لا تُترجم ملاحظاتك وملفاتك أبدًا.

### لون السمة { #theme-colour }

اللون الأساسي للتطبيق. المس لونًا ليُطبَّق في الحال:

- **الكحلي**، وهو الافتراضي ولون أيقونات التطبيق، أو أحد سبعة ألوان أخرى (أزرق مخضرّ، أخضر، بنفسجي، عنابي، برتقالي، بنّي، رمادي فحمي).
- زر الخلفية (**ألوان خلفية الهاتف**) يتبع ألوان الهاتف نفسه، كما يستخرجها أندرويد 12 وما بعده من خلفية شاشتك.
- **لون آخر (hex)**: اكتب أي لون من ست خانات، مثل `2E6B3A`. يُطبَّق بمجرد كتابة الخانة السادسة.

تُشتق من اللون الذي تختاره نسختان فاتحة وداكنة، تتبعان الوضع الداكن في الهاتف.

### الملاحظات { #notes }

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| **اسم التطبيق** | نبراس محمول | العنوان في أعلى صفحة الملاحظات. الفارغ يعرض اسم التطبيق نفسه بلغة الواجهة الحالية. |
| **رمز النوع الافتراضي (للملاحظات الجديدة)** | أول نوع | شريحة النوع المحددة مسبقًا للملاحظات الجديدة. تبقى محددة بعد كل حفظ. الفارغ يعني أول نوع في القائمة. |
| **رمز الفئة / القسم الافتراضي (للملاحظات الجديدة)** | أول فئة | الفئة المحددة مسبقًا للملاحظات الجديدة. الفارغ يعني أول فئة. |
| **الأولوية الافتراضية (للملاحظات الجديدة)** | 2 | الأولوية المحددة مسبقًا للملاحظات الجديدة. |
| **الأولوية القصوى (الأدوات)** | 4 | الأولوية التي تعرضها أداتا **الأولوية القصوى** و**مهام اليوم**، والتي تحسبها أداة مؤشرات الأداء. المهام المضافة من الأداة تأخذ هذه الأولوية. |
| **مجلد الملاحظات** | `Notes` في أعلى ذاكرة التخزين | حيث توجد ملاحظاتك. استخدم زر المجلد لاختيار واحد. |
| **مجلد إجابات الذكاء الاصطناعي** | مجلد الملاحظات + `-ai` | مجلد [إجابات الذكاء الاصطناعي](ai-answers.md) للقراءة فقط. الفارغ يستخدم الافتراضي. |
| **صيغة الطابع الزمني** | `yyyy_MM_dd-HHmmss` | كيف يُكتب الوقت في بداية اسم ملف الملاحظة الجديدة. يعرض **الآن:** مثالًا، أو **صيغة غير صالحة**. |
| **أسطر المعاينة** | 3 | أسطر النص المعروضة في كل بطاقة ملاحظة. |
| **أدنى أولوية**، **أعلى أولوية** | 1، 5 | نطاق الأولويات المعروضة. |

!!! tip "أحرف الطابع الزمني"
    في صيغة الطابع الزمني، `HH` هي الساعة، و`mm` الدقائق، و`MM` هي **الشهر**. الخلط بينها يعطي أسماء ملفات غريبة. تغيير الصيغة يؤثر في الملاحظات الجديدة فقط. وتبقى أسماء الملفات الموجودة كما هي.

### الأنواع والفئات { #types-and-categories }

قوائم أنواع الملاحظات وفئاتها، لكل إدخال **الرمز** القصير و**الاسم**.

- **الأنواع**: نوع واحد لكل ملاحظة. يأتي الرمز أولًا في اسم الملف.
- **الفئات**: فئة واحدة لكل ملاحظة. يأتي الرمز أخيرًا في اسم الملف.

استخدم **إضافة نوع** / **إضافة فئة** لإضافة إدخال، وأيقونة السلة (**إزالة**) لحذفه. اجعل الرموز قصيرة (حرف أو حرفان). لا يمكن استخدام الأحرف `~ / \ : * ? " < > |`.

الافتراضيات هي الأنواع `W` عمل، `H` منزل، `I` أفكار، `T` مهام، والفئات `P` شخصي، `W` عمل، `M` متفرقات.

!!! note "عند الاتصال بـ Nibras"
    عند إعداد خادم Nibras، تُستبدل القائمتان بوحدات الخادم وأقسامه عند بدء التطبيق وكلما ضغطت **تحديث الملاحظات والمزامنة الآن**، كي يستخدم الهاتف والخادم الرموز نفسها. وقد يُكتب حينها فوق التغييرات التي تجريها هنا.

حذف رمز لا يغيّر الملاحظات الموجودة. والملاحظات التي لا تزال تستخدمه تظهر تحت عامل التصفية **تصنيف غير صالح** في صفحة الملاحظات.

### جولة الإعداد { #setup-tour }

**عرض جولة الإعداد** يمرّ على المجلدات مجددًا، شارحًا الغرض من كل منها.

### نسخة احتياطية { #backup }

**تصدير الإعدادات** يحفظ كل إعدادات هذا الهاتف في ملف JSON واحد تختار أنت مكانه؛ و**استيراد الإعدادات** يعيد تحميل ملف كهذا، عند إعادة التثبيت أو على هاتف ثانٍ. تُحفظ الإعدادات المعروضة على الشاشة أولًا، فيكون ما تراه هو ما يدخل الملف. كلمة مرور الخادم غير مشمولة. والاستيراد يعيد تشغيل التطبيق (**استُورد N إعدادًا — إعادة التشغيل**).

## الخادم { #server }

**استخدام خادم نبراس** (مفعّل افتراضيًا): عند إيقافه لا يتصل التطبيق بأي مكان، ويختفي نطاق **من الخادم** من الشريط الجانبي.

### خادم Nibras { #nibras-server }

متصفح للقراءة فقط لقاعدة بيانات Nibras على حاسوبك. انظر [مزامنة Nibras](sync.md#connect) لشرح كل حقل.

| الإعداد | المعنى |
|---|---|
| **البروتوكول** | `http` أو `https` |
| **العنوان / المضيف**، **المنفذ**، **السياق** | عنوان الخادم. ويعرض **العنوان الكامل** النتيجة. |
| **اسم المستخدم**، **كلمة المرور** | حسابك في Nibras، ويُستخدم لتسجيل الدخول عند المزامنة. |
| **مجلد الملفات** | حيث توجد مرفقات السجلات على الهاتف (`Nibras` في أعلى ذاكرة التخزين افتراضيًا). |

### زر النجمة { #star-button }

ما تفعله النجمة على سجلات الخادم:

- **إشارة مرجعية على هذا الجهاز**: قائمة مختصرة خاصة. لا يُرسل شيء إلى الخادم. (الافتراضي.)
- **إزالة الإشارة في Nibras**: الضغط على النجمة يزيل السجل من محفوظاتك على الخادم. انظر [صفحات الخادم](server-pages.md#bookmark-the-star).

**حجم الخط N×** يحدد حجم نص النص الكامل للمصادر (1.5× افتراضيًا).

## أوقات الصلاة { #prayer-times }

مفتاح واحد، **أوقات الصلاة** (مفعّل افتراضيًا): صفحة الصلاة والأذان والكتم والأداة. عند إيقافه تختفي الصفحة من الشريط الجانبي ولا يُجدول شيء. الموقع وطريقة الحساب والأصوات تُضبط في صفحة [مواقيت الصلاة](prayer.md) نفسها. ومن هذا المفتاح تُعاد الصفحة إن أُوقفت من صفحة الصلاة.

### أداة الملاحظات الأخيرة { #recent-notes-widget }

إلى أي مدى ترجع [أداة الملاحظات الأخيرة](widgets.md#recent-notes) (من **اليوم فقط** حتى 30 يومًا، 3 افتراضيًا)، وكم كلمة قبل **اقرأ المزيد** (10–200، 40 افتراضيًا)، و**حجم النص N sp** (10–28، 15 افتراضيًا).

### أداة لوحة المهام { #tasks-board-widget }

**حجم النص N sp** في [أداة لوحة المهام](widgets.md#tasks-board) (10–24، 13 افتراضيًا) وعدد **أعمدتها** (1–4، 2 افتراضيًا).

يُعاد رسم الأدوات عند الضغط على **حفظ**، فيظهر الحجم الجديد في الحال.

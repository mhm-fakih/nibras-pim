# مرجع الإعدادات

افتح **الإعدادات** من الترس في أسفل الشريط الجانبي.

!!! warning "اضغط «حفظ»"
    تسري التغييرات في هذه الصفحة عندما تضغط **حفظ** في أعلى اليمين. و**رجوع** يغادر دون حفظ. الاستثناء الوحيد هو **اللغة**، التي تتغير لحظة الضغط عليها.

إعدادات مواقيت الصلاة موجودة في صفحة [مواقيت الصلاة](prayer.md) نفسها، وإعدادات المشغّل في [المشغّل](player.md#player-settings). تغطي هذه الصفحة كل ما عدا ذلك، بترتيب ظهوره.

## اللغة { #language }

**English** أو **عربي** أو **Français**. تُطبَّق فورًا. في العربية تكون الواجهة كلها من اليمين إلى اليسار. لا تُترجم ملاحظاتك وملفاتك أبدًا.

## الملاحظات { #notes }

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| **اسم التطبيق** | knotes | العنوان في أعلى صفحة الملاحظات. |
| **رمز النوع الافتراضي (للملاحظات الجديدة)** | أول نوع | شريحة النوع المحددة مسبقًا للملاحظات الجديدة. تبقى محددة بعد كل حفظ. الفارغ يعني أول نوع في القائمة. |
| **رمز الفئة / القسم الافتراضي (للملاحظات الجديدة)** | أول فئة | الفئة المحددة مسبقًا للملاحظات الجديدة. الفارغ يعني أول فئة. |
| **الأولوية الافتراضية (للملاحظات الجديدة)** | 2 | الأولوية المحددة مسبقًا للملاحظات الجديدة. |
| **الأولوية القصوى (الأدوات)** | 4 | الأولوية التي تعرضها أداتا **الأولوية القصوى** و**مهام اليوم**، والتي تحسبها أداة مؤشرات الأداء. المهام المضافة من الأداة تأخذ هذه الأولوية. |
| **مجلد الملاحظات** | `Notes` في أعلى ذاكرة التخزين | حيث توجد ملاحظاتك. استخدم زر المجلد لاختيار واحد. |
| **مجلد إجابات الذكاء الاصطناعي** | مجلد الملاحظات + `-ai` | مجلد [إجابات الذكاء الاصطناعي](ai-answers.md) للقراءة فقط. الفارغ يستخدم الافتراضي. |
| **صيغة الطابع الزمني** | `yyyy_MM_dd-HHmmss` | كيف يُكتب الوقت في بداية اسم ملف الملاحظة الجديدة. يعرض **الآن:** مثالًا، أو **صيغة غير صالحة**. |
| **أسطر المعاينة** | 3 | أسطر النص المعروضة في كل بطاقة ملاحظة. |
| **أدنى أولوية**، **أعلى أولوية** | 1، 5 | نطاق الأولويات المعروضة. |

!!! tip "أحرف الطابع الزمني"
    في صيغة الطابع الزمني، `HH` هي الساعة، و`mm` الدقائق، و`MM` هي **الشهر**. الخلط بينها يعطي أسماء ملفات غريبة. تغيير الصيغة يؤثر في الملاحظات الجديدة فقط. وتبقى أسماء الملفات الموجودة كما هي.

## خادم Nibras { #nibras-server }

متصفح للقراءة فقط لقاعدة بيانات Nibras على حاسوبك. انظر [مزامنة Nibras](sync.md#connect) لشرح كل حقل.

| الإعداد | المعنى |
|---|---|
| **البروتوكول** | `http` أو `https` |
| **العنوان / المضيف**، **المنفذ**، **السياق** | عنوان الخادم. ويعرض **العنوان الكامل** النتيجة. |
| **اسم المستخدم**، **كلمة المرور** | حسابك في Nibras، ويُستخدم لتسجيل الدخول عند المزامنة. |
| **مجلد الملفات** | حيث توجد مرفقات السجلات على الهاتف. |

### زر النجمة { #star-button }

ما تفعله النجمة على سجلات الخادم:

- **إشارة مرجعية على هذا الجهاز**: قائمة مختصرة خاصة. لا يُرسل شيء إلى الخادم. (الافتراضي.)
- **إزالة الإشارة في Nibras**: الضغط على النجمة يزيل السجل من محفوظاتك على الخادم. انظر [صفحات الخادم](server-pages.md#bookmark-the-star).

**حجم الخط N×** يحدد حجم نص النص الكامل للمصادر (1.5× افتراضيًا).

## الأنواع والفئات { #types-and-categories }

قوائم أنواع الملاحظات وفئاتها، لكل إدخال **الرمز** القصير و**الاسم**.

- **الأنواع**: نوع واحد لكل ملاحظة. يأتي الرمز أولًا في اسم الملف.
- **الفئات**: فئة واحدة لكل ملاحظة. يأتي الرمز أخيرًا في اسم الملف.

استخدم **إضافة نوع** / **إضافة فئة** لإضافة إدخال، وأيقونة السلة (**إزالة**) لحذفه. اجعل الرموز قصيرة (حرف أو حرفان). لا يمكن استخدام الأحرف `~ / \ : * ? " < > |`.

الافتراضيات هي الأنواع `W` عمل، `H` منزل، `I` أفكار، `T` مهام، والفئات `P` شخصي، `W` عمل، `M` متفرقات.

!!! note "عند الاتصال بـ Nibras"
    عند إعداد خادم Nibras، تُستبدل القائمتان بوحدات الخادم وأقسامه عند بدء التطبيق وكلما ضغطت **تحديث الملاحظات والمزامنة الآن**، كي يستخدم الهاتف والخادم الرموز نفسها. وقد يُكتب حينها فوق التغييرات التي تجريها هنا.

حذف رمز لا يغيّر الملاحظات الموجودة. والملاحظات التي لا تزال تستخدمه تظهر تحت عامل التصفية **تصنيف غير صالح** في صفحة الملاحظات.

# المعرض

**المعرض** (أيقونة الصور) عارض صور بملء الشاشة لمجلد صور واحد ومجلداته الفرعية. ويمكنك أيضًا وضع علامات على الصورة (الرسم عليها، والتظليل، والقص، وإعادة التسمية) كي تُشرح لقطة الشاشة قبل إرفاقها بملاحظة أو إرسالها.

المجلد هو **مجلد المعرض** في [الإعدادات](settings.md) (ويُضبط أثناء جولة الإعداد باسم **مجلد الصور**). افتراضيًا هو مجلد `Pictures` في هاتفك.

## التصفح { #browsing }

- اسحب يمينًا أو يسارًا، أو استخدم الزرين المستديرين **الصورة السابقة** / **الصورة التالية**، للتنقل بين الصور.
- تُعرض الصور معتدلة، أيًّا كان اتجاه الكاميرا عند التقاطها.

## وضع علامات على صورة { #marking-up-a-picture }

يظهر صف من شرائح الأدوات فوق الصورة:

| الأداة | ما يفعله السحب |
|---|---|
| **عرض** | لا شيء؛ السحب يقلب الصفحة. هذا هو الافتراضي. |
| **قلم** | يرسم خطوطًا حرة. |
| **تظليل** | يرسم شريط تظليل عبر الصورة. السحب يحدد عرض الشريط؛ أما ارتفاعه فثابت، كرأس قلم التظليل. |
| **قص** | يحدد المنطقة التي تُحتفظ بها. |

أثناء تحديد أداة، يرسم السحب بدل قلب الصفحة، فاستخدم زري **الصورة السابقة** / **الصورة التالية** للانتقال. **التراجع عن آخر علامة** يزيل أحدث علامة.

حقل **تسمية (تُعيد تسمية الملف)** يعيد تسمية الصورة: تُضاف التسمية إلى نهاية اسم الملف. وتطبيق تسمية جديدة يستبدل السابقة بدل أن يضيف إليها.

!!! note "لا يوجد زر حفظ"
    تُحفظ علاماتك وتسميتك تلقائيًا عند مغادرة الصورة: بالانتقال إلى التالية أو السابقة، أو بالعودة إلى **عرض**، أو بمغادرة المعرض. إن فشل الحفظ، يقول التطبيق **تعذّر حفظ هذه الصورة — ما زالت علاماتها هنا.** ويبقى على الصورة كي لا يضيع شيء.

!!! tip "الأصل محفوظ"
    في المرة الأولى التي توضع فيها علامات على صورة، يُنسخ الأصل دون تعديل إلى مجلد مخفي `.scr-backup` بجانبها. لا شيء يفرغ ذلك المجلد تلقائيًا، فأفرغه من حين لآخر متى رضيت عن تعديلاتك.

يُطبَّق القص دائمًا في النهاية، أيًّا كان ترتيب رسمك، فتستقر علاماتك حيث وضعتها.

## حذف صورة { #deleting-a-picture }

!!! warning
    زر **حذف الصورة** الأحمر في الزاوية يحذف الصورة الحالية **فورًا، دون سؤال**. هذا يجعل تفريغ مجلد من لقطات الشاشة سريعًا، فكن حذرًا.

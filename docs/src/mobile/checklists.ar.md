# قوائم التحقق

**قوائم التحقق** (أيقونة القائمة المعلَّمة، تحت التقويم مباشرة في الشريط الجانبي) تحفظ الأمور الصغيرة التي تنوي فعلها كل يوم أو كل أسبوع: شحن الهاتف، ومراجعة قبل النوم، واتصال بالأهل. تعلّمها يومًا بيوم، ويُحفظ كل أسبوع في ملف Markdown بسيط. وهي منفصلة عن مهامك عن قصد، كي لا تطمر ثلاثون علامة يومية صغيرة العملَ الحقيقي.

## الصفحة { #the-page }

- يعرض الشريط العلوي الأسبوع (**الأسبوع 43**) وتواريخه، و**هذا الأسبوع** أو **لم يبدأ** (أسبوع ليس له ملف بعد). ينقلك السهمان إلى **الأسبوع السابق** و**الأسبوع التالي**.
- **اليوم** / **الأسبوع** للتبديل بين عرضين للأسبوع نفسه (انظر أدناه).
- **هذا الأسبوع** يعيدك حين تكون في أسبوع آخر. وفي الأسبوع الحالي يظهر في المكان نفسه **تخطيط الأسبوع التالي**.
- القلم (**تعديل القوائم**) وأيقونة الملاحظة (**تعديل كنص**) لتغيير البنود. انظر [تعديل القوائم](#edit-the-lists).

تُرتَّب البنود في **مجموعات**. تبدأ القائمة الجديدة بـ **بداية اليوم** و**منتصف اليوم** و**نهاية اليوم** و**الدراسة** و**أسبوعي**، وكلها فارغة. أعد تسمية المجموعات أو أضفها أو احذفها كما تشاء.

### اليوم: التعليم { #day-ticking }

عرض **اليوم** للتعليم. صفّان من الأزرار في الأعلى يختاران اليوم، من الاثنين إلى الأحد، ومع كلٍّ منها نسبة ما أُنجز (**75%**). يُعلَّم اليوم الحالي بنقطة، ويمكنك اختيار يوم آخر لتكمل ما فاتك أمس.

اضغط على بند لتدوير علامته: منجز (✓)، ثم منجز جزئيًا (◐)، ثم غير منجز. والبند المنجز جزئيًا يُحسب نصفًا. ويعرض عنوان كل مجموعة نسبتها لذلك اليوم.

مجموعة **أسبوعي** مختلفة: لبنودها علامة واحدة للأسبوع كله بدل علامة لكل يوم.

### الأسبوع: نظرة إلى الوراء { #week-looking-back }

يعرض **الأسبوع** كل بند مقابل الأيام السبعة، مع نسبة إنجاز كل يوم فوق كل مجموعة. يمكنك التعليم هنا أيضًا؛ والأيام القادمة باهتة.

## تعديل القوائم { #edit-the-lists }

اضغط القلم (**تعديل القوائم**). تبقى الصفحة في وضع التعديل حتى تضغطه مجددًا (**إنهاء التعديل**):

- **إضافة بند** تحت مجموعة يضيف بنودًا. يبقى المربع مفتوحًا للبند التالي، فتُكتب القائمة الطويلة دفعة واحدة؛ واضغط **تم** عند الانتهاء.
- اضغط على بند أو على عنوان مجموعة لإعادة تسميته (**إعادة تسمية البند**، **إعادة تسمية المجموعة**).
- سلة المهملات بجانب البند تحذفه (**حذف البند**).
- **إضافة مجموعة** في الأسفل تضيف مجموعة. ولا تُحذف إلا المجموعة الفارغة (**حذف المجموعة**).

تسري التغييرات على الأسبوع المعروض، وتنتقل البنود إلى الأسابيع التالية.

### تعديل كنص { #edit-as-text }

للتغييرات الأكبر (مقررات فصل دراسي تُلصق دفعة واحدة، أو مجموعة يُعاد ترتيبها)، اضغط **تعديل كنص**. يُفتح الأسبوع كله نصًّا واحدًا:

```
## 1 بداية اليوم
1.1 التحقق من شحن الهاتف
1.2 مراجعة الخطة

## 5 أسبوعي [weekly]
5.1 الاتصال بالأهل
```

بند في كل سطر، تحت عنوان `## المجموعة`. أضف `[weekly]` بعد اسم المجموعة للبنود الأسبوعية. الصق أو رتّب أو احذف بحرية، ثم اضغط **حفظ**.

### الرموز { #codes }

لكل مجموعة رقم ولكل بند رمز (`1.2` هو البند 2 من المجموعة 1). يظهر الرمز صغيرًا فوق اسم كل بند، وإليه تنتمي العلامات: إعادة تسمية البند تحفظ علاماته، والرمز نفسه هو البند نفسه من أسبوع إلى آخر. تُعرض البنود بترتيب رموزها. وفي **تعديل كنص** يحتفظ السطر بعلاماته ما دام رمزه لم يتغير، وإعطاؤه رمزًا آخر ينقله. والسطر الذي بلا رمز بند جديد في المجموعة التي فوقه، يأخذ الرقم التالي.

## الأسابيع { #weeks }

يمتد كل أسبوع من الاثنين إلى الأحد وله قائمته الخاصة. والأسبوع الذي لم تلمسه بعد يعرض بنود آخر أسبوع سابق دون علامات؛ ولا يُكتب ملفه إلا حين تعلّم شيئًا أو تغيّره، فالنظر إلى ما هو قادم لا يترك أثرًا. **تخطيط الأسبوع التالي** ينسخ بنود هذا الأسبوع إلى الأسبوع التالي ويفتحه للتعديل، لتعدّل القائمة قبل أن يبدأ.

## التذكيرات { #reminders }

اكتب وقتًا قبل عنوان مجموعة، مثلًا أعد تسمية **بداية اليوم** إلى `07:30 بداية اليوم`. عندها، كل يوم في 07:30، يظهر إشعار هادئ يذكر اسم المجموعة ويقول **حان وقت تعبئة بنودها.** والضغط عليه يفتح الصفحة.

- التذكير **صامت**: بلا صوت ولا اهتزاز.
- ويُتخطّى في الأيام التي يكون فيها لكل بنود المجموعة علامة.
- للمجموعات اليومية وحدها تذكيرات، لا للمجموعة الأسبوعية.

الوقت جزء من العنوان، فينتقل مع المجموعة إلى الأسابيع التالية، والوقت الذي يُغيَّر على الحاسوب يلتقطه الهاتف.

## البنود العربية { #arabic-items }

البند أو المجموعة التي يبدأ نصها بحروف عربية يُكتب من اليمين إلى اليسار ويُحاذى إلى اليمين، أيًّا كانت لغة التطبيق. وما سوى ذلك يُقرأ من اليسار إلى اليمين، فيمكن أن تجمع القائمة بين الاثنين.

## أين توجد الملفات { #where-the-files-are }

كل أسبوع ملف Markdown واحد يحمل اسمه، مثل `2026-W43.md`، في **مجلد قوائم التحقق**. وهو افتراضيًا مجلد `checklists` داخل مجلد ملاحظاتك، فيُزامَن مع ملاحظاتك. غيّره من [الإعدادات](settings.md) ← **قوائم التحقق**. يبدو الملف هكذا:

```
# Week 43 · 2026-10-19 – 2026-10-25

## 1 Start of day
| Item | Mon | Tue | Wed | Thu | Fri | Sat | Sun |
|---|---|---|---|---|---|---|---|
| 1.1 Check phone charge level | ✓ | ◐ |  |  |  |  |  |
```

يظهر جدولًا في أي عارض Markdown. وإن عدّلته يدويًا، فحرف `x` يُعدّ منجزًا أيضًا. وحين يتغير الملف من خارج التطبيق (مزامنة من حاسوبك)، تعيد الصفحة قراءته عند عودتك إليها.

مفتاح **قوائم التحقق** في أعلى تبويب الإعدادات نفسه يوقف الميزة: تختفي الصفحة من الشريط ولا تُضبط أي تذكيرات.

# Gallery

**Gallery** (the photos icon) is a full-screen picture viewer for one folder of images and its subfolders. You can also mark up a picture (draw on it, highlight, crop and rename) so that a screenshot can be annotated before you attach it to a note or send it on.

The folder is the **Gallery folder** in [Settings](settings.md) (set during the setup tour as **Pictures folder**). By default it is your phone's `Pictures` folder.

## Browsing

- Swipe left or right, or use the round **Previous image** / **Next image** buttons, to move through the pictures.
- Pictures are shown upright, whichever way the camera held them.

## Marking up a picture

A row of tool chips sits over the picture:

| Tool | What a drag does |
|---|---|
| **View** | Nothing; swiping turns the page. This is the default. |
| **Pen** | Draws freehand lines. |
| **Highlight** | Draws a highlighter band across the picture. The drag sets how wide the band is; its height is fixed, like a highlighter nib. |
| **Crop** | Sets the area to keep. |

While a tool is selected, a drag draws instead of turning the page, so use the **Previous image** / **Next image** buttons to move on. **Undo last mark** removes the most recent mark.

The **Label (renames the file)** field renames the picture: the label is added to the end of the file name. Applying a new label replaces the previous one rather than adding to it.

!!! note "No save button"
    Your marks and label are saved automatically when you leave the picture: moving to the next or previous one, switching back to **View**, or leaving the Gallery. If a save fails, the app says **Couldn't save that image — its marks are still here.** and stays on the picture so nothing is lost.

!!! tip "The original is kept"
    The first time a picture is marked up, the untouched original is copied into a hidden `.scr-backup` folder next to it. Nothing clears that folder automatically, so empty it now and then once you're happy with your edits.

Crop is always applied last, whatever order you drew in, so your marks land where you put them.

## Deleting a picture

!!! warning
    The red **Delete photo** button in the corner deletes the current picture **immediately, without asking**. This makes it quick to clear out a folder of screenshots, so take care.

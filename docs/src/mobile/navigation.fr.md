# Se déplacer : le rail de gauche

Une étroite colonne d'icônes longe le côté gauche de chaque page (le côté droit en arabe). C'est le **rail**, et c'est par lui que vous passez d'une page à l'autre.

## Deux bandes, une seule ouverte à la fois { #two-bands-one-open-at-a-time }

Le rail est divisé en deux bandes teintées :

| Bande | Icône | Contenu |
|---|---|---|
| **Sur ce téléphone** | un téléphone | Les pages qui fonctionnent entièrement sur votre téléphone, avec ou sans réseau. |
| **Depuis le serveur** | un nuage | Les pages qui affichent les fiches de votre serveur Nibras. Hors ligne, elles affichent ce qui a été synchronisé en dernier. |

Une seule bande est ouverte à la fois, afin que celle que vous utilisez tienne à l'écran. Touchez l'en-tête de la bande fermée (elle porte une petite flèche en dessous) pour l'ouvrir. Touchez l'en-tête de la bande ouverte pour la replier, par exemple pour faire apparaître la bande serveur sur un petit téléphone. Lorsque vous ouvrez une page depuis un autre endroit, comme un widget ou une notification, le rail ouvre la bande à laquelle appartient cette page.

Les **Paramètres** se trouvent tout en bas, en dehors des deux bandes, et sont toujours visibles.

Si le rail reste plus haut que l'écran, une petite flèche vers le bas (**Plus bas**) apparaît à son pied. Touchez-la pour faire défiler jusqu'au bout du rail.

## Sur ce téléphone { #on-this-phone }

De haut en bas :

| Icône | Page | Voir |
|---|---|---|
| Mosquée | **Heures de prière** | [Heures de prière et adhan](prayer.md) |
| Réveil | **Alarmes** | [Alarmes, rappels et carillon](alarms.md) |
| Note | **Notes** : vos notes, l'écran d'accueil | [Écrire et modifier des notes](notes.md) |
| Étincelles | **Réponses IA** : un second dossier de notes en lecture seule | [Réponses IA](ai-answers.md) |
| Calendrier | **Agenda** | [Agenda](calendar.md) |
| Liste cochée | **Listes de contrôle** : listes quotidiennes et hebdomadaires | [Listes de contrôle](checklists.md) |
| Photos | **Galerie** | [Galerie](gallery.md) |
| Casque | **Médias** : votre bibliothèque audio | [Lecteur multimédia](player.md) |
| Pellicule | **Vidéos** | [Vidéos](player.md#videos) |
| Dossier avec flèche | **Collecter des fichiers** | [Collecter des fichiers](collect.md) |

Plusieurs de ces pages peuvent être désactivées, chacune avec l'interrupteur en haut de son onglet dans les [Paramètres](settings.md) : **Heures de prière**, **Listes de contrôle**, **Galerie**, **Pages du lecteur multimédia** (Médias et Vidéos ensemble) et **Collecte de fichiers**. Une page désactivée disparaît du rail. Si vous étiez dessus, l'application revient à Notes.

## Depuis le serveur { #from-the-server }

| Case | Page |
|---|---|
| **T**, **P**, **J**, **G**, **N**, **W**, **R** | Les sept types de fiches : **Tâches**, **Plans**, **Journal**, **Objectifs**, **Notes**, **Écrits**, **Ressources**. Le nombre entre parenthèses indique combien de fiches de ce type se trouvent sur le téléphone. |
| Cartes | **Cartes mémoire** |
| Guillemet | **Passages surlignés** |
| Personnes | **Contacts** |
| Globe avec loupe | **Rechercher sur le serveur** |
| Flèche circulaire | **Actualiser les pages du serveur**. Se reconnecte, actualise les types et catégories depuis le serveur et recharge toutes les pages serveur. N'ouvre aucune page. |

Toutes ces pages sont décrites dans [Pages serveur](server-pages.md).

Lorsque **Utiliser un serveur Nibras** est désactivé (**Paramètres → Serveur**), toute la bande disparaît du rail et **Sur ce téléphone** reste ouverte.

## Le bouton Retour { #the-back-button }

Depuis toute page autre que Notes, le geste Retour du système vous ramène à Notes au lieu de quitter l'application. À l'intérieur d'une page (une note ouverte, une fiche ouverte), Retour commence par fermer celle-ci.

Chaque page conserve son propre état pendant que vous êtes ailleurs : position de défilement, fiche ouverte, groupes repliés et texte de recherche sont toujours là à votre retour.

## Le mini-lecteur { #the-mini-player }

Dès qu'un élément a été lu, une fine barre apparaît en bas de chaque page. Touchez la barre pour ouvrir le [lecteur](player.md) complet ; touchez son bouton lecture/pause pour basculer la lecture sans quitter la page où vous êtes.

L'icône **Lecteur** de votre écran d'accueil mène directement au lecteur complet avec la dernière piste écoutée, sans passer par la page Médias.
